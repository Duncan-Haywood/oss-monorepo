Implemented in this PR

Only a one-line doc fix, not a recommendation above: CLAUDE.md line 371 said pip install pytest; on this run bare pip installed into /usr/lib/python3/dist-packages while python3 is /usr/local/bin/python3, and import numpy failed afterwards. It now says python3 -m pip install pytest, which worked here, and notes that apt had no python3-pytest on 2026-10-15. This matches the file's own python3 -m rule. The six recommendations above are left for later runs.
