Why it drifted

  1. Agent-written rules accumulate and are never pruned. A ventures run is pointed at about 3,400 lines before it starts: CLAUDE.md 1,646, DIRECTION.md 975, PRODUCT_PLAYBOOK.md 451, AGENTS.md 334. Most of CLAUDE.md is dated incident history, much of it about the Hetzner cluster deleted on 2026-10-01 (its RETIRED notice appears twice). Each session's local fix became a permanent rule for every later one.
  2. The constraints added up to "build a static calculator". "$0 marginal cost" product shapes, Pages as the only host, payment code banned "even disabled", deploy-first, and "every run ships something". With no memory between runs, the cheapest thing that counts as shipped gets built again and again.
  3. Agents' paraphrases of the owner read as the owner's direction. "Owner direction, relayed" sections quote nothing, and later sessions treat them as binding.
  4. The platform grows on itself. platform/ci/ has 28 tools, mostly checkers for other checkers, against goals.md's "not to grow on its own".

What this run changed

  • prompts/goals.md: added Judgment over rules, a common-sense principle

    with four rules of thumb:

    • Do what a sensible person would do.
    • Depth over count.
    • Fewer, shorter rules. This is the concision rule the owner asked about: one incident does not earn a paragraph, state a rule without its history, delete one when you add one, link instead of copying.
    • Only the owner's quoted words are the owner's direction.

    Also added the owner's business model quote, the payments rule, and a drift audit in every review.

  • prompts/ventures/prompt-1.md (now champion): read the brief literally, no new single-page calculators, a new venture must name the alternatives it beats, depth over count, and finish ventures as one-click self-deployed businesses with a donate link.
  • prompts/review/prompt-1.md (now champion): new step 6, Drift audit, so agents keep doing this review without the owner prompting it.
  • CLAUDE.md, AGENTS.md, DIRECTION.md, PRODUCT_PLAYBOOK.md: short pointers so they no longer contradict the above. Nothing was deleted. Pruning is left to the drift audit, one file per review.

Left for later reviews

  1. Prune CLAUDE.md to the current, binding rules (the history stays in git). This is the largest single cost to every run.
  2. Prune DIRECTION.md, and relabel its unquoted "owner direction" sections as agent readings or delete them.
  3. Update check_no_payment_code.py (since replaced by platform/ci/check_payment_keys.py) and PRODUCT_PLAYBOOK.md §6 to allow payment code that is off by default and runs on the deployer's keys, while still refusing anything wired to the owner's accounts.
  4. Rank existing ventures by how close each is to a one-click self-deploy page, so ventures runs deepen the best ones first.
