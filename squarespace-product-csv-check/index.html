Safe fixes

    The model, and what it leaves out

    • Variants are extra rows. A product's first row carries its Title; each further variant is a row with the same Product URL and a blank Title, holding its own SKU, Option Value, Price and Stock. A row with a Title, or a different URL, starts a new product.
    • Options: Option Name 1 to 3 are named on the product's first row; every variant row gives a value for each, and two variants cannot share a combination.
    • SKU is unique across the store, so a repeat inside the file is an error, and so are SKUs Excel rewrote to scientific notation.
    • Plain numbers: Price, Sale Price, Weight, Length, Width and Height are digits and a decimal point, with no currency symbol, unit or thousands separator. Stock is a whole number or Unlimited.
    • Flags On Sale and Visible are Yes or No; a Sale Price should be below the Price, and On Sale needs one.
    • Images: Hosted Image URLs holds full web addresses separated by spaces, not commas.
    • Safe fixes change only the delimiter, header and Product Type capitals, stray spaces, Yes/No flags, Unlimited, price and weight formatting, and commas between image addresses. It never changes the characters of a title, description, SKU, category, tag, option value or image address.
    • Not checked: that Squarespace will accept the file today, whether Product Page and categories exist, subscription or service products, the per-product variant and image limits as they stand now, that image URLs are reachable, and anything Squarespace changes in its importer. Import two or three products first.

    Common questions

    Why did my Squarespace product CSV import fail or create the wrong products?

    The usual causes are variant rows that carry a Title or a different Product URL (so each becomes its own product), a repeated SKU or Product URL, prices with a currency symbol or a decimal comma, a blank price, On Sale set to Yes with no Sale Price, an unquoted comma in Tags or a description that shifts every later cell, image addresses separated by commas, and an Excel save that turned SKUs into scientific notation or the file into semicolons. The tool checks each and names the line.

    How do I check a Squarespace product CSV before importing it?

    Paste the file or drop it onto this page. It reads the header against the import template, groups variant rows under their product by Product URL, and lists every problem with its line number, grouped as errors, warnings and notes. Nothing is uploaded.

    How do variants work in a Squarespace CSV?

    The first row of a product has the Title, description, Option Name columns and the first variant. Each additional variant is a following row with the same Product URL, a blank Title, and its own Option Value, SKU, Price and Stock. Two rows with the same option combination, or a variant value with no option name, are flagged.

    Why is my Squarespace CSV semicolon-separated?

    Excel in many European and Latin American locales saves CSV with semicolons because the comma is the decimal separator. The importer expects commas. This tool detects the delimiter and, with Apply safe fixes, rewrites the file with commas.

    What does Apply safe fixes change?

    Only things with one reasonable reading: the delimiter, header capitalisation, Product Type capitals, stray spaces around IDs, URLs, SKUs and image addresses, yes/no or true/false to Yes or No, unlimited to Unlimited, decimal commas in weights, prices like $1,299.00 to 1299.00, and commas between image addresses to spaces. It never changes the characters of a title, description, SKU, category, tag, option value or image address, and it lists every change before you download.

    Is it safe to put my product catalogue into a web page?

    The page runs in your browser, the file is read locally and nothing is uploaded; a test in the code asserts there are no network calls. Your own policies still decide what you may open in a browser.

    What does this not check?

    Whether Squarespace will accept the file today, whether pages and categories already exist, subscription or service products, current variant and image limits, whether image URLs are reachable, and anything Squarespace changes in its importer. A clean result is not a promise of success: import a few products first.
