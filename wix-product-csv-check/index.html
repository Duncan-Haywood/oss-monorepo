Safe fixes

    The rules, and what they leave out

    • Rows. A Product row carries the name, description, price, images, collection and options. Each Variant row that follows has the same handleId and one choice per option. Two Product rows must not share a handleId.
    • Options use productOptionName, productOptionType (DROP_DOWN or COLOR) and productOptionDescription, with the choices separated by semicolons. Up to six options per product; each name and each choice must be unique.
    • Variants must use a choice the Product row lists, once per combination. Use surcharge on a Variant row to add to or subtract from the price.
    • name is limited to 80 characters; price, weight, cost, surcharge and discountValue are digits and a decimal point. The store currency is set in Wix, not in the file.
    • visible is TRUE or FALSE; inventory is InStock, OutOfStock or a whole number; discountMode is PERCENT or AMOUNT and a percent cannot exceed 100.
    • productImageUrl holds one or more public web addresses separated by semicolons.
    • Safe fixes change only the delimiter, header capitals, Product/Variant capitalisation, price and surcharge formatting, TRUE/FALSE, PERCENT/AMOUNT, InStock/OutOfStock, option type spelling and stray spaces around a SKU. It never edits a name, description, image address, collection, option choice, handleId or SKU.
    • Not checked: that Wix will accept the file today, product categories, tax and shipping settings, custom text fields, image contents, and anything Wix changes in its importer. Import two or three products first.

    Common questions

    Why does my Wix Stores product CSV import fail or drop variants?

    The usual causes are a Variant row whose handleId has no Product row above it, a variant choice that is not in the Product row's option list, two Product rows with one handleId, a price with a currency symbol or decimal comma, visible or inventory values Wix does not read, a discount mode that is not PERCENT or AMOUNT, an unquoted comma that shifts every later cell, and an Excel save that turned SKUs into scientific notation. This tool tests each of them and names the line.

    How do variants work in a Wix product CSV?

    From memory of Wix's public documentation: one Product row carries the options, with the choices separated by semicolons in productOptionDescription, then one Variant row per combination follows with the same handleId, one choice per option and an optional surcharge. The tool checks that every variant matches the product's option list. Confirm the current format in a fresh Wix export.

    How do I check a Wix CSV before importing it?

    Paste the file or drop it onto this page. It reads the header against the Wix product export, checks every row and every variant against its product, and lists problems with their line numbers, grouped as errors, warnings and notes. Nothing is uploaded.

    What does Apply safe fixes change?

    Only things with one reasonable reading: the delimiter, header capitalisation, Product and Variant capitals, prices like $1,299.00 to 1299.00, TRUE and FALSE, PERCENT and AMOUNT, InStock and OutOfStock, option type spelling, and stray spaces around a SKU. It never edits a name, description, image address, collection, option choice, handleId or SKU.

    Is it safe to put my product catalogue into a web page?

    The page runs in your browser, the file is read locally and nothing is uploaded; a test in the code asserts there are no network calls.

    What does this not check?

    Whether Wix will accept the file today, product categories, tax and shipping settings, custom text fields, and image contents. A clean result is not a promise of success: import a few products first.
