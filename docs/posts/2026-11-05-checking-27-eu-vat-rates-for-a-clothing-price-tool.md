# We checked 27 EU VAT rates, and could not reach the official table

The Clothing Design Studio's price-by-market page turns one margin target into a shelf price for
every EU state, the UK and the US. Its 27 EU standard VAT rates had been typed from memory and
labelled unchecked.

The European Commission's rate table is blocked from the build host, so on 2026-11-05 the rates
were compared with search excerpts of five commercial 2026 tables. All 27 agree, including the
recent changes (Finland 25.5%, Estonia 24%, Slovakia 23%, Romania 21%). Those are secondary
sources, so the page keeps its "confirm before filing" wording, and reduced rates, OSS
registration and US state tax are still not applied. A test now pins the 27 rates so a stray edit
shows up.

The README and ROADMAP say exactly this: checked against commercial tables, not the Commission's.
