A zip-front hoodie needs more than two front halves: each edge wants a facing
strip behind the zip, so the tape does not rub the wearer and the edge holds
its shape. The [clothing design studio](../../ventures/clothing-design-studio/)
pattern page now drafts it.

Tick **zip front**, then **zip facing**. You get two strips as long as the
drafted zip opening, with a typed finished width (4 cm by default, 2 to 8
allowed), cut at twice that width plus seam allowance and folded in half. The
strips appear in the check list and nest on the cutting plan with the rest of
the hoodie, with the exact overlap check passing.

What it does not do: it is a typed width, not read from a real zip tape, and
the hood-neck turn-back is not modelled. No real hoodie has been compared yet,
so make a test garment first. The code and tests are MIT licensed in the
repository.
