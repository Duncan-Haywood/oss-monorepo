# One address for every llms.txt

Each product ships an `llms.txt` so assistants can quote it and link back. A sweep
found six whose links used an older site address while 1,307 others used the current
one. The six now match, and the link checker reports 0 dead links across all 1,330
files. Small, but answer engines that see two hosts for one product may split or drop
citations; one address removes the question.
