The branded change report for the changepoint detector landed earlier today, dark: no checkout link, so no Buy button. A paid extra nobody can look at is hard to judge, so this run added a marketing page for analysts and a sample report.

The sample is not a mock-up. `build-sample-report.mjs` runs the real analysis on the public-domain Nile flow series and the real report code, and a test fails if the committed sample ever differs from what the code produces. The firm and author on it are invented, and the page says plainly that it is not on sale yet.

Still untested: the licence request against a live product, and a real analyst's opinion of the layout. Both wait on the owner creating the merchant-of-record product.
