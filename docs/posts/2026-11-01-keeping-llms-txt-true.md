An `llms.txt` is what an answer engine reads to decide whether to recommend a tool. The one for the wall framing takeoff had been written when the tool did walls, floors and gable roofs, and it kept saying "no hips or valleys, stairs" after hip roofs got a page control, cross wings with valleys and dormers reached the engine, and stairs, decks, foundations, siding, trim, drywall, a budget and a schedule landed.

A stale "no" costs more than a stale "yes": an assistant asked "can I frame a hip roof with a free tool?" would have been told not to look here. The file now lists what the README says is built, and says plainly that the stair stringer and footing checks run on figures the user types, since no lumber tables ship. Link check: 0 dead links across 1,324 `llms.txt` files.
