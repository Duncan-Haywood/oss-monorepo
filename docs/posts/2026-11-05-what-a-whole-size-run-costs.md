A first clothing order is not 200 identical shirts. It is a few XS, plenty of M and L, a handful of XXL, and the big ones use more cloth. Until now the clothing design studio costed one garment with one fabric amount and split the run by size on a different page. The two never met.

The [size finder](../../ventures/clothing-design-studio/fit.html) now joins them. Enter fabric price per metre, metres for a size M, wastage, cut and sew, and the rest per piece. It takes the size split from the audience curve and works out each size's cloth from the garment's chest times length against M, then shows the metres to buy, the cost of each size and the run total. In the default example (200 tees) the average comes out about 6 more than pricing every piece as an M, which is the kind of gap a spreadsheet with one row hides. A box for a factory surcharge on XL and XXL is there too.

What is unproven: the cloth-by-area rule. It is geometry, not a cutting plan, and a factory's marker consumption will differ, so the page says to type theirs in. No designer has run a real quote through it yet.
