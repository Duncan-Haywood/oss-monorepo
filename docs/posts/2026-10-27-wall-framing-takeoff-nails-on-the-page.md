The nail count that only the command line could print is now a tick box on the [wall-framing-takeoff](../../ventures/wall-framing-takeoff/) page. Tick "Also count nails by connection", and a card lists nails per connection (stud ends, jack to king, header plies, sills, plates) plus sheathing nails when the sheathing box is on. Type a nails-per-box figure and a box price and the budget gains a "Framing nails (boxes)" line. The settings save with the plan file.

Every spacing is a typed default of common practice, not a code table, so check it against your code edition and engineer. Exercised in a real browser on the sample house only (page errors: 0). No hold-downs or hardware.
