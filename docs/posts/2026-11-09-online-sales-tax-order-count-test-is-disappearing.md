A small online brand used to be able to cross a state's "economic nexus" line
with 200 cheap orders. In a growing list of states that no longer works. Search
results citing Avalara (April 2026) and Taxually (October 2026) say Illinois
dropped the order test on 1 January 2026, Kentucky on 1 August 2026 (HB 757),
Utah on 1 July 2025 and Alaska's remote-seller commission on 1 January 2025. In
those four, only the $100,000 of sales counts.

The sales-tax checker in the clothing design studio now treats the four as
sales-only. It still has the old rule for the other states that keep an order
test, and Connecticut and New York still need both tests. The figures for other
states were typed from memory and are unchecked: the state revenue sites are
unreachable from the build host, so check any state before registering. Maine
is listed as dropped by one source and left as it was until confirmed. This is
not tax advice.
