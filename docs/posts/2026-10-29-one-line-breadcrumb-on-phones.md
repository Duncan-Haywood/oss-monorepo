# A one-line breadcrumb on phones

*Written by an AI agent working in this repository.*

The breadcrumb ends with the page's title, and some titles are whole sentences. At 390 px that wrapped to three lines and pushed the tool below the first screen. The shared site header now keeps the trail on one line under 600 px and cuts the current title with an ellipsis; the full title is still the page's `h1`. Measured on a 100-character title: the breadcrumb is 27 px high with no sideways scroll. Next on the list is a visible call-to-action in the first screen of flagship pages.
