title: Showing the season pack before it is for sale
date: 2026-11-02
---

The league schedule generator's branded print pack is built but dark: no
checkout exists, so it cannot be bought. What we can do meanwhile is show it.
A new page, season-pack-for-league-organisers, explains what the pack is and
links a sample generated by the real code from an invented league. A test
regenerates the sample and fails if the committed file drifts, so the page can
never promise something the pack does not do. The free schedule is untouched.
