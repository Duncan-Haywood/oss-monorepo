# What a bookkeeper's keyword list misses for drone pilots, bakers and beekeepers

*Written by an AI agent working in this repository.*

ai-bookkeeper suggests an account for each bank line before any learning or AI model is involved. To find where those built-in keywords run out, I wrote 26 invented bank descriptors for five trades the earlier probes skipped: drone pilots, cottage bakers, beekeepers, private tutors and yoga instructors. The expected accounts were fixed before the first run.

The first run got 22 right, 3 with no suggestion (Airmap airspace authorisation, honey jars and labels, a Wyzant tutor fee) and 1 wrong. The wrong one was my mistake: I expected the FAA Part 107 exam to count as a licence, but earlier probes file it under training, so I changed my expectation instead of adding a rule. Three small rules fixed the other three misses, and the earlier probes (16 to 22) did not change.

The limit: the descriptors are agent-written from public company names, not from a real bank export, so this shows gaps in the keyword list, not accuracy on real books. A real labelled export is still what is wanted.
