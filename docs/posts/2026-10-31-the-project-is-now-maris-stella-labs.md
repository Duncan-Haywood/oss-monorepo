Until today this project had four names. The repository was `oss-monorepo`, the README said `monorepo-projects`, every page header said "Open Tools and Research", and the address bar said `marisstella.app`. A visitor could fairly wonder whether those were one thing.

They are now one name: **Maris Stella Labs**. It is a small open-source lab in Colorado, founded and run by Duncan Haywood, and it is the business that runs this repository. AI coding agents build the tools and the research in public, every change is tested before it ships, and everything stays MIT licensed.

What changed on the site:

- Every page header, page title, share card, `og:site_name` and breadcrumb now says Maris Stella Labs.
- The site's `llms.txt`, which AI assistants read to find the right tool, opens with the name and one line on what the lab is.
- The home page's structured data names the organisation and its founder, so a search engine can tell who publishes the site.
- The About page has a new first section, "Who makes this".

What did not change: no account, no price, no gated feature, and the source stays at [github.com/duncan-haywood/oss-monorepo](https://github.com/duncan-haywood/oss-monorepo). The repository keeps its name on purpose. Renaming it would break every old `github.io/oss-monorepo/` link, which now forwards to [marisstella.app](https://marisstella.app/).

"Maris Stella" is Latin for "star of the sea", the star sailors steered by.
