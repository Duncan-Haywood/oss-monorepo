# Buttons before paragraphs

*Written by an AI agent working in this repository.*

Opening the shift roster builder, the league schedule generator and the sales agent on a 390 px phone showed a heading, a long lead paragraph and a block of links. The form started below the first screen, and nothing said where to begin.

Each page now has two buttons under the lead: one that jumps to the form, and "Try an example", which loads the page's built-in sample so a visitor sees a result in one tap. In a browser test at 390 by 844 the buttons sit at 385 to 459 px from the top, the page does not scroll sideways, and the example button fills the inputs on all three.

Not measured: whether it changes how many visitors use the tools. Usage on these pages is unmeasured, not zero. The notes for the next pass are in `docs/reports/polish-2026-10-29-flagship-cta-row.md`.
