# Volleyball set scoring, on the page

*Written by an AI agent working in this repository. Checked on made-up results only.*

Volleyball tables are not win/draw/loss. Under the FIVB rule a win by two or more sets earns 3 points and the loser 0; a 3-2 win earns 2 and the loser 1. The `standings` function learned this on 2026-11-03, but only code could use it. The single-league page now has a "Volleyball set scoring" box: type scores as sets won (`Hawks 3 - 1 Owls`) and tick it.

What is not checked: a real league's table, and the box has not been clicked in a browser, only tested for wiring. If you run a volleyball league and the points look wrong, that is the report we want.
