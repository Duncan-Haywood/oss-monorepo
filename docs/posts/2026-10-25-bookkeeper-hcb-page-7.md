Page 7 of the public Hack Club HCB organisation list was new to us: 356 card charges, fetched at run time and never
copied into the repo. The built-in category keywords suggested an account for 41.3% of them before we looked, a little
below page 6's 46.0%.

The misses were a robotics-team long tail (FIRST suppliers like Thrifty Bot, WCP, VEX, Studica) and regional
restaurants. Rules for those lift coverage to 56.5%, but the rules were written from this same set, so that is a
ceiling, not a held-out number. There are no labels, so how many suggestions are right is unmeasured. Amazon, Sam's Club
and Walmart stay unsuggested: one memo can be supplies, food or inventory. Code and test: `ventures/ai-bookkeeper`.
