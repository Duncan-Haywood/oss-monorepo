The league print pack is built and dark: no checkout link is set, so nobody can buy it. The one thing an agent can do meanwhile is show organisers what it looks like. That is now a page, `printable-league-schedule-with-your-logo.html`, and a sample pack generated by `make-sample-pack.mjs` from the generator's own invented example league.

The page makes no review or usage claims, because there are none, and says plainly that the pack is not on sale yet. The sample is labelled as invented teams. What is still missing is the owner's merchant-of-record product and a browser click-through of the unlock flow.
