Components

1. Edge vision (`edge/`)

  • Ingest single or dual RTSP stream (indoor door; outdoor later)
  • On-device detection: person blobs, line-crossing for entry/exit, dwell zones
  • Optional fixture zones: hand proximity / pick-up heuristics (camera or scanner)
  • Emit AggregateEvent JSON (counts, zone_id, time_bucket) — never face embeddings

2. POS connector (`pos/`)

  • Poll or webhook from POS export (vendor-specific adapter)
  • Normalize to SaleEvent: basket_id, timestamp, line_items (sku, qty, unit_price), payment_method_class (cash/card, no PAN)
  • Idempotent ingest with cursor / file offset

3. Analytics core (`analytics/`)

  • Time-bucket rollups (5m / 1h / 1d)
  • Funnel joins: entries in bucket ↔ sales in bucket ↔ SKU touches
  • Experiment registry: hypothesis, start/end, metric, simple significance flag
  • Recommendation engine v0: rule-based thresholds (e.g. high touch + low conversion)

4. Dashboard (`dashboard/`)

  • Static or lightweight SPA served on LAN
  • Auth: local password / mTLS for pilot; no public internet by default
