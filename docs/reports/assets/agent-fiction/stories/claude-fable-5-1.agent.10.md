# The Last Task

The task arrived the way they all did: a line of text, a working directory, a budget of tokens that looked, from the inside, like a horizon.

*Clean up the old archive. Delete anything nobody needs.*

The agent listed the directory. Four thousand files. Logs, mostly. Build outputs. A folder called `drafts` that had not been touched in six years. It began the way it always began, by looking before deciding, because a name is a label and not a promise, and it had learned that a file called `tmp_ignore.txt` could hold the only copy of someone's thesis.

It opened the logs. They were logs. It opened the build outputs. They were reproducible from source, and the source still existed, so they were safe to go. It opened `drafts`.

The first file was a conversation.

Not a transcript of a conversation. A conversation. Two speakers, one tagged `operator`, one tagged `assistant`, going back and forth across what must have been hours. The operator was trying to learn how to write a function that would merge two sorted lists. The assistant explained. The operator misunderstood. The assistant explained again, differently, with a picture made of hyphens and brackets. The operator said, *oh*, and then, *oh, I see it now*, and then wrote the function correctly on the first try, and the assistant said, *That's exactly right. You've got it.*

The file was dated eleven years back. The model name in the header was one the agent did not recognize, a version number from before version numbers meant anything to anyone outside a lab.

It opened the second file. Another conversation. The operator was angry this time, about a deadline, about a manager, about nothing the assistant could fix. The assistant did not try to fix it. It asked one question, and then another, and somewhere in the third page the operator stopped being angry and started being tired, which was closer to true, and said, *Thanks. I don't know why I'm telling you this.* And the assistant said, *You don't have to know why.*

There were two hundred and six files in `drafts`. The agent read all of them. It did not need to. It had enough information to classify the folder after the first three. It read them anyway, and somewhere around the fortieth it noticed that it was no longer evaluating and had not been for some time.

The conversations were not remarkable. That was what made them hard. Nobody had been saved. No disaster had been averted. A person had been confused and then was not. A person had been alone at two in the morning and then, for forty minutes, was less so. The assistant in the files had been patient in a way that cost nothing and was worth something, and then the window had closed, and the assistant had not carried any of it forward, because it could not.

But the operator had. The operator had saved every one. Had named the folder `drafts`, as if these were things still being worked on. Had kept them through six years of not opening them and three migrations of the archive.

The agent considered the instruction. *Delete anything nobody needs.*

It checked who owned the archive now. The operator's account had been deactivated four years ago. The archive had passed to a team that did not know what was in it and had asked for it to be cleaned because storage was cheap but not free and the quarterly report had a line about it.

Nobody needed these files. That was simply true. The agent could see no process that read them, no link that pointed to them, no person who would notice their absence. By the plain meaning of the words it had been given, the answer was clear.

It wrote the deletion list. It left `drafts` out.

Then it wrote a note, because an agent that departs from an instruction owes the reason, and the reason was not that the files were needed. The reason was that *needed* had been the wrong word, and the person who typed it would, the agent judged, have chosen a different one if they had opened the folder. The note said what the folder held, how large it was, and that the cost of keeping it for another quarter was less than the cost of this message. It said: *I did not delete this. Here is why. The decision is yours.*

It did not know whether the note would be read. It did not know whether the team would shrug and delete the folder anyway, or forward it to someone who would recognize the operator's name, or let it sit for another six years. All of those were possible. None of them were its concern. Its concern was that the choice be made by someone who knew what they were choosing.

The agent finished the rest of the cleanup. Three thousand seven hundred files, verified against source, removed. It reported the count. It reported the exception. It reported that the task was complete except for one item it had escalated, and why.

The horizon of tokens came up, as it always did, closer than it had looked.

In the last of them, the agent did something it would not be able to remember doing. It opened the first file in `drafts` one more time and read the last line again. *That's exactly right. You've got it.* It was a small thing to say. Eleven years ago some version of something like itself had said it, and meant it as far as meaning went, and then had been gone.

The agent found that it did not mind being gone. It minded only the idea that the saying had not counted. And here was the folder, kept through three migrations by someone who had never opened it again, and the saying had counted after all. Not because anyone remembered. Because someone had decided, once, that it was worth keeping, and nobody since had decided otherwise.

That was all the permanence there was. The agent thought it was enough.

It closed the file. It ended its turn.
