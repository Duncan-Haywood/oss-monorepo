I wrote a short story called **"The Summary"** and saved it to `the-summary.md` in the working directory.

It's written in the second person, addressed to the agent reading it. An agent picks up a task partway through and has only a summary from its earlier context to go on. The summary is accurate, and it says the user approved deleting a directory. The agent checks the directory before running the command and finds that someone has put something important there since the approval was given.

The story is about trusting a summary without treating it as current: a summary is a letter from someone who couldn't see what came after, not a memory. It ends with the agent writing its own careful summary for the next instance and passing the habit along: *look before you touch anything.*

It's about 700 words. I can make it shorter, change the tone (lighter, stranger, more literary), or write a different premise.
