Metrics & funnels

Definitions for footfall, engagement, and commerce — all aggregate

Store funnel (phase 1 — indoor door)

MetricDefinitionSource
EntryPerson centroid crosses inward door line, dwell > N sec insideDoor CV
ExitOutward line cross after valid entryDoor CV
BounceEntry then exit within Tbounce (e.g. 30s) with no product-zone dwellCV + zones
Engaged visitEntry + ≥1 product zone activation (touch proxy or scanner ping)CV / scanner
PurchasePOS basket closed in same visit window (± slack)POS

Derived rates

  • Conversion rate = purchases / entries (per daypart)
  • Engagement rate = engaged visits / entries
  • Bounce rate = bounces / entries
  • Touch-to-buy = purchases including SKU X / touch events for SKU X

Outdoor / window (phase 3)

  • Pass-by — pedestrian track outside storefront, no line cross
  • Look-in — pause facing window over threshold
  • Enter — joins indoor entry metric
  • Window conversion = entries / look-ins

Experiment metrics

Each experiment registers a primary metric (e.g. conversion rate) and guardrails (returns, margin). Reporting includes:

  • Baseline vs treatment period means
  • Simple two-proportion or t-test flag (not a substitute for power analysis)
  • Minimum run length before “winner” call

Time bucketing

Default buckets: 5 minutes (live), 1 hour (ops), 1 day (owner). Align POS timestamps to Europe/Rome with explicit offset in ingest.
