Consent Change Record

Did that consent banner actually stop the tracking requests, or just hide the banner? Export two HAR network captures from your browser — one before a consent choice, one after — and this diffs every request and cookie that appeared or disappeared. Nothing is uploaded.

How to get a HAR file

Open your browser's DevTools → Network tab → reload the page → make your consent choice (or don't) → right-click any request → "Save all as HAR". Do this twice on the same site: once before the consent action, once after, then drop both files below. Only test sites you own or are authorized to test.

Privacy

Everything runs in your browser. The HAR files you select are read locally with the File API and are never uploaded — there is no server this page talks to. We don't have accounts, tracking cookies, or an analytics vendor. This page counts anonymous, local feature-use events (e.g. "a diff was generated") in your own browser's localStorage, only so the maintainers can tell whether the tool is used at all — nothing leaves your device.
