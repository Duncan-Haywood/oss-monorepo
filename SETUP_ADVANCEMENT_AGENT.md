# Setting Up the Repo Advancement Agent

This guide walks you through setting up the automated repository advancement agent that uses Deepseek Flash V4 for planning and OpenCode for implementation.

## What It Does

The agent automatically:
1. **Plans improvements** using Deepseek Flash V4 (advanced reasoning)
2. **Implements changes** using OpenCode (specialized coding)
3. **Creates pull requests** with the improvements for review

The agent runs on a schedule (default: every Monday at 9 AM UTC) or can be triggered manually.

## Prerequisites

- GitHub repository admin or settings access
- API keys from:
  - **Deepseek**: https://platform.deepseek.com/api_keys
  - **OpenCode**: https://api.opencode.dev (get your API key)

## Step-by-Step Setup

### Step 1: Add GitHub Secrets

GitHub Secrets store your API keys securely without exposing them in code or logs.

#### Adding Secrets via GitHub Web UI

1. Go to your repository on GitHub
2. Click **Settings** → **Secrets and variables** → **Actions**
3. Click **New repository secret**

#### Add DEEPSEEK_API_KEY

1. **Name**: `DEEPSEEK_API_KEY`
2. **Secret**: Paste your Deepseek API key from https://platform.deepseek.com/api_keys
3. Click **Add secret**

#### Add OPENCODE_API_KEY

1. **Name**: `OPENCODE_API_KEY`
2. **Secret**: Paste your OpenCode API key
3. Click **Add secret**

**Verification**: Both secrets should now appear in your Secrets list.

### Step 2: Verify Workflow File

The workflow file is already created at:
```
.github/workflows/repo-advancement-agent.yml
```

To check it's valid:
1. Go to **Actions** → **Repo Advancement Agent**
2. You should see the workflow listed
3. The status indicator should be green (valid)

### Step 3: Enable the Workflow

The workflow is enabled by default. To verify:

1. Open `.github/workflows/repo-advancement-agent.yml`
2. Confirm the workflow is active (not commented out)
3. Go to Actions tab → you should see the workflow

### Step 4: Test Locally (Optional)

Before running in GitHub Actions, test locally:

```bash
# Set your API keys
export DEEPSEEK_API_KEY='your-deepseek-key'
export OPENCODE_API_KEY='your-opencode-key'

# Run in dry-run mode (no changes committed)
cd /path/to/monorepo-projects
bash platform/agents/run-local.sh --dry-run

# Run for real (creates test branch with changes)
bash platform/agents/run-local.sh --max-items 3
```

## Running the Agent

### Automatic (Scheduled)

The agent runs automatically every Monday at 9 AM UTC. No action needed.

To check past runs:
1. Go to **Actions** → **Repo Advancement Agent**
2. View the run history and logs

### Manual (On Demand)

To run immediately:

1. Go to **Actions** → **Repo Advancement Agent**
2. Click **Run workflow**
3. Optionally set **max_items** (default: 3)
4. Click **Run workflow**

Wait for the workflow to complete. It will:
- Create a new branch
- Run the planning and implementation
- Create a pull request

## What Happens During a Run

### Phase 1: Planning (~1-2 minutes)
- Analyzes repository state
- Calls Deepseek API to generate work items
- Example work items: add tests, fix documentation, refactor code

### Phase 2: Implementation (~2-5 minutes)
- For each selected work item:
  - Calls OpenCode API to implement changes
  - Receives generated code changes
  - Applies changes to working directory

### Phase 3: PR Creation (~1 minute)
- Commits changes with descriptive message
- Pushes to new branch
- Creates pull request with agent output

## Reviewing Agent PRs

When a PR is created by the agent:

1. **Read the description** - It includes the agent's reasoning
2. **Review the changes** - Check that code looks good
3. **Verify no regressions** - Run tests locally if needed
4. **Check CI** - Wait for GitHub Actions checks to pass
5. **Approve and merge** - Or request adjustments

### Typical PR Description

```
## Repo Advancement Agent

This PR contains improvements generated by the Repo Advancement Agent.

### Agent Output
[Details of what was planned and implemented]

### What Changed
- Code quality improvements
- Tests and documentation enhancements
- Performance optimizations
```

## Customization

### Change Schedule

Edit `.github/workflows/repo-advancement-agent.yml`:

```yaml
schedule:
  - cron: '0 9 * * 1'  # <- Change this line
```

Cron syntax: `minute hour day-of-month month day-of-week`

Examples:
- Daily at 9 AM: `0 9 * * *`
- Every 6 hours: `0 */6 * * *`
- Friday at 3 PM UTC: `0 15 * * 5`

### Adjust Implementation Limits

Edit `.github/workflows/repo-advancement-agent.yml`:

In the workflow_dispatch inputs section, change:
```yaml
default: '3'  # <- Max items per run
```

Or when manually running, set this value in the UI.

### Modify Agent Behavior

Edit `platform/agents/repo-advancement.js`:

- **Planning prompt** (line ~100): Change what kinds of improvements are identified
- **API endpoints**: Update base URLs if using different API services
- **Filtering logic**: Adjust how work items are selected and prioritized

Edit `platform/agents/config.json`:

- **Focus areas**: Types of improvements to focus on
- **Temperature**: Deepseek creativity level (0.0-1.0)
- **Max tokens**: Limit response size

## Troubleshooting

### Workflow doesn't appear in Actions

**Problem**: The workflow file isn't showing up in GitHub Actions.

**Solution**:
1. Verify file is at: `.github/workflows/repo-advancement-agent.yml`
2. Check syntax is valid YAML (use a YAML validator)
3. Commit and push the file
4. Wait 1-2 minutes for GitHub to detect it
5. Hard refresh the Actions page

### API key errors

**Problem**: `DEEPSEEK_API_KEY or OPENCODE_API_KEY not set`

**Solution**:
1. Go to Settings → Secrets and variables → Actions
2. Verify both secrets are listed
3. Check spelling: `DEEPSEEK_API_KEY` and `OPENCODE_API_KEY`
4. Re-create the secret if needed (delete and add again)

### No work items identified

**Problem**: Agent runs but creates no PR (no work identified).

**Causes & Solutions**:
- Repository is very well maintained
  → Adjust the planning prompt to look for smaller improvements
- Recent changes already covered the low-hanging fruit
  → Run again next week
- API didn't return useful response
  → Check API status and logs

### OpenCode API errors

**Problem**: `OpenCode API error: 401 Unauthorized`

**Solution**:
1. Verify API key is correct
2. Check API key has correct permissions
3. Ensure API key hasn't expired

### PR not created

**Problem**: Agent runs, changes are made, but no PR appears.

**Solution**:
1. Check workflow logs for errors
2. Verify GitHub token has `contents: write` and `pull-requests: write` permissions
3. Check if branch was successfully pushed

## Monitoring & Metrics

Track the agent's effectiveness:

1. **Run frequency**: Check Actions tab for run history
2. **PR quality**: Review merged PRs and their CI status
3. **Failure rate**: Monitor for consistent errors
4. **Cost**: Track API usage on Deepseek and OpenCode dashboards

## Cost Considerations

The agent makes API calls to:
- **Deepseek**: ~$0.14 per 1M tokens (planning phase)
- **OpenCode**: Check your billing dashboard

Estimated cost per run:
- Planning: 2,000-4,000 tokens from Deepseek (~$0.00-0.01)
- Implementation: Varies by OpenCode pricing

With weekly runs, expect minimal costs (~$1-5/month).

## Support & Feedback

### Issues?

1. Check agent logs: Actions → Repo Advancement Agent → Run → Logs
2. Review agent code: `platform/agents/repo-advancement.js`
3. Check configuration: `platform/agents/config.json`

### Want to modify the agent?

Edit these files:
- `platform/agents/repo-advancement.js` - Main agent logic
- `platform/agents/config.json` - Configuration
- `.github/workflows/repo-advancement-agent.yml` - Workflow definition

### Disabling the Agent

To temporarily disable:
1. Edit `.github/workflows/repo-advancement-agent.yml`
2. Comment out the `schedule` section:
   ```yaml
   # schedule:
   #   - cron: '0 9 * * 1'
   ```
3. Commit and push

To permanently remove:
1. Delete `.github/workflows/repo-advancement-agent.yml`
2. Delete `platform/agents/`
3. Commit and push
