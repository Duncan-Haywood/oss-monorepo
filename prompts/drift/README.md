# Drift reports

One per review run (`prompts/review/prompt-1.md`, step 6), named
`YYYY-MM-DD.md`. Each one checks whether the work and the documents still
match what the owner actually said, fixes what it can, and asks the owner
one-line questions about what it cannot. Write each report so the owner can
read it in two minutes. The rules it applies are "Judgment over rules" in
[`../goals.md`](../goals.md).
