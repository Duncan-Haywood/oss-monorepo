## Findings by root cause

| # | Root cause | Count in window | Why the process lets it through |
|---|---|---|---|
| 1 | **A new venture page violates a site-wide invariant the venture's own tests do not cover**: launch date missing from `launched.json`, `launched.json` key order, mirror not regenerated, `[hidden]` CSS rule, broken inline script, missing `</head>` | 11 fix-up commits (#6975, #6963, #6962, #6900, #6914, #6895, #6894, #6792, #6761, #6729, #6561) | The checks that catch these (`platform/pages`, `platform/marketing`, the Pages publish check) live outside the venture's `node --test` glob. A venture author's green local run is honest and still wrong. They show up as red `main` or as a blocked Pages publish |
| 2 | **Two sessions do the same fix or venture** | 2 pairs of fix-ups both merged (#6894/#6895, #6962/#6963); 4 pairs where one was closed unmerged (#6698/#6699, #6343/#6347, #6337/#6338, #6265/#6266); 1 venture name merged twice | The duplicate check is "look at open PRs", which cannot see a PR that merged minutes earlier. `CLAUDE.md` already records this for comparison pages and offers `surface-budget.mjs`; there is no equivalent for "is this slug or this fix already in flight" |
| 3 | **Run bookkeeping dominates history** | 142 run-log commits plus 108 merge-main commits, 250 of 1,580 (16%) | Each session appends its own log commit and merges `main` into its branch. Not defects, but they bury the commits the `fix` grep above has to read |
| 4 | **Instruction text costs time** | `promptctl.py measure` doc-friction: `CLAUDE.md` 5 reports (about 1,000 lines of incident history; checklist loop stops at the first failing module on clean main; 26 gitops tests fail on clean main when `gh` is preinstalled). This run: bare `pip install` landed in a different interpreter than `python3`, and apt had no `python3-pytest` | The file records every incident as a paragraph and deletes none |

Thin evidence: (a) root cause 1 counts only commits whose titles say what they
fix; fixes titled otherwise are missed, so 11 is a floor. (b) The 5% unmerged
rate is not split by cause (duplicate, abandoned, superseded); I read titles,
not bodies. (c) Run records are 97% research from the upstream repo and say
nothing about ventures (2 records), so per-track success rates do not
generalise. (d) "Merged?" is `unknown` for 167 of 175 records.

## Implemented in this PR

Only a one-line doc fix, not a recommendation above: `CLAUDE.md` line 371 said
`pip install pytest`; on this run bare `pip` installed into
`/usr/lib/python3/dist-packages` while `python3` is `/usr/local/bin/python3`,
and `import numpy` failed afterwards. It now says `python3 -m pip install
pytest`, which worked here, and notes that apt had no `python3-pytest` on
2026-10-15. This matches the file's own `python3 -m` rule. The six
recommendations above are left for later runs.
