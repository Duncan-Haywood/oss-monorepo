      What it does, and what it leaves to you

      • Finds: shall / must / is required to / will (when the contractor is the subject) obligations, shall-not prohibitions and should-style desirables, each with the sentence it came from. Lists introduced by "The Contractor shall:" become one row per item. Repeated sentences are merged.
      • Leaves out: the buyer's own duties ("the County will evaluate...").
      • Not decided: whether you can meet a requirement, whether a requirement is reasonable or lawful, evaluation weighting, or anything in a table, image or attachment you did not paste. Read the solicitation and every addendum.

      Prefer the command line? node cli.mjs rfp.txt --format csv > matrix.csv runs the same code on your own machine (see the README in the repository). Teams can also deploy their own copy with an API and an optional AI pass that splits compound requirements, using their own keys.

      Common questions

      What is an RFP compliance matrix?

      A compliance matrix is a table with one row per requirement in a solicitation: where the requirement appears, what it says, who answers it, where in the proposal it is answered, and whether it is done. Proposal managers use it to make sure no shall or must statement goes unanswered, because a missed mandatory requirement can make a proposal non-responsive.

      How does the generator find the requirements?

      It splits the pasted text into sentences, keeps the section number each sits under, and flags sentences with shall, must, is required to, will (when the contractor is the subject) and similar wording. It separates prohibitions (shall not), desirables (should) and the buyer's own duties (the County will). A lead-in such as The Contractor shall followed by a list becomes one row per list item.

      Is it as good as reading the RFP?

      No. It is a first pass that saves the typing. A sentence can contain two obligations, and requirements can hide in tables, figures and attachments that were not pasted. Read the whole solicitation and every addendum yourself, and check the matrix against it.

      Is my RFP uploaded anywhere?

      No. The extraction runs in your browser and nothing is sent to a server. There is also a command-line version that runs on your own machine.
