      Want this as a gate before you apply?

      Same engine, zero dependencies, one file. Fails the job when the estimated monthly delta is above a number you choose:

      terraform plan -out=tfplan && terraform show -json tfplan > plan.json
node cli.mjs estimate plan.json                          # report only
node cli.mjs estimate plan.json --max-delta 200          # exit 1 if it adds more than $200/month
node cli.mjs estimate plan.json --region eu-west-1 --json

      Get cli.mjs and engine.mjs — Node 18+, nothing to install, no network call, ever. Exit codes: 0 within budget, 1 over budget, 2 unreadable file or bad option.

      What it prices, and what it does not

      Priced: EC2 instances (with root and extra EBS volumes), EBS volumes, RDS and Aurora instances, NAT gateways, ALB/NLB/classic load balancers, Elastic IPs, EKS control planes and node groups, ElastiCache, provisioned DynamoDB, and CloudWatch alarms and dashboards. Named as usage-based and not estimated: S3, Lambda, on-demand DynamoDB, log groups and a few more. Everything else is listed as unpriced. Comparing it with the paid, multi-cloud tool?       Common questions

      Already applied it and the bill moved? Explain the change from a Cost Explorer export with the AWS Bill Change Explainer.

      Is this an Infracost alternative?

      For one narrow job, yes: paste the JSON from terraform show -json and get an approximate monthly cost delta for the common AWS resources, with no signup, no API key and no upload. Infracost covers more clouds and uses live pricing, so it is the better tool if you need that; this is the zero-setup, offline option. See the comparison page.

      How accurate is the estimate?

      It is an approximation, not a quote. It uses a small bundled table of rounded us-east-1 on-demand list prices (dated on the page and in every report), scaled by a rough regional multiplier. It does not know your discounts, savings plans, reserved instances, spot usage or free tier, and it does not estimate usage-based charges such as data transfer, S3 storage, Lambda invocations or log ingestion.

      What happens to resources it cannot price?

      They are listed under unpriced with the reason, and the summary says the figure is not the full change. Nothing unpriced is silently counted as zero. Usage-based resources such as S3 buckets and Lambda functions are named separately.

      Is my plan uploaded anywhere?

      No. The page reads a pasted or locally loaded file in your browser and makes no network request. The CLI reads a local file and makes no network call.

      Can I fail CI when a change costs too much?

      Yes. The CLI takes --max-delta USD and exits 1 when the estimated monthly delta is above it, so it can sit between terraform plan and terraform apply. Resources it cannot price are excluded from the number the gate sees, and the output warns when that happened.

      Which file does it need?

      The structured plan JSON: terraform plan -out=tfplan && terraform show -json tfplan > plan.json. Not the text output and not the terraform plan -json stream.
