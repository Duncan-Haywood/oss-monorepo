This calculator vs. the AWS Pricing Calculator

AWS publishes its own free estimation tool, the AWS Pricing Calculator, at calculator.aws, with background and FAQs at aws.amazon.com/aws-cost-management/aws-pricing-calculator/faqs. You pick a service such as S3, a region, a storage class, and expected usage, and it prices that configuration against AWS's own published rate card, either as a one-off workload estimate or a full consolidated bill.

That makes it the right tool for one job: what a specific AWS configuration will cost, on AWS's current published prices. It reads AWS's own price list, so it is authoritative in a way no third-party page, including this one, can be. This site does not publish AWS's current per-GB rates or claim to, and it prices only AWS services -- it has no notion of a non-AWS provider's rate card, because there is no "other cloud" line item to select. If you need a current AWS estimate, that is the tool to open, and this page says so.

QuestionWhere to answer it
What will this exact AWS S3 configuration cost this month, on AWS's current price list? AWS's own Pricing Calculator — it is the live source.
Given the two rate sheets I was actually quoted, which one is cheaper for my workload? This calculator — storage, requests, and egress on one screen, from the numbers you paste in.
At what outbound-transfer volume does the cheaper-storage option stop winning? This calculator's break-even outbound volume.
Does a CDN, a same-region replica, or infrequent-access storage still beat the alternative on this workload? This calculator's linked follow-on pages, back on the calculator.

This calculator is deliberately provider-agnostic: it never fetches or stores a published price for AWS, another cloud provider, or anyone else. Every rate is one you type in, so it stays correct when a price sheet changes and works equally well for an AWS-to-AWS storage-class comparison, an AWS-versus-another-provider comparison, or a proposed price increase from your current vendor.

It needs no AWS account and no sign-in: it is a static page, the arithmetic runs in your browser, and once it has loaded it keeps working with the connection off. Nothing you type is uploaded anywhere.

Common questions

Should I use this calculator or AWS's own Pricing Calculator?

Most people get more use out of both. AWS's own Pricing Calculator, at calculator.aws, is the authoritative source for what a specific AWS service configuration will cost, because it reads AWS's live published price list for the region and options you select. This page does not try to replace that lookup. What it adds is the decision AWS's tool is not built for: comparing two price sheets you already have — AWS against another provider, one storage class against another, or last year's rate against a new quote — on the same storage-plus-request-plus-egress workload, with the outbound-transfer volume where the cheaper-storage option stops being cheaper.
