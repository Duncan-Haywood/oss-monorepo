Is your affiliate disclosure missing, or just too late?

Paste a blog post or page's HTML and see every affiliate link it recognises — an Amazon Associates tag= link, an amzn.to short link, rel="sponsored", or a known network's tracking link (ShareASale, CJ, Impact, Skimlinks, AWIN, and similar) — and whether a disclosure phrase appears before the first one, the way the FTC's Endorsement Guides call for. Separately, it checks whether any Amazon link carries Amazon's own required exact statement — a generic "affiliate links" note is not enough for Amazon specifically, and Amazon has terminated associate accounts over exactly this gap.

Nothing is uploaded. The text box is parsed in this browser and never leaves your device. This is a fact-check, not a compliance determination: it names what it found, not whether you are safe from the FTC or from Amazon.

Common questions

Why does this matter for Amazon Associates specifically?

Amazon's Associates Program Operating Agreement requires every page carrying an Associates link to state, in substance, "As an Amazon Associate I earn from qualifying purchases." Amazon has terminated associate accounts for missing this, which removes the account's entire earning history, not just future commissions — so a missing disclosure is a real, checkable income risk, not a hypothetical one.

Is a generic "affiliate links" disclosure enough for an Amazon link?

Not for Amazon specifically. The FTC's Endorsement Guides ask for a clear and conspicuous disclosure in general, which a generic phrase like "this post contains affiliate links" can satisfy — but Amazon's own operating agreement additionally requires its specific exact statement, so this tool checks the two separately and flags an Amazon link that has some disclosure but not Amazon's own required wording.

Does this tell me whether I am FTC or Amazon compliant?

No. It reports which affiliate-link signals and which disclosure phrases it found, and their order on the page — facts about the text, not a legal or contractual determination. Read the FTC's Endorsement Guides and Amazon's own Associates Program Operating Agreement, and consult a professional if you need a determination you can rely on.

Is my content uploaded anywhere?

No. The browser page parses the HTML you paste entirely in your own browser and never sends it anywhere. The CLI reads only local files — no network call, ever.
