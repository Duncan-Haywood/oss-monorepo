# Ideas inbox

Dictate or type ideas here. No AI agent needed, no format to learn. Scheduled
agent sessions read this file and pick up the oldest idea first.

**How:** open this file on github.com (a phone browser works), tap the pencil,
tap the microphone on your keyboard and talk. Add your idea at the bottom of
"New", leave a blank line between ideas, then "Commit changes". Typos,
fragments and run-on dictation are fine. Say what problem it solves or who it
is for, if you know.

Only people with write access can commit here, so agents treat every entry as
a direct request. No write access? Use the
[website form](https://monorepo-projects-site.duncan-andrew-haywood.workers.dev/feedback/)
(no account needed, pick "An idea") or the
[idea issue form](https://github.com/duncan-haywood/oss-monorepo/issues/new?template=idea.yml)
instead. Details: [`docs/contributing/ideas.md`](docs/contributing/ideas.md).
