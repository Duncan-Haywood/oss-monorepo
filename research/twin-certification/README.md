# Can a digital twin shorten a real-world safety certification? Exact size of a twin-informed failure-rate test

Pure Python, no dependencies. A controller is tested for `n` real trials, `k` fail, and we certify "real failure probability `p < ε`" if `k ≤ c`. Because `k ~ Bin(n,p)` is monotone in `p`, the worst-case false-certification probability of any such rule is exactly `P(Bin(n,ε) ≤ c)`, and by Karlin–Rubin the exact (Clopper–Pearson) threshold is the most powerful valid one, so **a twin used as a prior cannot cut the real trials needed at a fixed worst-case level**. It can only raise `c`, which raises the size by exactly a binomial-CDF step. Results, all from `experiments/results.txt` (ε = 0.01, δ = 0.05, twin data 2 failures in 20000 rollouts, i.e. it claims `p = ε/100`, discounted to weight `w` real trials per rollout): the exact zero-failure test needs 299 trials; a Jeffreys credible-bound rule (no twin) already has worst-case size 0.147 at its 191-trial "zero-failure" point; twin priors at `w = 0.003` give 133 trials at size 0.263, and at `w = 0.01` the prior certifies with no real data at all. Held to the same worst-case size, the exact test needs the same `n` as the twin rule (1116 vs 1116 for Jeffreys, 1057 vs 1057 for `w = 0.003`; 1441 at the nominal 0.05), so the apparent saving is a change of level. A wrong twin is not symmetric: an optimistic one inflates size (0.237 at `n = 400` for claims ≤ ε/10), a pessimistic one (claim 2ε) makes the rule refuse to certify at any `k` (power 0), and the largest twin weight that keeps the worst-case size within 0.06 is `w = 0.0046` (91.6 twin-trial equivalents) at `n = 299`, falling to 52 at `n = 500`. See `paper/whitepaper.md`.

```bash
cd research/twin-certification
PYTHONPATH=src python3 -m unittest discover -s tests -v   # 11 tests, <1 s
PYTHONPATH=src python3 experiments/run.py                 # seconds; output in experiments/results.txt
```

**Builds on.** The safe-autonomy-with-verification direction of RECUV (<https://www.colorado.edu/recuv/>) and the simulation-based validation of field robots by the Autonomous Systems IRT (<https://www.colorado.edu/irt/autonomous-systems/>); no specific paper from either is reproduced and nothing here is affiliated with or endorsed by them. Statistics: Clopper & Pearson (1934), Karlin & Rubin (1956), Brown, Cai & DasGupta (2001) on binomial intervals, and the power prior of Ibrahim & Chen (2000) for discounting historical (here, simulated) data. Companion to the twin projects `twin-transfer`, `twin-audit`. Black-box safety validation background: Corso et al. (2021).

Stylised: one Bernoulli failure probability, i.i.d. real trials, a twin summarised by failure counts (no importance sampling, no continuous scores or control variates, which can help beyond the level-matched limit shown here), chosen ε, δ and twin claims, no real robot or trial data. MIT.
