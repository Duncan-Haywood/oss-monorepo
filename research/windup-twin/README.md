# Windup twin: a twin with an unlimited actuator says a PI loop's step response is independent of step size, what does the real loop with a command limit do?

Pure Python, no dependencies. Real plant `x' = sat_U(u) + d` (a velocity-commanded axis with bounded command and constant load `d`), PI control `u = −kp x − ki z`, `z' = x`, `kp = 2ζωn`, `ki = ωn²`. Twin: no saturation, `d = 0`, closed loop `s² + kp s + ki`, stable for every positive gain, whose normalised step response does not depend on the step size. Results (all from `experiments/results.txt`, ζ = 0.7, U = 1): (1) the twin is *exact* while the largest command `kp·x0 ≤ U` (max deviation 0 to machine precision for x0 ≤ 0.7143) and wrong beyond it (deviation 6·10⁻⁵ at x0 = 0.72, 0.084 at x0 = 1, 0.44 at x0 = 2), so a twin validated with gentle steps passes; (2) beyond it the integrator winds up: its peak value is exactly `x0²/(2U)` (12.5, 50, 200, 1250 at x0 = 5, 10, 20, 50), overshoot rises from the twin's 21% to 74% (x0 = 5), 87% (10), 93% (20), 97% (50) and the 2% settling time from 4.9 to 16.7, 48.6, 164.6, 944.5; the exit time and integrator value at the end of the saturated phase follow a closed form that matches simulation to 4–5 digits; (3) a constant load `d` is rejected only if `d < U`: settling time at x0 = 5 is 16.7, 25.0, 54.7, 105, 214, 1064 for d/U = 0, 0.5, 0.8, 0.9, 0.95, 0.99 and the loop never settles for d ≥ U, where the twin (d = 0) promises 4.9; (4) "faster is better" fails: for x0 = 5 the twin's settling time falls 19.5 → 0.61 as ωn goes 0.25 → 8, while the real one is best near ωn = 1 (16.7) on this grid and rises to 76.6 at ωn = 8; (5) conditional-integration clamping removes most of the damage (settling time 4.9–7.6 for ωn ≥ 1 against 17–77, overshoot ≤ 3%). Stylised: linear PI on a single integrator, one static command limit, noiseless; see `paper/whitepaper.md`.

```bash
cd research/windup-twin
PYTHONPATH=src python3 -m unittest discover -s tests -v   # 7 tests, about 4 s

```

**Builds on.** The digital-twin simulation-fidelity and sim-to-real direction of ARPG (<https://arpg.colorado.edu/>), HIRO Group (<https://hiro-group.ronc.one/>, manipulation) and the Autonomous Systems IRT (<https://www.colorado.edu/irt/autonomous-systems/>) and RECUV (<https://www.colorado.edu/recuv/>, UAV and field-robot simulation); no specific paper from those groups is reproduced and nothing here is affiliated with or endorsed by them. Integrator windup and anti-windup are classical (Åström & Murray 2008; Åström & Rundqwist 1989). Companion to `saturation-twin` (saturation of an unstable plant under noise), `slew-twin`, `lag-twin` and `control-twin` in this repository.

Stylised: one integrator plant, PI loop, simulated "real" system, no field data. MIT.
