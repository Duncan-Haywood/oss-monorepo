Module `seq_1011(input clk, input rst, input x, output hit)`. Synchronous active-high reset, rising-edge clock. Detects the serial pattern 1,0,1,1 (oldest bit first) on `x`, overlapping matches allowed (e.g. 1011011 gives two hits). `hit` is a Mealy output: it is 1 combinationally in the cycle where the current `x` completes the pattern (the last three previously sampled bits were 1,0,1 and `x` is 1). After reset no history is held.
