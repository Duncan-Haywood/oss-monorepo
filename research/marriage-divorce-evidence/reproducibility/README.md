# Original U.S. marriage/divorce microdata analysis

Prepared October 19, 2026. These are original respondent-level calculations, not copied published statistics.

The [local report](http://127.0.0.1:4173/) is the narrative deliverable. Its source lives in the sibling `report-app` folder; scientific PNG/SVG figures live in sibling `figures`. `Report.html` in the outputs folder is the portable offline export of that same report.

## Reproduce

Requires Python 3.11+ and internet for full-raw re-extraction. A standard environment can be prepared with:

```sh
python3 -m venv .venv
. .venv/bin/activate
python3 -m pip install -r requirements.txt
sh run_all.sh
```

The full rerun downloads about 1GB if the original ACS/NLSY archives are absent, streams the 6.7GB uncompressed NLSY CSV without saving it, and recomputes all outputs. Allow several minutes and sufficient disk space. Run source scripts individually to reproduce only that source. For NSFG, `sh nsfg/download.sh` reacquires original official inputs; included raw data suffice without a network connection.

To rerun only ACS models or NLSY calculations from the delivered compact datasets:

```sh
python3 model_acs.py
python3 acs/degree_contrasts.py
python3 acs/sensitivity_acs.py
python3 longitudinal/analyze_nlsy79.py
```

`python3 assemble_report.py` rebuilds the reviewed report snapshot from CSVs, keeping the report artifact ID. To compile the editable report UI on a Codex installation with the Data plugin, follow `../report-app/AGENTS.md`; the installed `data-app.mjs build --project-dir ... --separate-data` helper is needed. This UI dependency is independent of the Python analyses: CSV results, dataset documentation and static figures remain usable without it. `plot_results.py` regenerates standalone PNG/SVG figures; copied app image assets should be refreshed before rebuilding.

`run_all.sh` intentionally regenerates the report as `creating`; after reviewing new results, set `buildStatus` to `complete` and rebuild. Reproducibility does not mean conclusions should be blindly retained after a source changes.

## What the estimates mean

- **ACS:** past-12-month divorce reports per ever-married adult, and separately current divorced marital-status prevalence. Neither is cumulative divorce risk. Age-standardized estimates and all 80-replicate CIs are included. The income and employment models adjust separately for age, education and race/ethnicity; odds ratios are not risk ratios.
- **NSFG:** historical first-marriage divorce/annulment/separation prevalence by interview among ever-married ages 25–49. Taylor-design 95% CIs use 18 strata/72PSUs. Separate legal-divorce/annulment-only results, current attendance, family income/employment and female-reported first-husband education pairings are included. Age adjustment does not align marriage duration. The approximate grouped 4-year KM output is exploratory and excluded from conclusions.
- **NLSY79:** recorded cumulative occurrence of any legal divorce through 2022/23 among retained ever-married respondents from the 1957–1964 birth cohort. **CIs are weight-only approximations, not full complex-survey CIs.** Missing waves can conceal divorce. Latest education may postdate divorce. The prospective supplement uses 1999 family income/hours, marriage in 2000 and divorce-transition records in 2002–2022, conditional on retention.

No dataset identifies a causal effect of salary, religion or degree on divorce. Do not multiply associations into individual risk predictions. Exact master’s/PhD/professional spouse-pair risks cannot be recovered; NSFG first husbands’ graduate/professional category is combined. PSID was not analyzed because its official download portal requires free registration.

## Validation

Official parsing counts and routing checked; matched-replicate degree contrasts; independent optimization reproduced four ACS model coefficient vectors within 1.4e−9; NSFG age-standardization influence derivatives checked numerically; allocated-response and missing-wave sensitivity results retained. See source-specific audit/review files. These checks do not establish causality or remove all measurement/selection bias.

## Annual profile extension

The report now begins with jointly adjusted annual comparisons and supported profiles. New folders:

- `annual_acs/`: joint models under both denominator choices, formal standardized contrasts, preset profiles and observed support. `first_marriage/` adds coarse age-at-marriage and duration controls while excluding newlyweds and remarriages. Full80 replicate fits. `independent_checks.json` independently verifies coefficients and profile arithmetic.
- `annual_nlsy/legally_married_primary/`: legal-divorce incidence per1,000 observed person-years, including married/separated baselines and predictors measured before follow-up. The root-folder annual NLSY outputs are a married-only sensitivity. Both state-adjusted and non-state-adjusted models are retained. Intervals cluster by respondent and use baseline-wave weights; they do **not** account for full survey PSU/stratum design.
- `annual_nsfg/feasibility.md`: why current public NSFG dates/covariates were not forced into artificial annual hazards.
- `Annual_Profiles.ipynb`: executed results and independent validation companion, including two scientific figures. Requires Python with `nbformat`, `nbclient`, `ipykernel` to re-execute; ordinary analysis scripts do not require Jupyter.

Run `sh run_annual.sh` to recompute the extension from delivered analytical datasets. It updates the same report snapshot and copied figure assets; rebuild the report app afterward using its `AGENTS.md`. Full raw re-extraction is optional via `annual_nlsy/extract_annual_nlsy.py` (downloads official NLSY archive if absent). To regenerate the entire report after `run_all.sh`, run `run_annual.sh` last so the earlier assembly does not replace the annual extension.

The annual results **do not confirm a universal optimal spouse profile**. Recent ACS profiles are contemporaneous, and prospective older-cohort estimates sometimes differ. Specifically, prospective attendance is not clearly protective, and graduate education among women does not show the same association as in recent ACS. Already-separated status is a strong immediate marker of legal divorce, not a causal lever. Low observed divorce in nonworking/zero-income cells is not evidence that reducing income or quitting work would prevent divorce. See the updated report for estimates and limitations.

Run `python3 couple_profiles/analyze_couple_profiles.py` then `python3 couple_profiles/verify_couple_profiles.py`. This uses the delivered interval input; see couple_profiles/METHODS.md for reconstruction, controls, common target, fixed schooling mixture and limitations. ## Duration, conditional matching and milestones

Run the folder-specific analyze/verify scripts in duration_nlsy, conditional_pairing and milestones_nlsy; see their METHODS.md for source data, design and limitations. Duration_and_Matching.ipynb is an executed results-and-validation companion. The report increments are integrate_duration_matching.py and integrate_milestones.py, applied after the earlier couple-profile assembly. Full original NLSY79 archive extraction remains optional when delivered compact inputs are used. Conditional matching tests retain every respondent in one held-out fold, avoiding repeated-person leakage.
