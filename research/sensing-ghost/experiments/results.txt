# sensing-ghost: burst merging with a moving subject (synthetic scenes, Poisson-Gaussian noise)
48x48 px scenes, 16 scenes per cell, still camera, one bright disc (radius 4 px) moving along x at v px per frame.
A = 4 (large/small pixel area), read = 3 e-, P = 300 e- per unit radiance in one large frame (small frame: 75).
Truth = noise-free frame 0 (reference frame). PSNR is display-referred (gamma 1/2.2, scene peak 1), border cropped.
all = every interior pixel; static = pixels the disc never comes within 2 px of; trail = pixels it touches in any frame (within 1 px).
The large frame is one exposure of the same duration as ONE small frame, so its object is frozen at the frame-0 position.
