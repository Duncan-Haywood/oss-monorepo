Module `rr_arb4`: inputs `clk`, `rst` (synchronous, active high), `[3:0] req`; output `[3:0] gnt` (combinational from the current state and `req`). Round-robin arbiter. State: `last`, the index (0..3) of the most recently granted requester, 3 after reset. Each cycle, if any request is set, `gnt` is one-hot at the first set bit of `req` found by scanning indices last+1, last+2, last+3, last (mod 4) in that order; otherwise `gnt` is 0. At the rising clock edge, if `gnt` is non-zero then `last` becomes the index of the granted bit; otherwise `last` holds.
