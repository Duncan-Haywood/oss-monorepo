Module `satcnt4`: inputs `clk`, `rst`, `en`, `dec`; output `[3:0] q` (a register output). On each rising edge of `clk`: if `rst` is 1, `q` becomes 0; otherwise, if `en` is 1, `q` counts down by one when `dec` is 1 and up by one when `dec` is 0, saturating at 0 (no wrap below) and at 15 (no wrap above); if `en` is 0, `q` holds. `rst` is synchronous. `q` is 0 at the first clock edge only after `rst`; no initial value is specified.
