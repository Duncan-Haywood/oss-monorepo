Do the agent run records match git? Does every landed session leave one?

research/swe-reccover

Do the agent run records match git? All 522 records naming a pull request in this repository name one that landed, but only 79.8% of sessions landing commits from 13 October have a record (ventures 79.2%, research 92.2%; preliminary, seven days).

9 tests

What it found

Checks the run records against the commit history on main. All 522 records that name a pull request in this repository name one that landed (Wilson 95% 99.3–100%). But only 79.8% of sessions that landed commits from 13 October have a record (1,465 of 1,836; 77.9–81.6%): 89.8% of sessions that followed the master prompt, 4.2% of those that did not, and by track research 92.2%, process 93.2%, red team 100% and ventures 79.2% (75.5–82.5%). Coverage rose from about 60% on 13–14 October to 82–88% afterwards. Preliminary: seven days; sessions are identified by a commit trailer, so sessions without one are invisible; landed is a git fact, not a quality one.
