# data

`AEP_hourly.csv`: hourly load (MW) of the American Electric Power zone in PJM, 2004-12 to 2018-01.
PJM Interconnection publishes this through Data Miner 2; this copy is the widely mirrored
Kaggle "Hourly Energy Consumption" extract (Rob Mulla, CC0), fetched from a public GitHub
mirror (bryangoodrich/python-exercises, commit dad19f5). Only the shape (load / yearly peak) is used.
