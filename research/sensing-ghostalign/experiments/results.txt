# sensing-ghostalign: motion-compensated burst merging of a moving subject (synthetic, Poisson-Gaussian noise)
48x48 px scenes, 16 scenes per cell, still camera, one bright disc (radius 4 px) moving along x at v px per frame.
A = 4, read = 3 e-, P = 300 e- per unit radiance in one large frame (small frame: 75). Truth = noise-free frame 0.
Display PSNR (gamma 1/2.2, peak 1), border cropped. all = interior; static = never within 2 px of the subject; trail = any touched pixel (+1 px);
obj0 = the subject's footprint in frame 0 (+1 px). Alignment: per-pixel search, dy +-2 px, dx +-(0.5+v*i+0.5) px, 0.5 px steps, 9x9 window, margin 40 chi-square units.
The horizontal search bound uses the true speed v (an oracle); section D relaxes it.
