## 2026-11-13 · Milestone 4f planned: does the jackknife stop overstating f's spread once the view set leaves the critical region?

Written while the milestone-4f solves ran, before any of them was analysed. Milestone 4e found, post hoc, that f's spread per view falls 2–5× between 3 and 5 views and then roughly follows 1/n. It guessed that the same effect is why the leave-one-view-out jackknife overstated the real set-to-set spread of 7-view sets (1.8× and 2.3× on 5×5 corners): deleting one view from a small set lands near the critical set, so a few delete-one solves swing far and inflate the variance. If the guess is right, the overstatement should shrink as the old set grows, and a robot that logs about 10 views could use the jackknife as it is. Here every subset of 3 to 12 of the 13 views is solved on each camera (8,086 per camera, `experiments/m4f_setsize/run.py`; milestones 4d and 4e's 5×5 solves reused), on 5×5 corners only (milestone 6b's unbiased localiser), with milestone 4b's solver, reference views and start.

- **Quantities** (per camera, relative to the all-view f<sub>13</sub>, converged solves only):
  - real sd, disjoint pairs (DP), n = 3..6: √(mean d²/2) over every unordered pair of disjoint n-view sets, d = (f<sub>A</sub> − f<sub>B</sub>)/f<sub>13</sub>. Model-free; needs 2n ≤ 13.
  - real sd, around all views (A13), any n: √(mean (f<sub>S</sub> − f<sub>13</sub>)² / (1 − n/13)) over every n-view set S. Exact if each view adds an independent offset (then var(f<sub>S</sub> − f<sub>13</sub>) = var(f<sub>S</sub>)(1 − n/13)); the only real reference above 6 views.
  - jackknife J(n) = √(mean v<sub>J</sub>) over n-view sets with all n delete-one solves converged, v<sub>J</sub> = (n−1)/n Σ(f<sub>i</sub> − f̄)²/f<sub>13</sub>² (milestone 4b's `jackknife_cov`, f entry).
  - reported R(n) = √(mean σ<sub>f</sub>²)/f<sub>13</sub> (the solver's own covariance).
  - ratio ρ<sub>J</sub>(n) = J(n)/real(n); reference DP for n ≤ 6 where stated, A13 otherwise.
- **H48 (overstatement falls with set size).** On each camera ρ<sub>J</sub>(4) > ρ<sub>J</sub>(6) against DP, and the Spearman correlation of ρ<sub>J</sub>(n) (A13) with n over n = 4..10 is ≤ −0.8. Refuted if either fails on either camera.
- **H49 (honest from about 8 views).** ρ<sub>J</sub>(n) (A13) lies in 0.67–1.5 for each of n = 8, 9, 10 on both cameras. Refuted if any falls outside.
- **H50 (the independent-offset model holds where it can be checked).** At n = 4, 5, 6, A13 over DP lies in 0.8–1.25 on both cameras. Refuted otherwise (and then H48's and H49's A13 reference is suspect above 6 views).
- **H51 (the solver's σ stays small at every size).** R(n)/real(n) (A13) ≤ 0.67 for every n = 4..10 on both cameras (milestone 1: about 2× small on 13 views). Refuted if any exceeds.
- **Reported, unscored.** n = 3, 11, 12; robust versions (1.4826 MAD for the real spread, median v<sub>J</sub> for the jackknife); convergence counts per n; a leave-one-view-out sensitivity (each ratio recomputed with every set holding view v dropped, for each of the 13 v; min–max reported).
- **Caveat set in advance.** All sets are drawn from the same 13 views and overlap heavily, so the per-n figures are far from independent and carry no honest interval beyond the leave-one-view-out range. The A13 reference at n ≥ 11 divides by 1 − n/13 ≤ 0.15 and is too noisy to score. 5×5 corners only: the other localisers carry a bias (milestone 6b) that adds a shared offset to every set.

## 2026-11-13 · Milestone 4e result: a threshold from the old set's own 4 + 3 split-halves is quiet but deaf, because f's spread does not shrink as 1/n below 5 views

- **Runs.** 3,168 new solves (every 3- and 4-view subset of the 13 views not already stored, × 3 localisers × 2 cameras), all with the milestone-4b solver; merged with milestones 4b and 4d, every one of the 171 old sets per camera and localiser had all 35 partitions usable. 14,040 decisions scored with milestone 4c's `score()`, unchanged, none left undecided.
- **H43 held.** z<sub>H</sub>² against F<sub>1,6</sub>, 5×5 corners, S0, k ≥ 4: 0.6% (left, 95% 0.1–3.1%) and 0.0% (right) false alarms.
- **H44 refuted.** ±2% at k = 6 pooled: 0.8% (0.2–3.0%), against 61% for the borrowed threshold. Against χ²<sub>1</sub> it is still only 4.2%; ±4% is caught in 7–9% (F) and 27–31% (χ²<sub>1</sub>).
- **H45 refuted.** Real sd of (f<sub>new</sub> − f<sub>old</sub>)/f<sub>old</sub> at k = 6 over predicted: 0.67% / 1.94% = 0.34 (left), 0.50% / 2.62% = 0.19 (right). The split-half scale overstates the spread 2.9× and 5.2×, more than the jackknife did (1.8× / 2.3×).
- **H46 refuted.** S0 99th percentiles of z<sub>H</sub>²: 5.34 (left) against 1.24 (right), a factor 4.3.
- **H47 held.** Harmful adoptions 0.02% of 4,680 decisions, because the test almost never fires.
- **Unscored.** Median τ̂ per view (5×5): 2.98% left, 3.96% right (11×11 3.23 / 6.48%, SB 4.30 / 5.11%). On 11×11 and SB corners the picture is the same: scale ratio 0.46 / 0.22 and 0.33 / 0.25, ±2% detected in 0–2%. The unit swap is invisible to f alone (0.0%); the union with W against χ²<sub>3</sub> is W alone (79.4% swap, 1.9% false alarms).
- **Why, post hoc (computed after H45 failed).** The robust sd (1.4826 MAD) of each subset's f around the all-view f, divided by √(1/n − 1/13) (the part of the gap a subset's own views make if each view adds an independent offset), should be the same at every n. On 5×5 corners it is 3.29% / 5.21% per view at 3 views, 2.15% / 2.17% at 4, 1.68% / 1.35% at 5, 1.67% / 1.04% at 6 and 1.55% / 0.95% at 7 (left / right); the update spread at k = 6 implies 1.20% / 0.91%. Below 5 views the halves sit near the critical set, where milestone 2 found the error grows fastest, so a 3-view half carries 2–5× the per-view spread a 6- or 7-view set does. 1/n holds roughly from 5 views up.
- **Reading.** Two of five predictions held, and both only because the test is silent. A per-unit scale from the old calibration's own views is the right idea for the threshold not to travel between units, but it needs halves in the regime where 1/n holds: at least 5 views each, so about 10 views in the old set, or halves of an old set enlarged by views a robot logs during normal operation. With 7 views, the borrowed or pooled threshold remains the only usable f-alone test. It may also be part of why milestone 3 found the jackknife very conservative at 4 views (deleting one view from a small set lands near the critical set); that was not tested here.
- **Caveat.** The 35 partitions of 7 views are dependent, and the 13 views are shared by every split, so the intervals are too narrow; the post hoc per-view figures use subsets that overlap one another heavily.

## 2026-11-13 · Milestone 4e planned: a threshold from the old calibration's own views, with no sibling unit

Written before any milestone-4e solve was run. Milestone 4d's f-alone update test caught a 2% focal change in 61% of splits on unbiased 5×5 corners, but its threshold was borrowed from the other camera, and it no longer travelled: 11.1% false alarms on the left camera, because the jackknife overstates the real set-to-set spread by different amounts on the two cameras (1.5× and 2.8×). The paper draft names a per-unit tail estimate as what a submission needs. Here the scale comes from the old set itself, which a robot always has: each old set of 7 views is split into 4 + 3 views in all 35 ways, and the spread of the two halves' focal lengths, scaled by 1/n, predicts the spread between the old set and a new set of k views. Nothing is borrowed from another unit and the new views are never used to set the threshold.

- **Solves.** Every 3- and 4-view subset of the 13 views (1,001 per camera) that milestones 4b and 4d did not already solve, on all three localisers (`experiments/m4e_selfscale/run.py`: the same solver, k<sub>1</sub> model, reference views and start).
- **Statistic.** For an old set O and each partition (A, B) with both halves converged, r = (f<sub>A</sub> − f<sub>B</sub>)/f<sub>O</sub>. The per-view scale is τ̂² = median(r²) / 0.45494 / (1/4 + 1/3) (the median of χ²<sub>1</sub> makes it robust to a near-critical half). Predicted variance of the relative update v = τ̂²(1/7 + 1/k), and z<sub>H</sub>² = ((f<sub>new</sub> − f<sub>old</sub>)/f<sub>old</sub>)² / v. A decision needs at least 20 of the 35 partitions converged. Splits, disturbances (S1 focal change, S0 unchanged, S2 principal-point shift, S3 unit swap, where the old set and so its scale come from the other camera), k ≥ 4 scoring and the adoption rule are milestone 4c's.
- **Reference.** Primary: F<sub>1,6</sub> at 1% (13.75), since τ̂ rests on 7 views. Secondary, also scored: χ²<sub>1</sub> (6.63).
- **H43 (quiet with nothing borrowed).** On 5×5 corners, z<sub>H</sub>² against F<sub>1,6</sub>: S0 false alarms (k ≥ 4) ≤ 3% on each camera. Refuted if above on either (the borrowed threshold: 11.1% left).
- **H44 (power kept).** On 5×5 corners, F<sub>1,6</sub>: a ±2% focal change at k = 6, pooled over sign and camera, detected in ≥ 40% of splits (borrowed threshold 61%). Refuted below.
- **H45 (the scale is right).** On 5×5 corners, S0, k = 6: the real standard deviation of (f<sub>new</sub> − f<sub>old</sub>)/f<sub>old</sub> about each camera's mean, divided by the root mean predicted v, lies within 0.67–1.5 on both cameras (the jackknife: 0.67/1.23 = 0.54 and 0.51/1.17 = 0.44). Refuted outside on either.
- **H46 (the tail travels).** On 5×5 corners, the two cameras' S0 99th percentiles of z<sub>H</sub>² (k ≥ 4) are within a factor of 2 of each other (jackknife z<sub>f</sub>²: 3.56 against 1.03, 3.5×). Refuted otherwise.
- **H47 (no harm).** On 5×5 corners, F<sub>1,6</sub>: harmful adoptions over all scenarios (k ≥ 4) ≤ 1.5% (borrowed threshold 1.3%). Refuted above.
- **Reported, unscored.** The same on 11×11 and SB corners; χ²<sub>1</sub>; ±1% and ±4%; the principal-point shift and the unit swap; a union with milestone 4b's W against χ²<sub>3</sub> for the principal point; comparisons with the borrowed (E<sub>1</sub>) and oracle thresholds.
- **Caveat set in advance.** The 1/n scaling assumes each view adds an independent offset; 3- and 4-view halves sit nearer the critical set than 7-view sets, which would inflate τ̂ and make the test conservative. The 35 partitions of 7 views are not independent, and the splits reuse 13 views, so the intervals are too narrow.

## 2026-11-11 · Milestone 3 planned: is the 2× overconfidence real, and does a cluster-robust σ fix it?

Written before any milestone-3 experiment was run. The proposal's milestone 3 (natural features on a second data set) moves to 3b; this step answers the question milestone 2 left open, on the same 560 subsets, with no new data.

- **Why σ could be too small.** The Gauss–Newton σ assumes independent, equal-variance pixel residuals and a correct model. Corner-detector errors are correlated within an image (blur, lighting, the detector's shared sub-pixel window) and the k1-only lens leaves structured residuals. Both make the reported σ too small by a factor that differs between subsets, which a single inflation factor cannot follow (milestone 2's cross-camera κ).
- **Robust σ, two estimators, no fitted constants.** (a) The cluster-robust sandwich, clustered by view: var f = Σ_views ((J b)·r)² over each view's residuals, with b = (JᵀJ)⁻¹e_f, times the small-sample factor G/(G − 1). (b) The leave-one-view-out jackknife: re-solve the subset k times without one view each (cold start, same solver), var f = (k − 1)/k Σ (f₍ᵢ₎ − f̄)². Ablation: the sandwich clustered by corner (54 clusters) and unclustered (HC0).
- **H8 (the reference is not the cause).** Zhang's all-view f is itself 0.8 / 1.3 px from the target-free all-view f, so part of milestone 2's z could be reference mismatch. Self-consistency test against the target-free all-view solution, with the nested-estimator variance: z_n = (f_sub − f_all) / √(σ_sub² − σ_all²), random subsets of 4–12 views (subsets with σ_sub ≤ σ_all are counted and dropped). Predicted: rms z_n > 1.5 (the overconfidence is real). Refuted if ≤ 1.5.
- **H9 (robust σ is honest).** With σ from the jackknife, rms z against all-view Zhang over random 4–12-view subsets lies in [0.7, 1.4] on each camera, with no fitted factor. Scored separately for the view-clustered sandwich; predicted to hold for the jackknife and to fail (rms z > 1.4) for the sandwich at 4–6 views, where few clusters bias it down.
- **H10 (robust σ ranks better).** As a gate statistic for good (|Δf|/f ≤ 1%) against bad (> 2%) updates, pooled over all subsets of 4–12 views and both cameras, the jackknife σ/f has a higher ROC AUC than the reported σ/f. Refuted if it is equal or lower (paired bootstrap over subsets, 95% interval of the AUC difference).
- **H4, second test.** Accept iff σ_jack / f ≤ 0.5% (the same threshold as milestone 2); target 90/90. Also scored on the near-critical subsets alone. And the transfer test from milestone 1's next steps: the threshold on each σ that maximises min(accept good, reject bad) on one camera, scored on the other.
