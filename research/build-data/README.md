# build-data

Research programme (proposal stage), AI-assisted: do open permit feeds predict permit and build duration across cities? See [`PROPOSAL.md`](PROPOSAL.md) and [`LOG.md`](LOG.md). Relates to the construction data warehouse and `ventures/wall-framing-takeoff`. Milestone 1 is done: `src/permits.py` loads Chicago, San Francisco and Austin onto one schema (`datasheets/`, `results/manifest.json`, `results/lags.json`). Reproduce: `python3 src/permits.py pull --out DIR` then `python3 src/describe.py DIR`. Finding so far: the median permit issue lag is 0 days in all three cities, so the target is zero-inflated. No model has been run.
