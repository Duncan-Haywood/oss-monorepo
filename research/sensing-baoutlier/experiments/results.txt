sensing-baoutlier: bundle adjustment with mismatched observations, 6 seeds per cell, 300 features. Synthetic only.
Default cell: 12-view orbit, 0.5 px noise, pose error 0.5 deg and 0.02 radii per axis, 300 function evaluations.
A mismatch replaces an observation by a uniform random pixel in the 640 x 480 image. Robust-loss scale 3 x sigma_px; trim gate 4 x sigma_px + 2 px.
clean_ba = the same adjustment on clean observations (the floor). tri = DLT on all views of the contaminated data. linear/huber/cauchy/trim
start from tri; ri_init = per-point RANSAC pair triangulation (20 px gate), ri_linear/ri_cauchy/ri_trim start from it.
