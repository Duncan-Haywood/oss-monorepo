# civ-seeding research log

## 2026-11-13 · Plan: reproduce the information model's estimate (milestone 1, written before the run)

- Why: every later milestone (complex contagion, identification, seeding policies) is scored against the model Banerjee, Chandrasekhar, Duflo and Jackson (2013) fitted to these 43 villages. If our port of their code does not land on their estimate, nothing built on it can be compared with the paper. Targets, from the NBER working paper w17743 (January 2012), read this session: non-leader take-up 18.5% (SD 8.4%), leader take-up 24.8% (SD 12.5%); information model q<sub>N</sub> = 0.10, q<sub>P</sub> = 0.50, both different from 0 (Table 4, Panel A.1); with q<sub>N</sub> set to 0, take-up falls "from more than 20.2 percent to 13.7 percent" and the informed share "from over 81 percent to 57 percent".
- Data: `data/bcdj_villages.json.gz`, built by `data/build_dataset.py` from the replication archive (doi:10.7910/DVN/U3BIHX, CC0; read from a public GitHub mirror because the Dataverse file sits behind a guestbook form). 43 villages, 9,126 households in giant components, 44,367 ties.
- Method: `src/civ_seeding/bcdj.py` ports `diffusion_model.m`, `moments.m` (version 1, five moments), `divergence_model.m` and the identity-weighted grid criterion of `Main_models_1_3.m`: the same grid (31 q<sub>N</sub> by 39 q<sub>P</sub> values), S = 75 simulations per village, trimesters, beta from a logit of leaders' take-up on the six covariates. Common random numbers across grid points (the Matlab code redraws). Standard errors by the authors' Bayesian bootstrap over villages (exponential weights), B = 1,000.
- H1 (descriptives): non-leader and leader take-up within 0.5 points of 18.5% and 24.8%. Refuted otherwise.
- H2 (estimate): the grid minimiser is within one grid step of (0.10, 0.50): q<sub>N</sub> in {0.05, 0.10, 0.15} and q<sub>P</sub> in {0.45, 0.50, 0.55}. Refuted otherwise.
- H3 (q<sub>P</sub> > q<sub>N</sub>): in at least 95% of bootstrap draws. Refuted otherwise.
- H4 (counterfactual): at our estimate, setting q<sub>N</sub> = 0 cuts simulated take-up by between a quarter and a half (paper: about a third). Refuted otherwise.
- Robustness, reported not tested: three seeds for the common random numbers.
- Caveats written now: the published Science version may report different decimals from the 2012 working paper; we test against the working paper because that is the text we read.
- Outcome (`experiments/m1_reproduce/results.txt`, `run.py`, 123 s on 4 cores): **H1 held**: non-leader take-up 0.187 (SD 0.082), leaders 0.247 (SD 0.126). **H2 refuted**: the grid minimum is q<sub>N</sub> = 0.05, q<sub>P</sub> = 0.30 for all three seeds (q<sub>N</sub> within one step, q<sub>P</sub> four steps below 0.50); the published point scores 11.3 times our minimum. **H3 held**: q<sub>P</sub> > q<sub>N</sub> in 98.4% of 1,000 bootstrap draws (q<sub>N</sub> 95% interval [0.05, 0.10], q<sub>P</sub> [0.15, 1.00]; restricting q<sub>N</sub> = q<sub>P</sub> doubles the criterion). **H4 held**: with q<sub>N</sub> = 0, take-up falls 0.194 to 0.129 (drop 0.337; informed 0.78 to 0.55), against the paper's 0.202 to 0.137 and 0.81 to 0.57.
- Not pre-registered, run after seeing H2 (`twostep.py`, `periods.py`): two-step optimal weights give q<sub>P</sub> 0.20 to 0.25 (q<sub>N</sub> 0.05) whether the weight matrix comes from our first step or from the code's (0.09, 0.45); quarterly periods give (0.05, 0.15), monthly (0.01, 0.10). Nothing tried moves toward (0.10, 0.50). The criterion profile at q<sub>N</sub> = 0.05 stays within a factor 2 of its minimum for q<sub>P</sub> 0.25 to 0.50; at q<sub>N</sub> = 0.10 it is 2 to 16 times the minimum everywhere.
- Reading: the port reproduces the data, the adopter effect and the counterfactual, not the point. Unresolved causes: other moments, weights or grid in the published table; the Science version against the 2012 working paper; a port difference the tests miss. The weak identification of q<sub>P</sub> is itself a first data point for H2 of the programme. Next (milestone 2): reinforcement and threshold models on the same moments plus take-up by number of adopting neighbours; before that, read the Science version's supplementary table if any host serves it.
