Module `rr_arb4`: ports `input clk, input rst, input [3:0] req, output [3:0] grant`. A 4-way round-robin arbiter with a registered pointer `last` (2 bits, reset value 3, synchronous active-high `rst`). `grant` is combinational and one-hot (or 0 if `req` is 0): it grants the first requester found when scanning indices `last+1, last+2, last+3, last+4` (mod 4). On each rising clock edge with `rst` low, if any grant is given, `last` becomes the index of the granted requester; otherwise it holds.
