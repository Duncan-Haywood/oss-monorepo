Module `fifo4`: ports `input clk, input rst, input push, input pop, input [7:0] din, output [7:0] dout, output full, output empty`. A synchronous FIFO of depth 4 and width 8. Synchronous active-high `rst` empties it. On a rising edge: a `push` is accepted only if the FIFO was not full at the start of the cycle; a `pop` is accepted only if it was not empty at the start of the cycle; when both are accepted, both happen. `empty` and `full` are combinational functions of the stored count. `dout` is combinational: the oldest stored word, or 0 when empty.
