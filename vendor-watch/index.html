Know when a vendor changes its terms.

Point Vendor Watch at a public terms, privacy policy or subprocessor page. It keeps a snapshot and, next time, shows what changed word by word, with the time and the source URL.

What it does

  • Word-level diff against your last snapshot, timestamped and linked to the source page.
  • A failed or non-2xx fetch is labelled inconclusive. It never overwrites a good snapshot and is never reported as "no change".
  • Command line exits non-zero on a change, so a cron job or CI step can watch a page.
  • Private, loopback and link-local addresses are refused; only public http/https pages are supported.

Run it yourself

The CLI needs only Node. Baselines are stored on your own disk.

git clone https://github.com/Duncan-Haywood/oss-monorepo
cd oss-monorepo/ventures/vendor-watch
npm install
npm run watch -- https://vendor.example/terms

The browser version needs a server, because fetching an arbitrary vendor page from a tab is blocked by CORS. See the README in the venture folder for both.

Privacy and usage

This page has no scripts, cookies or analytics, and records nothing about you. The browser tool keeps its snapshots in your own browser's local storage; the server does not persist them.
