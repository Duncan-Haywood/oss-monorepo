# Commercial Property Cap Rate Calculator

Free, private browser tool: enter rent, vacancy and operating expenses to get NOI, the value at a market cap rate, and, with a price, the going-in cap rate, DSCR, cash-on-cash return, break-even occupancy, the loan a 1.25x lender test allows, and a value grid across cap rates and vacancy.

**Live tool:** https://duncan-haywood.github.io/monorepo-projects/commercial-property-cap-rate-calculator/

After using this, you know what a small commercial or multifamily building is worth on its income and whether the loan covers it, which used to take a broker's proforma or a hand-built spreadsheet.

Open `index.html`. Tests: `node --test 'ventures/commercial-property-cap-rate-calculator/**/*.test.mjs'`.
