The metric watch in your own GitHub account was withdrawn

This page used to show how to set up a daily changepoint watch in a GitHub repository you own, from a zip or a script. On 2026-11-27 the Changepoint Detector moved to an all-rights-reserved licence, and that set-up, which copied the tool's code into your account, was withdrawn with it. A repository made before then keeps running under the licence it shipped with.

  • The watch.mjs command line described in the tool's README ("Watching a growing series").
