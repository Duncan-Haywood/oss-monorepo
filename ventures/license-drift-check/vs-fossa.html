License Drift Check vs. FOSSA

FOSSA is a hosted software composition analysis (SCA) platform. It connects to your repositories, continuously scans your dependency tree, tells you what license each dependency carries right now, checks that against a policy you configure (for example, block strong copyleft in a proprietary codebase), and can generate an SBOM or fail a build on a policy violation. It is a genuinely useful, always-on system for an organization that wants license compliance enforced across every repository without anyone checking by hand.

That is not this tool's job. License Drift Check parses two point-in-time snapshots you paste — a baseline and a current one — and reports exactly which packages' license changed, were added, or were removed between them. Nothing is uploaded, there is no account, no policy engine, and no memory once you close the tab.

QuestionWhere to answer it
What license does every dependency in my codebase carry right now, continuously, across my whole org? FOSSA — that needs an ongoing connected scan and a policy engine, which a stateless browser page never does.
I have a baseline snapshot and today's snapshot — did any package's license change between them? License Drift Check — paste both, get the exact list of changed, added, and removed packages, no signup, nothing leaves your device.
I want a build to fail automatically when a dependency violates my license policy. FOSSA's policy engine — this tool reports a diff, it does not enforce a rule about which licenses are acceptable.
My dependency tree is private and I don't want to connect an account or upload it just to check for a relicensing event. License Drift Check — the browser page never makes a network request, and the CLI reads only local files.

The two are not substitutes. A team that wants continuous, policy-driven license enforcement across every repository and every contributor needs a hosted platform like FOSSA — a page that only looks at whatever you paste into it, once, cannot do that job. A developer who already has two snapshots and wants to know what changed between them, without connecting a repository or accepting a policy engine's opinion of what is acceptable, does not need an account to get that answer.

Common questions

Should I use License Drift Check or FOSSA?

They answer different questions. FOSSA is a hosted software composition analysis (SCA) platform: it connects to your repositories, continuously scans every dependency, tells you what license each one carries right now, checks that against a policy you configure (for example, block copyleft in a proprietary codebase), and can generate SBOMs and block a build on a violation. License Drift Check is a free tool with no account and no connection: you paste two point-in-time snapshots of your dependency tree's declared licenses — a baseline and a current one — and it reports exactly which packages' license changed, were added, or were removed between them. FOSSA tells you the state today; this tool tells you what moved since last time. If you want continuous policy enforcement across a whole org, FOSSA's job is not one this page tries to do. If you already have two snapshots and want the diff before connecting anything, that is what this tool is for.

Does FOSSA already catch a license change on its own?

FOSSA's own product describes continuous scanning and policy checks against the license each dependency currently carries, which will flag a newly-scanned dependency that now violates your policy. What it is built to answer is the current state against a rule you set, not a side-by-side diff of exactly which packages changed license since an earlier snapshot you choose yourself — the four events this tool's README documents (MongoDB, Elasticsearch, Terraform, Redis) are exactly the case where the policy did not change, only the license did, underneath a routine version bump.

Is FOSSA free?

FOSSA offers a free tier for public open-source projects. Scanning private repositories, team seats, policy enforcement across an organization, and SBOM export at scale are paid tiers. License Drift Check has no account and nothing that bills at any tier — it is a free static page and a zero-dependency CLI, for public or private dependency trees alike, with no per-repository or per-seat cost.
