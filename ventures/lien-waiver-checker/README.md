# Lien Waiver Checker

**Live tool:** <https://duncan-haywood.github.io/monorepo-projects/lien-waiver-checker/>

Free, private browser tool for contractors, subcontractors and suppliers: paste the lien waiver you were sent and see the common ways it costs the signer money (unconditional before the funds clear, release of all claims or future work, wrong amount or through-date, retainage and pending change orders not excepted, indemnity or bond language), each with the change to ask for.

Open `index.html`. Tests: `node --test 'ventures/lien-waiver-checker/**/*.test.mjs'`.

Not legal advice. It reads wording with fixed rules and does not decide validity in any state. See `VENTURE.yaml`.
