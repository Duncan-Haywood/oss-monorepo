What Sponsor Ready actually checks, and how much each one is worth. Fix the top of this table first — it is ranked by weight for exactly that reason.

The gap between the top and bottom of this table is deliberate, not arbitrary: FUNDING.yml alone is worth as much as the bottom five items combined. A repo can have a perfect README, a license, topics, and a code of conduct, and still show no Sponsor button to a single visitor, because that button's existence depends on one file none of those other signals touch.

Common questions

What does it actually take to look ready for GitHub Sponsors?

There is no official eligibility checklist from GitHub for how a repo looks to a visitor. This page lists the 10 publicly-checkable signals Sponsor Ready scores, ranked by weight: a FUNDING.yml file (30 points) matters most because it is the file that turns on the Sponsor button at all, followed by recent activity, a visible sponsorship ask in the README, and seven smaller signals covering README quality, discoverability, and community health.

Which single fix improves a Sponsors readiness score the most?

Adding .github/FUNDING.yml with at least one funding platform, for example github: [your-username]. It is worth 30 of the 100 points Sponsor Ready checks for — three times the next-highest single item — because without it a repo has no Sponsor button for a visitor to click at all, regardless of how strong every other signal is.
