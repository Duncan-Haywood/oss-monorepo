What this is and isn't

  • Every check runs in your browser, calling GitHub's public API directly. This site has no server and stores nothing about the repos you check.
  • This is an informational heuristic against publicly documented signals — it is not affiliated with GitHub and does not guarantee any sponsorship outcome. It never tells you to enable GitHub Sponsors.
  • Only anonymous, aggregate usage counts (for example "a scan happened") may be recorded locally — never which repo you scanned.
