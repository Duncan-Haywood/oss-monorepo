# ExpressExpense SRD receipts: US phone photos, totals read by eye

Work in progress (2026-11-12): labels for the 200 free receipt photos of
ExpressExpense's "large receipt image dataset" (SRD), mostly US restaurant and
shop receipts on thermal paper, photographed with a phone. The images are not
committed; `../srd-receipts.mjs` fetches them at run time.
