# Commercial Photography Licensing Quote Calculator

When a commercial client asks where, how long, and how widely they can use your images, this free browser-local worksheet turns that scope into a transparent starting quote. It separates the creative fee from usage rights, shows the assumptions, and creates a client-ready draft.

After using this, you can explain a commercial image license line by line, which used to take rebuilding a spreadsheet for every client request.

## Run it

Open `index.html` in a browser. No account, server, build step, API key, or paid dependency is required. The calculator is deterministic: it is a negotiation worksheet, not an automated valuation or contract generator.

## Privacy and usage

Everything runs in the browser. Your numbers and drafts are never uploaded; there are no accounts, cookies, or analytics vendors. The optional local counter records only aggregate feature events such as `quote_built` and `draft_copied`, never people, IP addresses, quote content, or identifiers. The counter can be disabled in the page and is cleared by the page control.

## Business opportunity

The target user is an independent commercial, brand, product, or editorial photographer who repeatedly receives unclear usage requests. Existing contract libraries and generic pricing guides provide templates or broad advice, but generally do not expose a quick usage-scope breakdown for a specific quote. Search terms include “commercial photography licensing fee calculator”, “photo usage rights pricing”, and “photography usage license quote”.

The free product can later support paid hosted quote history, custom rate presets, or an optional user-supplied AI key for plain-language negotiation notes. None of those are required for the current workflow, and no payment is collected here. Hosting is a static file with zero marginal compute cost.
