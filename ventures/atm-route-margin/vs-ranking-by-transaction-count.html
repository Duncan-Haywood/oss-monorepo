This calculator vs. ranking your route by transaction count

Names no specific product or company. This compares a free calculator against the generic habit every route operator already has: sorting locations by monthly withdrawal count and treating the busiest machines as the best ones.

First — transaction count is not useless

A withdrawal report is real information: it tells you a location still gets foot traffic, and a machine trending toward zero withdrawals is a genuine problem worth acting on. Nothing below argues for ignoring that report. What it argues is that count alone cannot answer the next question — which of these locations is actually worth keeping — because count only drives one line of the arithmetic, and every other cost is set by the placement terms, not the traffic.

Both locations below process the identical 220 withdrawals this month at the same $2.75 surcharge fee — so a transaction-count ranking would place them side by side. The only things that differ are the commission split, the size of the vault cash load, and the drive to service the machine.

The two places a transaction-count ranking goes quiet

1. It cannot see the placement terms behind the count

A withdrawal report has one column. It cannot show that Location B's 55% commission takes more than double the cut Location A's 25% does on the identical surcharge revenue, or that the processor fee — fixed per withdrawal — already lands the same on both before commission is even subtracted. Two machines that look identical on a traffic report can be running under completely different agreements.

2. It cannot see the cash and the drive

Vault cash cost and refill mileage scale with the machine's own cash load and location, not with how many withdrawals it processes. A location that needs a larger cash float and a longer drive carries a real monthly cost a transaction count never states, which is most of the gap between Location A's $262.03 profit and Location B's $29.38 loss on the same 220 withdrawals.

When ranking by count is still the right first check

Watching withdrawal counts month to month is still the cheapest way to catch a location going quiet, and it needs no calculator. The point at which count stops being enough is when you are deciding which locations to keep, drop, or renegotiate — that decision needs the commission split, the cash load, and the drive behind each stop, which is what this calculator prices per location before rolling the whole route up against a monthly income goal.

Common questions

Is transaction count a bad way to judge a location?

Not on its own terms — it tells you the location gets foot traffic, which is real information. The problem is using it as a stand-in for profit. Two locations doing the identical 220 withdrawals a month can land on opposite sides of zero once the commission split, the vault cash sitting in the machine, and the drive to service it are counted, and a monthly report that only lists withdrawal counts has no way to show that.

How can two locations with the same withdrawal count have such different profit?

Because withdrawal count only drives one line — gross surcharge revenue — and every other cost is set by the placement terms, not the traffic. On this calculator's own worked example, both locations gross an identical $605.00 from 220 withdrawals at the same surcharge fee. One pays a 25% commission on a $2,000 cash load with a 10-minute drive; the other pays 55% on a $5,000 cash load with a 35-minute drive. The first nets $262.03. The second loses $29.38.

Which locations does this catch that a withdrawal-count ranking misses?

The ones a monthly transaction report ranks in the middle or even near the top, because it sorts by traffic, not by what the traffic is worth after the location's cut, the processor fee, and the cost of servicing the stop. A route operator dropping the lowest-count machines to trim the route can pass right over a busier machine that is actually the one losing money, and keep a quieter one that pays better per visit.

Does this replace watching my withdrawal counts?

No. Withdrawal count is still the number that tells you whether a location is getting used at all, and a machine trending toward zero withdrawals is a real problem this calculator does not need to tell you about. What it adds is the number withdrawal count cannot produce on its own: whether the traffic that is there is actually profitable once the placement's own terms are priced in.
