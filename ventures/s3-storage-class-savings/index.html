Common questions

    
Does this connect to my AWS account?

    
No. It reads the S3 Inventory CSV you paste or choose and never contacts AWS. It cannot see your real bill, free tier, volume tiers, request or data-transfer charges, so every dollar figure is rows you supplied times list prices you can edit.

    
Why can moving small objects to a cheaper class lose money?

    
Standard-IA and Glacier Instant Retrieval bill every object as at least 128 KB, Glacier Flexible and Deep Archive add about 40 KB of overhead per object, and every lifecycle transition is a billed request per object. For an object under about 128 KB those charges can exceed the storage you save. Add ObjectSizeGreaterThan 131071 to the lifecycle rule to leave them in Standard.

    
What does it assume about how often my data is read?

    
An inventory lists what exists, not what is read, so retrieval is an input: the percentage of transitioned bytes retrieved each month (default 1%). Raise it if you read old data; Standard-IA and Glacier Instant Retrieval charge per GB retrieved and Intelligent-Tiering has no retrieval fee. The percentage of objects deleted early is also an input, because of the 30, 90 and 180 day minimum storage durations.

    
Is my inventory uploaded anywhere?

    
No. The browser page reads the file or text in your own browser and never sends it anywhere. The CLI reads a local file or stdin and makes no network call.
