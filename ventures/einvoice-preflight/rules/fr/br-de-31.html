BR-DE-31: Prélèvement sans compte débité

EnglishDeutschToutes les règles

Message officiel

Wenn "DIRECT DEBIT" BG-19 vorhanden ist, dann muss "Debited account identifier" BT-91 übermittelt werden.
Gravité
Erreur (la facture est rejetée)
Vérifiée en
UBL, CII
Termes métier
BG-19, BT-91

Que signifie BR-DE-31 ?

Quand la facture contient des informations de prélèvement (BG-19), elle doit indiquer l'identifiant du compte débité (BT-91), le compte de l'acheteur sur lequel le montant sera prélevé. En UBL c'est cac:PayerFinancialAccount/cbc:ID dans cac:PaymentMandate ; en CII ram:IBANID dans ram:PayerPartyDebtorFinancialAccount.

Causes fréquentes

  • Seule la référence du mandat a été exportée, pas l'IBAN de l'acheteur.
  • L'IBAN de l'acheteur a été placé dans le compte du bénéficiaire au lieu de celui du payeur.
  • Le logiciel omet l'IBAN par souci de confidentialité et renvoie au mandat.

Comment corriger BR-DE-31 ?

  1. Reprendre l'IBAN de l'acheteur dans le mandat SEPA signé.
  2. L'ajouter comme cac:PayerFinancialAccount/cbc:ID dans cac:PaymentMandate (UBL) ou comme ram:PayerPartyDebtorFinancialAccount/ram:IBANID dans le moyen de paiement (CII).
  3. S'il n'y a pas de prélèvement, supprimer les données du mandat et utiliser le code du mode de paiement réel.

XML corrigé (exemple minimal rédigé par nous)

UBL

<cac:PaymentMeans>  <cbc:PaymentMeansCode>59</cbc:PaymentMeansCode>  <cac:PaymentMandate>    <cbc:ID>MANDAT-2026-001</cbc:ID>    <cac:PayerFinancialAccount>      <cbc:ID>DE02120300000000202051</cbc:ID>    </cac:PayerFinancialAccount>  </cac:PaymentMandate></cac:PaymentMeans>

CII

<ram:SpecifiedTradeSettlementPaymentMeans>  <ram:TypeCode>59</ram:TypeCode>  <ram:PayerPartyDebtorFinancialAccount>    <ram:IBANID>DE02120300000000202051</ram:IBANID>  </ram:PayerPartyDebtorFinancialAccount></ram:SpecifiedTradeSettlementPaymentMeans>

Valeurs d'exemple uniquement. Remplacez ou complétez les éléments de votre fichier ; l'ordre des éléments est imposé dans les deux syntaxes.
