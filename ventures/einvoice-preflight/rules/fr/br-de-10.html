BR-DE-10: L'adresse de livraison n'a pas de ville

EnglishDeutschToutes les règles

Message officiel

Das Element "Deliver to city" (BT-77) muss übermittelt werden, wenn die Gruppe "DELIVER TO ADDRESS" (BG-15) übermittelt wird.
Gravité
Erreur (la facture est rejetée)
Vérifiée en
UBL, CII
Termes métier
BT-77, BG-15

Que signifie BR-DE-10 ?

Si la facture indique une adresse de livraison (BG-15), XRechnung exige qu'elle comporte une ville (BT-77). Une facture sans adresse de livraison n'est pas concernée par cette règle.

Causes fréquentes

  • Seule une rue ou un nom de bâtiment a été saisi pour l'adresse de livraison.
  • Le logiciel écrit un bloc d'adresse de livraison vide même sans livraison à une autre adresse.
  • La ville et le code postal ont été saisis dans une seule ligne d'adresse.

Comment corriger BR-DE-10 ?

  1. Ajoutez la ville du lieu de livraison : cbc:CityName dans cac:Delivery/cac:DeliveryLocation/cac:Address (UBL) ou ram:CityName dans ram:ShipToTradeParty/ram:PostalTradeAddress (CII).
  2. Complétez en même temps le code postal (BR-DE-11) et le code pays.
  3. Si rien n'a été livré à une autre adresse, omettez plutôt l'adresse de livraison que de l'envoyer incomplète.

XML corrigé (exemple minimal rédigé par nous)

UBL

<cac:Delivery>  <cbc:ActualDeliveryDate>2026-11-20</cbc:ActualDeliveryDate>  <cac:DeliveryLocation>    <cac:Address>      <cbc:StreetName>Lagerstraße 7</cbc:StreetName>      <cbc:CityName>Potsdam</cbc:CityName>      <cbc:PostalZone>14467</cbc:PostalZone>      <cac:Country>        <cbc:IdentificationCode>DE</cbc:IdentificationCode>      </cac:Country>    </cac:Address>  </cac:DeliveryLocation></cac:Delivery>

CII

<ram:ApplicableHeaderTradeDelivery>  <ram:ShipToTradeParty>    <ram:Name>Example Authority, warehouse</ram:Name>    <ram:PostalTradeAddress>      <ram:PostcodeCode>14467</ram:PostcodeCode>      <ram:LineOne>Lagerstraße 7</ram:LineOne>      <ram:CityName>Potsdam</ram:CityName>      <ram:CountryID>DE</ram:CountryID>    </ram:PostalTradeAddress>  </ram:ShipToTradeParty></ram:ApplicableHeaderTradeDelivery>

Valeurs d'exemple uniquement. Remplacez ou complétez les éléments de votre fichier ; l'ordre des éléments est imposé dans les deux syntaxes.
