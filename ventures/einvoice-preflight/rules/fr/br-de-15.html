Règle de facture électronique expliquée · XRechnung

BR-DE-15: La référence acheteur (Leitweg-ID) est absente

EnglishDeutschToutes les règles

Message officiel

Das Element "Buyer reference" (BT-10) muss übermittelt werden.
Gravité
Erreur (la facture est rejetée)
Vérifiée en
UBL, CII
Termes métier
BT-10

Que signifie BR-DE-15 ?

XRechnung exige la référence acheteur (BT-10) sur chaque facture. Pour les acheteurs publics allemands, ce champ porte la Leitweg-ID, le code d'acheminement qui indique à la plateforme de réception à quelle administration la facture est destinée.

Causes fréquentes

  • Le logiciel de facturation laisse BT-10 vide, car il est facultatif dans la norme EN 16931 seule.
  • La Leitweg-ID a été saisie dans une note, la référence de commande (BT-13) ou le nom de l'acheteur au lieu de BT-10.
  • Un modèle prévu pour les clients privés a été utilisé pour un acheteur public.

Comment corriger BR-DE-15 ?

  1. Demandez à l'acheteur la référence qu'il attend ; un acheteur public vous communique sa Leitweg-ID avec la commande.
  2. Indiquez-la dans cbc:BuyerReference (UBL) ou ram:BuyerReference dans ram:ApplicableHeaderTradeAgreement (CII).
  3. Pour un acheteur privé allemand sans Leitweg-ID, convenez d'une autre référence (par exemple son numéro de commande) et transmettez-la.

XML corrigé (exemple minimal rédigé par nous)

UBL

<cbc:BuyerReference>04011000-12345-34</cbc:BuyerReference>

CII

<ram:ApplicableHeaderTradeAgreement>
  <ram:BuyerReference>04011000-12345-34</ram:BuyerReference>
</ram:ApplicableHeaderTradeAgreement>

Valeurs d'exemple uniquement. Remplacez ou complétez les éléments de votre fichier ; l'ordre des éléments est imposé dans les deux syntaxes.
