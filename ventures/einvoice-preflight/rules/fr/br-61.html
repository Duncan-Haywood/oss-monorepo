Règle de facture électronique expliquée · EN 16931

BR-61: Virement sans compte bénéficiaire

EnglishDeutschToutes les règles

Message officiel

If the Payment means type code (BT-81) means SEPA credit transfer, Local credit transfer or Non-SEPA international credit transfer, the Payment account identifier (BT-84) shall be present.
Gravité
Erreur (la facture est rejetée)
Vérifiée en
UBL, CII
Termes métier
BT-81, BT-84

Que signifie BR-61 ?

Lorsque le code du moyen de paiement (BT-81) indique un virement, la facture doit donner l'identifiant du compte de paiement (BT-84), en général l'IBAN. En UBL, le contrôle ne vise que les codes 30 et 58. En CII, il ne regarde qu'à l'intérieur d'un bloc de compte déjà présent : un fichier CII avec le code 30 ou 58 et aucun bloc de compte n'est pas détecté par cette règle.

Causes fréquentes

  • Le moyen de paiement 58 (virement SEPA) ou 30 (virement) est indiqué, mais les coordonnées bancaires manquent dans le XML.
  • L'IBAN figure dans une note de paiement libre (BT-82) ou dans les informations du vendeur au lieu du compte bénéficiaire.
  • En UBL, l'IBAN n'est pas dans cbc:ID sous cac:PayeeFinancialAccount ; en CII, le bloc de compte existe mais ne contient ni ram:IBANID ni ram:ProprietaryID.

Comment corriger BR-61 ?

  1. Indiquez le compte sur lequel vous voulez être payé : en UBL dans cbc:ID sous cac:PayeeFinancialAccount, en CII dans ram:IBANID (ou ram:ProprietaryID pour un compte sans IBAN).
  2. Vérifiez que le code correspond au moyen de paiement voulu : 58 pour un virement SEPA, 30 pour les autres virements.
  3. Enregistrez les coordonnées bancaires dans les paramètres de votre logiciel de facturation pour que chaque facture les porte.

XML corrigé (exemple minimal rédigé par nous)

UBL

<cac:PaymentMeans>  <cbc:PaymentMeansCode>58</cbc:PaymentMeansCode>  <cbc:PaymentID>INV-2026-001</cbc:PaymentID>  <cac:PayeeFinancialAccount>    <cbc:ID>DE02120300000000202051</cbc:ID>    <cbc:Name>Example GmbH</cbc:Name>  </cac:PayeeFinancialAccount></cac:PaymentMeans>

CII

<ram:SpecifiedTradeSettlementPaymentMeans>  <ram:TypeCode>58</ram:TypeCode>  <ram:PayeePartyCreditorFinancialAccount>    <ram:IBANID>DE02120300000000202051</ram:IBANID>    <ram:AccountName>Example GmbH</ram:AccountName>  </ram:PayeePartyCreditorFinancialAccount></ram:SpecifiedTradeSettlementPaymentMeans>

Valeurs d'exemple uniquement. Remplacez ou complétez les éléments de votre fichier ; l'ordre des éléments est imposé dans les deux syntaxes.
