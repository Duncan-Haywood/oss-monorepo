Règle de facture électronique expliquée · EN 16931

BR-CL-14: Code pays non conforme à l'ISO 3166-1

EnglishDeutschToutes les règles

Message officiel

Country codes in an invoice MUST be coded using ISO code list 3166-1
Gravité
Erreur (la facture est rejetée)
Vérifiée en
UBL, CII

Que signifie BR-CL-14 ?

Chaque code pays de la facture (adresses du vendeur, de l'acheteur, de livraison, pays d'origine d'un article) doit être un code ISO 3166-1 alpha-2 de deux lettres en majuscules, comme FR, DE ou BE. La liste accepte aussi XI pour l'Irlande du Nord et 1A pour le Kosovo.

Causes fréquentes

  • Le nom du pays (« France », « Allemagne ») ou un code à trois lettres (FRA) a été saisi à la place du code à deux lettres.
  • Le code est en minuscules (fr) ou contient une espace.
  • Un préfixe de TVA a servi de code pays : EL pour la Grèce (le code pays est GR) ou UK pour le Royaume-Uni (le code pays est GB).

Comment corriger BR-CL-14 ?

  1. Recherchez le code ISO 3166-1 à deux lettres de chaque pays figurant sur la facture.
  2. Saisissez-le en majuscules, sans espace, dans chaque champ pays : cbc:IdentificationCode en UBL, ram:CountryID en CII.
  3. Corrigez les fiches clients et fournisseurs pour que la prochaine facture soit juste.

XML corrigé (exemple minimal rédigé par nous)

UBL

<cac:PostalAddress>  <cbc:StreetName>Musterstraße 1</cbc:StreetName>  <cbc:CityName>Berlin</cbc:CityName>  <cbc:PostalZone>10115</cbc:PostalZone>  <cac:Country>    <cbc:IdentificationCode>DE</cbc:IdentificationCode>  </cac:Country></cac:PostalAddress>

CII

<ram:PostalTradeAddress>  <ram:PostcodeCode>10115</ram:PostcodeCode>  <ram:LineOne>Musterstraße 1</ram:LineOne>  <ram:CityName>Berlin</ram:CityName>  <ram:CountryID>DE</ram:CountryID></ram:PostalTradeAddress>

Valeurs d'exemple uniquement. Remplacez ou complétez les éléments de votre fichier ; l'ordre des éléments est imposé dans les deux syntaxes.
