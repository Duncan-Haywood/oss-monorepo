BR-DE-25-a: Prélèvement sans informations de prélèvement

EnglishDeutschToutes les règles

Message officiel

Wenn BT-81 "Payment means type code" einen Schlüssel für Lastschriften enthält (59), muss genau BG-19 "DIRECT DEBIT" übermittelt werden.
Gravité
Erreur (la facture est rejetée)
Vérifiée en
UBL, CII
Termes métier
BT-81, BG-19

Que signifie BR-DE-25-a ?

Quand un moyen de paiement utilise le code de prélèvement 59 en BT-81, la facture doit contenir le groupe prélèvement (BG-19). En UBL il s'agit d'un cac:PaymentMandate dans le même moyen de paiement ; en CII il suffit qu'une référence de mandat, un identifiant de créancier ou l'IBAN du compte débité soit présent. Le message officiel parle d'exactement un groupe, mais le test vérifie seulement sa présence.

Causes fréquentes

  • Le code 59 a été choisi sans que les données du mandat soient exportées.
  • La référence du mandat figure seulement dans une note ou dans le texte des conditions de paiement.
  • Le code 59 a été utilisé pour une facture que l'acheteur paiera en réalité par virement.

Comment corriger BR-DE-25-a ?

  1. Ajouter dans le même cac:PaymentMeans un cac:PaymentMandate avec la référence du mandat (cbc:ID) et l'IBAN de l'acheteur dans cac:PayerFinancialAccount (UBL).
  2. En CII, indiquer ram:DirectDebitMandateID dans ram:SpecifiedTradePaymentTerms, ram:CreditorReferenceID et ram:PayerPartyDebtorFinancialAccount/ram:IBANID.
  3. S'il n'y a pas de prélèvement, utiliser plutôt le code 58 ou 30 avec votre propre compte.

<cac:PaymentMeans>  <cbc:PaymentMeansCode>59</cbc:PaymentMeansCode>  <cac:PaymentMandate>    <cbc:ID>MANDAT-2026-001</cbc:ID>    <cac:PayerFinancialAccount>      <cbc:ID>DE02120300000000202051</cbc:ID>    </cac:PayerFinancialAccount>  </cac:PaymentMandate></cac:PaymentMeans>
