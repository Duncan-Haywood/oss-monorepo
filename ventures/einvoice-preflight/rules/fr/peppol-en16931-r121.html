Règle de facture électronique expliquée · Peppol BIS

PEPPOL-EN16931-R121: La quantité de base du prix est nulle ou négative

EnglishDeutschToutes les règles

Message officiel

Base quantity MUST be a positive number above zero.
Gravité
Erreur (la facture est rejetée)
Vérifiée en
UBL, CII
Termes métier
BT-149

Que signifie PEPPOL-EN16931-R121 ?

Si le prix d'une ligne indique une quantité de base (BT-149, le nombre d'unités auquel s'applique le prix), elle doit être supérieure à zéro. L'omettre est permis : elle vaut alors 1. En CII, la règle contrôle la quantité de base du prix net comme du prix brut.

Causes fréquentes

  • Le logiciel écrit une quantité de base de 0 lorsqu'aucune unité de prix n'est définie.
  • Sur un avoir ou une ligne de retour, le signe moins a été placé sur la quantité de base au lieu de la quantité.
  • Un champ vide a été exporté comme 0.

Comment corriger PEPPOL-EN16931-R121 ?

  1. Renseignez cbc:BaseQuantity (UBL) ou ram:BasisQuantity (CII) avec le nombre d'unités auquel s'applique le prix, généralement 1.
  2. Placez les signes négatifs sur la quantité ou le montant, jamais sur la quantité de base.
  3. Si le prix est simplement unitaire, vous pouvez supprimer la quantité de base.

XML corrigé (exemple minimal rédigé par nous)

UBL

<cac:Price>
  <cbc:PriceAmount currencyID="EUR">25.00</cbc:PriceAmount>
  <cbc:BaseQuantity unitCode="C62">1</cbc:BaseQuantity>
</cac:Price>

CII

<ram:NetPriceProductTradePrice>
  <ram:ChargeAmount>25.00</ram:ChargeAmount>
  <ram:BasisQuantity unitCode="C62">1</ram:BasisQuantity>
</ram:NetPriceProductTradePrice>

Valeurs d'exemple uniquement. Remplacez ou complétez les éléments de votre fichier ; l'ordre des éléments est imposé dans les deux syntaxes.
