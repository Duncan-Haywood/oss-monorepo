Règle de facture électronique expliquée · XRechnung

BR-DE-CVD-02: Référence de l'appel d'offres ou du lot manquante sur une facture « véhicules propres »

EnglishDeutschToutes les règles

Message officiel

Das Element "Tender or lot reference" (BT-17) muss übermittelt werden.
Gravité
Erreur (la facture est rejetée)
Vérifiée en
UBL, CII
Termes métier
BT-17

Que signifie BR-DE-CVD-02 ?

Sur une facture qui déclare dans BT-24 l'extension XRechnung pour les véhicules propres (CVD), la référence de l'appel d'offres ou du lot (BT-17) doit être renseignée : le numéro de la procédure de marché ou du lot attribué pour le véhicule. Les factures portant l'identifiant XRechnung habituel ne sont pas contrôlées par cette règle.

Causes fréquentes

  • Le numéro de procédure ou de lot n'a pas été repris des documents de consultation.
  • Il figure seulement dans la référence du contrat (BT-12) ou dans une note.
  • En CII, un document référencé supplémentaire a été ajouté, mais sans code de type 50 ou avec un numéro vide.

Comment corriger BR-DE-CVD-02 ?

  1. Retrouvez le numéro de procédure ou de lot dans les documents de consultation ou l'avis d'attribution de l'acheteur.
  2. En UBL, indiquez-le dans cac:OriginatorDocumentReference/cbc:ID.
  3. En CII, ajoutez dans ram:ApplicableHeaderTradeAgreement un ram:AdditionalReferencedDocument avec le numéro dans ram:IssuerAssignedID et ram:TypeCode 50.

XML corrigé (exemple minimal rédigé par nous)

UBL

<cac:OriginatorDocumentReference>
  <cbc:ID>VG-2026-117-LOS-2</cbc:ID>
</cac:OriginatorDocumentReference>

CII

<ram:ApplicableHeaderTradeAgreement>
  <ram:BuyerReference>04011000-12345-34</ram:BuyerReference>
  <ram:AdditionalReferencedDocument>
    <ram:IssuerAssignedID>VG-2026-117-LOS-2</ram:IssuerAssignedID>
    <ram:TypeCode>50</ram:TypeCode>
  </ram:AdditionalReferencedDocument>
</ram:ApplicableHeaderTradeAgreement>

Valeurs d'exemple uniquement. Remplacez ou complétez les éléments de votre fichier ; l'ordre des éléments est imposé dans les deux syntaxes.
