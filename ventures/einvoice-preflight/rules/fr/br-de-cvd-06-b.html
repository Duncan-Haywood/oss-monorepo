Règle de facture électronique expliquée · XRechnung

BR-DE-CVD-06-b: Une ligne avec un attribut cva doit avoir exactement une catégorie CVD

EnglishDeutschToutes les règles

Message officiel

Wenn "Item attribute name" (BT-160) mit dem Wert 'cva' angegeben ist, muss in derselben Rechnungszeile genau ein "Item classification identifier" (BT-158) mit dem Scheme identifier 'CVD' vorhanden sein.
Gravité
Erreur (la facture est rejetée)
Vérifiée en
UBL, CII
Termes métier
BT-158, BT-160

Que signifie BR-DE-CVD-06-b ?

Sur une facture qui déclare dans BT-24 l'extension XRechnung pour les véhicules propres (CVD), toute ligne dont l'article porte un attribut nommé cva (BT-160) doit aussi avoir exactement un code de classification de schéma CVD (BT-158). Aucun code fait échouer le contrôle, deux ou plus sur la même ligne aussi.

Causes fréquentes

  • L'attribut cva a été ajouté, mais la classification de la catégorie du véhicule a été oubliée.
  • La catégorie a été indiquée avec un autre identifiant de schéma, ou sans, au lieu de listID CVD.
  • Deux classifications CVD figurent sur une seule ligne, par exemple pour deux véhicules facturés ensemble.

Comment corriger BR-DE-CVD-06-b ?

  1. Sur chaque ligne portant un attribut cva, ajoutez exactement un code de classification avec listID CVD et la catégorie M1, M2, M3, N1, N2 ou N3.
  2. Si une ligne couvre des véhicules de catégories différentes, scindez-la en une ligne par catégorie.
  3. Si la ligne ne porte pas sur un véhicule, retirez plutôt l'attribut cva.

XML corrigé (exemple minimal rédigé par nous)

UBL

<cac:Item>
  <cbc:Name>Electric city bus, 12 m</cbc:Name>
  <cac:CommodityClassification>
    <cbc:ItemClassificationCode listID="CVD">M3</cbc:ItemClassificationCode>
  </cac:CommodityClassification>
  <cac:AdditionalItemProperty>
    <cbc:Name>cva</cbc:Name>
    <cbc:Value>zero-emission</cbc:Value>
  </cac:AdditionalItemProperty>
</cac:Item>

CII

<ram:SpecifiedTradeProduct>
  <ram:Name>Electric city bus, 12 m</ram:Name>
  <ram:ApplicableProductCharacteristic>
    <ram:Description>cva</ram:Description>
    <ram:Value>zero-emission</ram:Value>
  </ram:ApplicableProductCharacteristic>
  <ram:DesignatedProductClassification>
    <ram:ClassCode listID="CVD">M3</ram:ClassCode>
  </ram:DesignatedProductClassification>
</ram:SpecifiedTradeProduct>

Valeurs d'exemple uniquement. Remplacez ou complétez les éléments de votre fichier ; l'ordre des éléments est imposé dans les deux syntaxes.
