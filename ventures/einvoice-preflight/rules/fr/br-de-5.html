Règle de facture électronique expliquée · XRechnung

BR-DE-5: Le nom du contact du vendeur est absent

EnglishDeutschToutes les règles

Message officiel

Das Element "Seller contact point" (BT-41) muss übermittelt werden.
Gravité
Erreur (la facture est rejetée)
Vérifiée en
UBL, CII
Termes métier
BT-41

Que signifie BR-DE-5 ?

Lorsque le groupe contact du vendeur est présent, XRechnung exige un point de contact (BT-41) : le nom d'une personne ou d'un service. En UBL, c'est cbc:Name dans le cac:Contact du vendeur ; en CII, ram:PersonName ou ram:DepartmentName est accepté.

Causes fréquentes

  • Le groupe contact ne contient qu'un numéro de téléphone ou une adresse e-mail.
  • Aucun interlocuteur facturation n'est configuré dans le logiciel, le nom est donc vide.
  • Le nom a été saisi dans un autre champ, par exemple la raison sociale.

Comment corriger BR-DE-5 ?

  1. Indiquez un nom ou un service comme « Comptabilité » : cbc:Name dans le cac:Contact du vendeur (UBL), ram:PersonName ou ram:DepartmentName dans ram:DefinedTradeContact (CII).
  2. Définissez un contact facturation par défaut dans les paramètres de l'entreprise pour que chaque facture en ait un.
  3. Gardez le téléphone et l'adresse e-mail dans le même groupe (BR-DE-6, BR-DE-7).

XML corrigé (exemple minimal rédigé par nous)

UBL

<cac:Contact>
  <cbc:Name>Accounts team</cbc:Name>
  <cbc:Telephone>+49 30 1234567</cbc:Telephone>
  <cbc:ElectronicMail>invoices@example.com</cbc:ElectronicMail>
</cac:Contact>

CII

<ram:DefinedTradeContact>
  <ram:DepartmentName>Accounts</ram:DepartmentName>
  <ram:TelephoneUniversalCommunication>
    <ram:CompleteNumber>+49 30 1234567</ram:CompleteNumber>
  </ram:TelephoneUniversalCommunication>
  <ram:EmailURIUniversalCommunication>
    <ram:URIID>invoices@example.com</ram:URIID>
  </ram:EmailURIUniversalCommunication>
</ram:DefinedTradeContact>

Valeurs d'exemple uniquement. Remplacez ou complétez les éléments de votre fichier ; l'ordre des éléments est imposé dans les deux syntaxes.
