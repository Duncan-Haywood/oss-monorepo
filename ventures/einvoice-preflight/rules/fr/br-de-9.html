Règle de facture électronique expliquée · XRechnung

BR-DE-9: Le code postal de l'acheteur est absent

EnglishDeutschToutes les règles

Message officiel

Das Element "Buyer post code" (BT-53) muss übermittelt werden.
Gravité
Erreur (la facture est rejetée)
Vérifiée en
UBL, CII
Termes métier
BT-53

Que signifie BR-DE-9 ?

XRechnung exige que l'adresse postale de l'acheteur comporte un code postal (BT-53), facultatif dans la norme EN 16931 seule. Le contrôle échoue si le code postal manque ou ne contient que des espaces.

Causes fréquentes

  • La fiche client n'a pas de code postal, ou il a été saisi dans le champ ville.
  • Une boîte postale ou un code de courrier interne a été saisi à la place du code postal.
  • L'acheteur est établi dans un pays sans code postal.

Comment corriger BR-DE-9 ?

  1. Indiquez le code postal de l'acheteur dans son propre champ : cbc:PostalZone dans la cac:PostalAddress de l'acheteur (UBL) ou ram:PostcodeCode dans sa ram:PostalTradeAddress (CII).
  2. Reprenez l'adresse de facturation donnée par l'acheteur ; pour un acheteur public, elle figure en général dans la commande ou ses consignes de facturation.
  3. Si le pays de l'acheteur n'a pas de codes postaux, demandez-lui quoi indiquer : la règle ne prévoit pas d'exception.

XML corrigé (exemple minimal rédigé par nous)

UBL

<cac:AccountingCustomerParty>  <cac:Party>    <cac:PostalAddress>      <cbc:StreetName>Amtsweg 5</cbc:StreetName>      <cbc:CityName>Bonn</cbc:CityName>      <cbc:PostalZone>53111</cbc:PostalZone>      <cac:Country>        <cbc:IdentificationCode>DE</cbc:IdentificationCode>      </cac:Country>    </cac:PostalAddress>  </cac:Party></cac:AccountingCustomerParty>

CII

<ram:BuyerTradeParty>  <ram:Name>Example Authority</ram:Name>  <ram:PostalTradeAddress>    <ram:PostcodeCode>53111</ram:PostcodeCode>    <ram:LineOne>Amtsweg 5</ram:LineOne>    <ram:CityName>Bonn</ram:CityName>    <ram:CountryID>DE</ram:CountryID>  </ram:PostalTradeAddress></ram:BuyerTradeParty>

Valeurs d'exemple uniquement. Remplacez ou complétez les éléments de votre fichier ; l'ordre des éléments est imposé dans les deux syntaxes.
