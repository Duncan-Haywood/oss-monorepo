PEPPOL-EN16931-P0112: Type de facture 326, 384 ou 389 utilisé hors des pays autorisés

EnglishDeutschToutes les règles

Message officiel

Invoice type codes 326 and 389 are only allowed when both buyer and seller are German organizations. Invoice type code 384 is only allowed when both buyer and seller are German organizations or both are Slovak organizations.
Gravité
Erreur (la facture est rejetée)
Vérifiée en
UBL

Que signifie PEPPOL-EN16931-P0112 ?

Les types de facture 326 (facture partielle), 384 (facture rectificative) et 389 (autofacturation) ne sont admis sur Peppol que si le vendeur et l'acheteur sont tous deux allemands, d'après le code pays de leur adresse postale. Le code 384 est aussi admis si les deux sont slovaques ; le pays est alors déduit du préfixe du numéro de TVA (pour le vendeur, à défaut celui du représentant fiscal), sinon de l'adresse postale. Les autres factures doivent utiliser un code comme 380.

Causes fréquentes

  • Le logiciel utilise 326, 384 ou 389 pour tous les clients, y compris étrangers.
  • Vendeur et acheteur sont tous deux allemands, mais un code pays d'adresse postale manque ou n'est pas DE.
  • Une facture rectificative (384) a été envoyée entre des parties d'autres pays que l'Allemagne ou la Slovaquie.

Comment corriger PEPPOL-EN16931-P0112 ?

  1. Vérifiez les codes pays des adresses postales (cac:Country/cbc:IdentificationCode) du vendeur et de l'acheteur ; pour deux parties allemandes, les deux doivent être DE.
  2. Sinon, utilisez le code 380 (facture commerciale) dans cbc:InvoiceTypeCode ; pour corriger une facture, émettez un avoir puis une nouvelle facture au lieu d'une 384.
  3. S'il s'agit d'autofacturation ou d'une facture partielle, demandez à votre prestataire Peppol comment le destinataire souhaite qu'elle soit signalée.
