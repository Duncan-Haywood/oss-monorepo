BR-DE-25-a: Lastschrift ohne Lastschriftangaben

EnglishFrançaisAlle Regeln

Offizielle Meldung

Wenn BT-81 "Payment means type code" einen Schlüssel für Lastschriften enthält (59), muss genau BG-19 "DIRECT DEBIT" übermittelt werden.
Schweregrad
Fehler (die Rechnung wird abgewiesen)
Geprüft in
UBL, CII
Geschäftsbegriffe
BT-81, BG-19

Was bedeutet BR-DE-25-a?

Enthält eine Zahlungsanweisung den Lastschriftcode 59 in BT-81, muss die Rechnung die Gruppe Lastschrift (BG-19) enthalten. In UBL ist das ein cac:PaymentMandate in derselben Zahlungsanweisung; in CII genügt eine vorhandene Mandatsreferenz, Gläubiger-ID oder IBAN des zu belastenden Kontos. Die amtliche Meldung spricht von genau einer Gruppe, der Test prüft aber nur das Vorhandensein.

Typische Ursachen

  • Code 59 wurde gewählt, aber die Mandatsdaten wurden nicht exportiert.
  • Die Mandatsreferenz steht nur in einer Bemerkung oder im Text der Zahlungsbedingungen.
  • Code 59 wurde für eine Rechnung verwendet, die der Käufer tatsächlich überweist.

Wie behebe ich BR-DE-25-a?

  1. In derselben cac:PaymentMeans cac:PaymentMandate mit der Mandatsreferenz (cbc:ID) und der IBAN des Käufers in cac:PayerFinancialAccount ergänzen (UBL).
  2. In CII ram:DirectDebitMandateID in ram:SpecifiedTradePaymentTerms, ram:CreditorReferenceID und ram:PayerPartyDebtorFinancialAccount/ram:IBANID angeben.
  3. Wird nicht per Lastschrift eingezogen, stattdessen Code 58 oder 30 mit dem eigenen Konto verwenden.

Korrigiertes XML (minimales Beispiel von uns)

UBL

<cac:PaymentMeans>
  <cbc:PaymentMeansCode>59</cbc:PaymentMeansCode>
  <cac:PaymentMandate>
    <cbc:ID>MANDAT-2026-001</cbc:ID>
    <cac:PayerFinancialAccount>
      <cbc:ID>DE02120300000000202051</cbc:ID>
    </cac:PayerFinancialAccount>
  </cac:PaymentMandate>
</cac:PaymentMeans>

CII

<ram:ApplicableHeaderTradeSettlement>
  <ram:CreditorReferenceID>DE98ZZZ09999999999</ram:CreditorReferenceID>
  <ram:InvoiceCurrencyCode>EUR</ram:InvoiceCurrencyCode>
  <ram:SpecifiedTradeSettlementPaymentMeans>
    <ram:TypeCode>59</ram:TypeCode>
    <ram:PayerPartyDebtorFinancialAccount>
      <ram:IBANID>DE02120300000000202051</ram:IBANID>
    </ram:PayerPartyDebtorFinancialAccount>
  </ram:SpecifiedTradeSettlementPaymentMeans>
  <ram:SpecifiedTradePaymentTerms>
    <ram:DirectDebitMandateID>MANDAT-2026-001</ram:DirectDebitMandateID>
  </ram:SpecifiedTradePaymentTerms>
</ram:ApplicableHeaderTradeSettlement>

Nur Beispielwerte. Ersetzen oder ergänzen Sie die Elemente in Ihrer Datei; die Reihenfolge der Elemente ist in beiden Syntaxen vorgeschrieben.
