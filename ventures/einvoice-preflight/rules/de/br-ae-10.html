E-Rechnungs-Prüfregel erklärt · EN 16931

BR-AE-10: Umsatzsteuer-Aufschlüsselung „Reverse Charge“ ohne Befreiungsgrund

EnglishFrançaisAlle Regeln

Offizielle Meldung

A VAT breakdown (BG-23) with VAT Category code (BT-118) "Reverse charge" shall have a VAT exemption reason code (BT-121), meaning "Reverse charge" or the VAT exemption reason text (BT-120) "Reverse charge" (or the equivalent standard text in another language).
A VAT Breakdown (BG-23) with VAT Category code (BT-118) "Reverse charge" shall have a VAT exemption reason code (BT-121), meaning "Reverse charge" or the VAT exemption reason text (BT-120) "Reverse charge" (or the equivalent standard text in another language).

Fehler (die Rechnung wird abgewiesen)

Was bedeutet BR-AE-10?

Verwendet die Umsatzsteuer-Aufschlüsselung die Kategorie AE (Steuerschuldnerschaft des Leistungsempfängers, Reverse Charge), muss dieser Eintrag auch einen Befreiungsgrund-Code (BT-121) oder einen Befreiungsgrund-Text (BT-120) enthalten. Die offizielle Meldung erwartet sinngemäß „Reverse charge“; die Prüfung selbst kontrolliert nur, dass eines von beiden vorhanden ist.

Typische Ursachen

  • Die Software setzt die Kategorie AE, hat aber kein Feld für den Befreiungsgrund oder lässt es leer.
  • Der Hinweis „Steuerschuldnerschaft des Leistungsempfängers“ steht nur als freier Text in einer Rechnungsbemerkung statt in der Aufschlüsselung.
  • Der Grund wurde an der Rechnungsposition statt am Aufschlüsselungseintrag angegeben.

Wie behebe ich BR-AE-10?

  1. Diese Regel greift erst, wenn AE bereits gewählt ist; ob Reverse Charge für Ihren Umsatz gilt, ist eine steuerliche Frage, die Sie im Zweifel mit Ihrer Steuerberatung klären.
  2. Ergänzen Sie im AE-Aufschlüsselungseintrag den Code VATEX-EU-AE und/oder den Text „Reverse charge“ bzw. „Steuerschuldnerschaft des Leistungsempfängers“.
  3. Eine Bemerkung für den Käufer können Sie zusätzlich behalten; der Aufschlüsselungseintrag braucht trotzdem seinen eigenen Grund.
