BR-DE-24-a: Kartenzahlung ohne Kartenangaben

EnglishFrançaisAlle Regeln

Offizielle Meldung

Wenn BT-81 "Payment means type code" einen Schlüssel für Kartenzahlungen enthält (48, 54, 55), muss genau BG-18 "PAYMENT CARD INFORMATION" übermittelt werden.
Schweregrad
Fehler (die Rechnung wird abgewiesen)
Geprüft in
UBL, CII
Geschäftsbegriffe
BT-81, BG-18

Was bedeutet BR-DE-24-a?

Enthält eine Zahlungsanweisung einen Code für Kartenzahlung (48, 54 oder 55 in BT-81), muss sie die Gruppe Kartenangaben (BG-18) enthalten. Die amtliche Meldung spricht von genau einer Gruppe, der Test prüft aber nur, dass sie vorhanden ist.

Typische Ursachen

  • Es wurde ein Kartencode gewählt, aber keine Kartendaten exportiert.
  • Die Kartenangaben stehen nur in einer Freitext-Bemerkung.
  • Code 48 wurde für eine Zahlung verwendet, die tatsächlich eine Überweisung oder Lastschrift ist.

Wie behebe ich BR-DE-24-a?

  1. In derselben cac:PaymentMeans cac:CardAccount ergänzen (UBL) bzw. ram:ApplicableTradeSettlementFinancialCard (CII).
  2. Nur die letzten vier bis sechs Ziffern der Kartennummer angeben, nie die vollständige Nummer, dazu das Kartennetz und, falls bekannt, den Karteninhaber.
  3. Wird nicht per Karte gezahlt, den Code der tatsächlichen Zahlungsart verwenden.

Korrigiertes XML (minimales Beispiel von uns)

UBL

<cac:PaymentMeans>  <cbc:PaymentMeansCode>54</cbc:PaymentMeansCode>  <cac:CardAccount>    <cbc:PrimaryAccountNumberID>1234</cbc:PrimaryAccountNumberID>    <cbc:NetworkID>VISA</cbc:NetworkID>    <cbc:HolderName>Erika Mustermann</cbc:HolderName>  </cac:CardAccount></cac:PaymentMeans>

CII

<ram:SpecifiedTradeSettlementPaymentMeans>  <ram:TypeCode>54</ram:TypeCode>  <ram:ApplicableTradeSettlementFinancialCard>    <ram:ID>1234</ram:ID>    <ram:CardholderName>Erika Mustermann</ram:CardholderName>  </ram:ApplicableTradeSettlementFinancialCard></ram:SpecifiedTradeSettlementPaymentMeans>

Nur Beispielwerte. Ersetzen oder ergänzen Sie die Elemente in Ihrer Datei; die Reihenfolge der Elemente ist in beiden Syntaxen vorgeschrieben.
