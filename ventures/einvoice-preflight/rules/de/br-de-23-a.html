BR-DE-23-a: Überweisung ohne Zahlungskonto des Empfängers

EnglishFrançaisAlle Regeln

Offizielle Meldung

Wenn BT-81 "Payment means type code" einen Schlüssel für Überweisungen enthält (30, 58), muss BG-17 "CREDIT TRANSFER" übermittelt werden.
Schweregrad
Fehler (die Rechnung wird abgewiesen)
Geprüft in
UBL, CII
Geschäftsbegriffe
BT-81, BG-17

Was bedeutet BR-DE-23-a?

Enthält eine Zahlungsanweisung einen Code für Überweisung (30 oder 58 in BT-81), muss sie die Gruppe Überweisung (BG-17) enthalten, also das Konto, auf das der Käufer zahlen soll. Geprüft wird jede Zahlungsanweisung einzeln.

Typische Ursachen

  • Die Bankverbindung steht nur auf dem PDF oder in einer Bemerkung, nicht in den strukturierten Zahlungsanweisungen.
  • Code 30 oder 58 wurde als Voreinstellung gewählt, obwohl kein Konto angegeben ist.
  • Das Konto steht an der falschen Stelle, etwa beim Konto des Zahlers statt beim Konto des Empfängers.

Wie behebe ich BR-DE-23-a?

  1. In derselben cac:PaymentMeans cac:PayeeFinancialAccount mit Ihrer IBAN in cbc:ID ergänzen (UBL) bzw. ram:PayeePartyCreditorFinancialAccount mit ram:IBANID (CII).
  2. Kontoinhaber und BIC können in derselben Gruppe mitgegeben werden.
  3. Zahlt der Käufer anders (Karte, Lastschrift), den dazu passenden Code statt 30 oder 58 verwenden.

Korrigiertes XML (minimales Beispiel von uns)

UBL

<cac:PaymentMeans>  <cbc:PaymentMeansCode>58</cbc:PaymentMeansCode>  <cac:PayeeFinancialAccount>    <cbc:ID>DE02120300000000202051</cbc:ID>    <cbc:Name>Beispiel GmbH</cbc:Name>  </cac:PayeeFinancialAccount></cac:PaymentMeans>

CII

<ram:SpecifiedTradeSettlementPaymentMeans>  <ram:TypeCode>58</ram:TypeCode>  <ram:PayeePartyCreditorFinancialAccount>    <ram:IBANID>DE02120300000000202051</ram:IBANID>    <ram:AccountName>Beispiel GmbH</ram:AccountName>  </ram:PayeePartyCreditorFinancialAccount></ram:SpecifiedTradeSettlementPaymentMeans>

Nur Beispielwerte. Ersetzen oder ergänzen Sie die Elemente in Ihrer Datei; die Reihenfolge der Elemente ist in beiden Syntaxen vorgeschrieben.
