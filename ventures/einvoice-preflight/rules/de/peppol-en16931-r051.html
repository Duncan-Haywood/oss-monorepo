PEPPOL-EN16931-R051: Ein Betrag hat eine andere Währung als die Rechnungswährung

EnglishFrançaisAlle Regeln

Offizielle Meldung

All currencyID attributes must have the same value as the invoice currency code (BT-5), except for the invoice total VAT amount in accounting currency (BT-111).
Schweregrad
Fehler (die Rechnung wird abgewiesen)
Geprüft in
UBL
Geschäftsbegriffe
BT-5, BT-111

Was bedeutet PEPPOL-EN16931-R051?

Jeder Betrag in der Rechnung (Preise, Positionsbeträge, Zu- und Abschläge, Umsatzsteuerbeträge und Gesamtsummen) muss eine currencyID tragen, die dem Code der Rechnungswährung (BT-5, cbc:DocumentCurrencyCode) entspricht. Einzige Ausnahme ist der Umsatzsteuer-Gesamtbetrag in Buchungswährung (BT-111): ein zweites cac:TaxTotal ohne Steueraufschlüsselung.

Typische Ursachen

  • Die Rechnung lautet auf eine Währung, aber einige Beträge wurden in der Hauswährung geschrieben, etwa eine USD-Rechnung mit EUR bei den Steuerbeträgen.
  • Der Steuerbetrag in Buchungswährung steht im Haupt-TaxTotal oder hat eine Steueraufschlüsselung und gilt deshalb nicht mehr als BT-111.
  • Ein Tippfehler oder Kleinbuchstaben in einer currencyID, etwa eur oder EURO.

Wie behebe ich PEPPOL-EN16931-R051?

  1. Setzen Sie currencyID bei jedem Betrag auf den Wert von cbc:DocumentCurrencyCode, genau so geschrieben.
  2. Müssen Sie die Umsatzsteuer in Buchungswährung angeben, setzen Sie cbc:TaxCurrencyCode und fügen ein eigenes cac:TaxTotal nur mit cbc:TaxAmount in dieser Währung hinzu, ohne cac:TaxSubtotal.
  3. Durchsuchen Sie die Datei nach currencyID= und prüfen Sie jeden Wert.

Korrigiertes XML (minimales Beispiel von uns)

UBL

<cbc:DocumentCurrencyCode>USD</cbc:DocumentCurrencyCode>
<cbc:TaxCurrencyCode>EUR</cbc:TaxCurrencyCode>
<!-- parties, lines and other elements unchanged -->
<cac:TaxTotal>
  <cbc:TaxAmount currencyID="USD">19.00</cbc:TaxAmount>
  <cac:TaxSubtotal>
    <cbc:TaxableAmount currencyID="USD">100.00</cbc:TaxableAmount>
    <cbc:TaxAmount currencyID="USD">19.00</cbc:TaxAmount>
    <cac:TaxCategory>
      <cbc:ID>S</cbc:ID>
      <cbc:Percent>19</cbc:Percent>
      <cac:TaxScheme>
        <cbc:ID>VAT</cbc:ID>
      </cac:TaxScheme>
    </cac:TaxCategory>
  </cac:TaxSubtotal>
</cac:TaxTotal>
<cac:TaxTotal>
  <cbc:TaxAmount currencyID="EUR">17.48</cbc:TaxAmount>
</cac:TaxTotal>

Nur Beispielwerte. Ersetzen oder ergänzen Sie die Elemente in Ihrer Datei; die Reihenfolge der Elemente ist in beiden Syntaxen vorgeschrieben.
