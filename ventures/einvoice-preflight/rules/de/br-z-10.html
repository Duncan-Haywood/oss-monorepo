E-Rechnungs-Prüfregel erklärt · EN 16931

BR-Z-10: Aufschlüsselung zum Nullsatz darf keinen Befreiungsgrund enthalten

EnglishFrançaisAlle Regeln

Offizielle Meldung

A VAT breakdown (BG-23) with VAT Category code (BT-118) "Zero rated" shall not have a VAT exemption reason code (BT-121) or VAT exemption reason text (BT-120).
A VAT Breakdown (BG-23) with VAT Category code (BT-118) "Zero rated" shall not have a VAT exemption reason code (BT-121) or VAT exemption reason text (BT-120).
Schweregrad
Fehler (die Rechnung wird abgewiesen)

Geschäftsbegriffe
BG-23, BT-118, BT-121, BT-120

Was bedeutet BR-Z-10?

Ein Aufschlüsselungseintrag mit Kategorie Z (Nullsatz) darf weder einen Befreiungsgrund-Code (BT-121) noch einen Befreiungsgrund-Text (BT-120) enthalten. In EN 16931 ist der Nullsatz ein steuerpflichtiger Satz von 0 %, keine Befreiung; deshalb sind die Grundfelder dort nicht erlaubt.

Typische Ursachen

  • Die Software trägt bei jedem 0-%-Eintrag einen Befreiungsgrund ein, unabhängig von der Kategorie.
  • Eine Vorlage für steuerfreie (E) oder Reverse-Charge-Rechnungen (AE) wurde mit Kategorie Z weiterverwendet.
  • Eigentlich wäre eine andere Kategorie richtig gewesen, und Z wurde nur wegen des Satzes von 0 % gewählt.

Wie behebe ich BR-Z-10?

  1. Prüfen Sie, ob Z die gewollte Kategorie ist; welche Kategorie zu Ihrem Umsatz passt, ist eine steuerliche Frage, die Sie im Zweifel mit Ihrer Steuerberatung klären.
  2. Ist Z richtig, löschen Sie TaxExemptionReason und TaxExemptionReasonCode (CII: ram:ExemptionReason und ram:ExemptionReasonCode) aus dem Eintrag.
  3. Möchten Sie den Nullsatz für den Käufer erläutern, nutzen Sie dafür eine Rechnungsbemerkung (BT-22).

Korrigiertes XML (minimales Beispiel von uns)

UBL

<cac:TaxSubtotal>
  <cbc:TaxableAmount currencyID="EUR">250.00</cbc:TaxableAmount>
  <cbc:TaxAmount currencyID="EUR">0.00</cbc:TaxAmount>
  <cac:TaxCategory>
    <cbc:ID>Z</cbc:ID>
    <cbc:Percent>0</cbc:Percent>
    <cac:TaxScheme>
      <cbc:ID>VAT</cbc:ID>
    </cac:TaxScheme>
  </cac:TaxCategory>
</cac:TaxSubtotal>
