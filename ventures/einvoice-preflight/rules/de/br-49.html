E-Rechnungs-Prüfregel erklärt · EN 16931

BR-49: Zahlungsanweisungen ohne Code der Zahlungsart

EnglishFrançaisAlle Regeln

Offizielle Meldung

A Payment instruction (BG-16) shall specify the Payment means type code (BT-81).
Schweregrad
Fehler (die Rechnung wird abgewiesen)
Geprüft in
UBL, CII
Geschäftsbegriffe
BG-16, BT-81

Was bedeutet BR-49?

Jeder Block Zahlungsanweisungen (BG-16) in der Rechnung muss den Code der Zahlungsart (BT-81) aus der Liste UNCL 4461 enthalten, etwa 58 für SEPA-Überweisung, 59 für SEPA-Lastschrift oder 30 für Überweisung.

Typische Ursachen

  • Bankverbindung oder Verwendungszweck wurden angegeben, der Code für die Zahlungsart fehlt aber.
  • Die Zahlungsart steht nur als Text („Überweisung“) und nicht als Code in der Datei.
  • Für eine nicht genutzte Zahlungsart wurde ein leerer PaymentMeans-Block (CII: ram:SpecifiedTradeSettlementPaymentMeans) erzeugt.

Wie behebe ich BR-49?

  1. Legen Sie fest, welche Zahlungsart der Block beschreibt, und ergänzen Sie den Code nach UNCL 4461: cbc:PaymentMeansCode in UBL, ram:TypeCode in CII.
  2. Setzen Sie den Code an den Anfang des Blocks, vor Verwendungszweck und Kontoangaben.
  3. Entfernen Sie nicht benötigte Zahlungsblöcke, statt sie ohne Code stehen zu lassen.

Korrigiertes XML (minimales Beispiel von uns)

UBL

<cac:PaymentMeans>
  <cbc:PaymentMeansCode>58</cbc:PaymentMeansCode>
  <cbc:PaymentID>INV-2026-001</cbc:PaymentID>
  <cac:PayeeFinancialAccount>
    <cbc:ID>DE02120300000000202051</cbc:ID>
  </cac:PayeeFinancialAccount>
</cac:PaymentMeans>

CII

<ram:SpecifiedTradeSettlementPaymentMeans>
  <ram:TypeCode>58</ram:TypeCode>
  <ram:PayeePartyCreditorFinancialAccount>
    <ram:IBANID>DE02120300000000202051</ram:IBANID>
  </ram:PayeePartyCreditorFinancialAccount>
</ram:SpecifiedTradeSettlementPaymentMeans>

Nur Beispielwerte. Ersetzen oder ergänzen Sie die Elemente in Ihrer Datei; die Reihenfolge der Elemente ist in beiden Syntaxen vorgeschrieben.
