E-Rechnungs-Prüfregel erklärt · EN 16931

BR-S-01: Normalsatz-Positionen ohne Umsatzsteuer-Aufschlüsselung zum Normalsatz

EnglishFrançaisAlle Regeln

Offizielle Meldung

An Invoice that contains an Invoice line (BG-25), a Document level allowance (BG-20) or a Document level charge (BG-21) where the VAT category code (BT-151, BT-95 or BT-102) is "Standard rated" shall contain in the VAT breakdown (BG-23) at least one VAT category code (BT-118) equal with "Standard rated".
Schweregrad
Fehler (die Rechnung wird abgewiesen)
Geprüft in
UBL, CII
Geschäftsbegriffe
BG-25, BG-20, BG-21, BT-151, BT-95, BT-102, BG-23, BT-118

Was bedeutet BR-S-01?

Hat eine Rechnungsposition, ein Nachlass oder ein Zuschlag auf Belegebene die Umsatzsteuerkategorie S (Normalsatz), muss die Umsatzsteuer-Aufschlüsselung (BG-23) mindestens einen Eintrag mit Kategorie S enthalten. In der UBL-Fassung prüft die Regel auch umgekehrt: Ein S-Eintrag in der Aufschlüsselung ohne passende Position, Nachlass oder Zuschlag fällt ebenfalls durch.

Typische Ursachen

  • Die Positionen tragen Kategorie S, die Software schreibt die Aufschlüsselung aber mit einem anderen Code (etwa einem internen Code oder E).
  • Die Umsatzsteuer-Aufschlüsselung fehlt ganz oder wurde nur für einen Teil der Steuersätze erzeugt.
  • Eine Position wurde nachträglich auf S (oder von S weg) umgestellt, ohne die Aufschlüsselung neu zu berechnen.

Wie behebe ich BR-S-01?

  1. Prüfen Sie den Steuerkategorie-Code jeder Position, jedes Nachlasses und jedes Zuschlags; die dort gewählte Kategorie muss sich in der Aufschlüsselung wiederfinden.
  2. Legen Sie für jeden verwendeten Normalsatz einen Aufschlüsselungseintrag mit Kategorie S, Bemessungsgrundlage und Steuerbetrag an.
  3. Entfernen Sie S-Einträge, auf die keine Position verweist, und berechnen Sie die Rechnungssummen neu.
