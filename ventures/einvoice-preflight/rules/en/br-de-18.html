BR-DE-18: Early-payment discount (Skonto) line is not in the required format

Skonto Zeilen in müssen diesem regulärem Ausdruck entsprechen: . Die Informationen zur Gewährung von Skonto müssen wie folgt im Element "Payment terms" (BT-20) übermittelt werden: Anzugeben ist im ersten Segment "SKONTO", im zweiten "TAGE=n", im dritten "PROZENT=n". What does BR-DE-18 mean?

XRechnung reads early-payment discounts from the payment terms (BT-20) in a fixed machine-readable form: one line per discount, exactly #SKONTO#TAGE=14#PROZENT=2.00#, optionally with #BASISBETRAG=500.00# before the closing #. Every line of the first payment-terms note that starts with # must match that pattern, and the last discount line must be followed by a line break; free-text lines without a leading # are ignored.

Usual causes

  • The percentage is written without exactly two decimals or with a comma (PROZENT=2 or PROZENT=2,00 instead of PROZENT=2.00).
  • The line uses lower case, spaces inside it or extra text (#Skonto#, #SKONTO# TAGE=14#, "2 % Skonto" after the last #).
  • The last discount line ends the note with no line break after its closing #.
  • Another line in the note starts with # but is not a discount line, for example a comment or reference number.

How do I fix BR-DE-18?

  1. Write each discount on its own line as #SKONTO#TAGE=n#PROZENT=n.nn#, in capitals, with no spaces; TAGE is a whole number of days, PROZENT has a dot and exactly two decimals.
  2. Add #BASISBETRAG=n.nn# (two decimals, before the final #) only when the discount applies to part of the amount due rather than all of it.
  3. End every discount line, including the last one, with a line break; ordinary text may follow on the next line.
  4. Put the lines in the first cbc:Note of cac:PaymentTerms (UBL) or the first ram:Description of ram:SpecifiedTradePaymentTerms (CII), and do not start any other line there with #.

Corrected XML (minimal example we wrote)

UBL

<cac:PaymentTerms>  <cbc:Note>#SKONTO#TAGE=14#PROZENT=2.00##SKONTO#TAGE=30#PROZENT=1.00#BASISBETRAG=500.00#Zahlbar innerhalb von 45 Tagen netto</cbc:Note></cac:PaymentTerms>

CII

<ram:SpecifiedTradePaymentTerms>  <ram:Description>#SKONTO#TAGE=14#PROZENT=2.00##SKONTO#TAGE=30#PROZENT=1.00#BASISBETRAG=500.00#Zahlbar innerhalb von 45 Tagen netto</ram:Description></ram:SpecifiedTradePaymentTerms>

Example values only. Put the elements in place of, or beside, what your file has; element order matters in both syntaxes.
