E-invoice rule explained · XRechnung

BR-DE-10: Delivery address has no city

DeutschFrançaisAll rules

Official message

Das Element "Deliver to city" (BT-77) muss übermittelt werden, wenn die Gruppe "DELIVER TO ADDRESS" (BG-15) übermittelt wird.
Severity
Error (the invoice is rejected)
Checked in
UBL, CII
Business terms
BT-77, BG-15

What does BR-DE-10 mean?

If the invoice gives a deliver-to address (BG-15), XRechnung requires it to include a city (BT-77). An invoice without a delivery address is not affected by this rule.

Usual causes

  • Only a street or a building name was entered for the delivery address.
  • The software writes an empty delivery address block even when nothing was delivered elsewhere.
  • City and post code were typed into one address line.

How do I fix BR-DE-10?

  1. Add the city of the delivery place: cbc:CityName in cac:Delivery/cac:DeliveryLocation/cac:Address (UBL) or ram:CityName in ram:ShipToTradeParty/ram:PostalTradeAddress (CII).
  2. Complete the post code (BR-DE-11) and country code at the same time.
  3. If goods were not delivered to a different address, leave the delivery address out altogether rather than sending an incomplete one.

Corrected XML (minimal example we wrote)

UBL

<cac:Delivery>  <cbc:ActualDeliveryDate>2026-11-20</cbc:ActualDeliveryDate>  <cac:DeliveryLocation>    <cac:Address>      <cbc:StreetName>Lagerstraße 7</cbc:StreetName>      <cbc:CityName>Potsdam</cbc:CityName>      <cbc:PostalZone>14467</cbc:PostalZone>      <cac:Country>        <cbc:IdentificationCode>DE</cbc:IdentificationCode>      </cac:Country>    </cac:Address>  </cac:DeliveryLocation></cac:Delivery>

CII

<ram:ApplicableHeaderTradeDelivery>  <ram:ShipToTradeParty>    <ram:Name>Example Authority, warehouse</ram:Name>    <ram:PostalTradeAddress>      <ram:PostcodeCode>14467</ram:PostcodeCode>      <ram:LineOne>Lagerstraße 7</ram:LineOne>      <ram:CityName>Potsdam</ram:CityName>      <ram:CountryID>DE</ram:CountryID>    </ram:PostalTradeAddress>  </ram:ShipToTradeParty></ram:ApplicableHeaderTradeDelivery>

Example values only. Put the elements in place of, or beside, what your file has; element order matters in both syntaxes.
