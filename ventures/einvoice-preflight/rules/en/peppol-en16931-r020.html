PEPPOL-EN16931-R020: Seller electronic address is missing

DeutschFrançaisAll rules

Official message

Seller electronic address MUST be provided
Severity
Error (the invoice is rejected)
Checked in
UBL, CII
Business terms
BT-34

What does PEPPOL-EN16931-R020 mean?

Peppol requires the Seller electronic address (BT-34): your own Peppol endpoint, so the buyer and the network know where the invoice comes from and where to send responses. In UBL it is cbc:EndpointID in the seller party, with a schemeID from the Peppol EAS code list; in CII it is ram:URIUniversalCommunication/ram:URIID in ram:SellerTradeParty.

Usual causes

  • Your company settings in the invoicing software have no Peppol ID filled in.
  • The software does not export the seller endpoint because it is optional in plain EN 16931.
  • Your Peppol ID was only configured at the access point provider and never written into the invoice.

How do I fix PEPPOL-EN16931-R020?

  1. Find your Peppol participant ID (your access point provider registered it); it is a scheme code plus an identifier, for example 9930 with your German VAT number or 0088 with your GLN.
  2. Add it as the first element of the seller party: cbc:EndpointID with schemeID (UBL), or ram:URIUniversalCommunication/ram:URIID with schemeID (CII).
  3. Store it in your company settings so every invoice carries it.

Corrected XML (minimal example we wrote)

UBL

<cac:AccountingSupplierParty>
  <cac:Party>
    <cbc:EndpointID schemeID="9930">DE123456789</cbc:EndpointID>
    <cac:PartyName>
      <cbc:Name>Example Seller GmbH</cbc:Name>
    </cac:PartyName>
  </cac:Party>
</cac:AccountingSupplierParty>

CII

<ram:SellerTradeParty>
  <ram:Name>Example Seller GmbH</ram:Name>
  <ram:URIUniversalCommunication>
    <ram:URIID schemeID="9930">DE123456789</ram:URIID>
  </ram:URIUniversalCommunication>
</ram:SellerTradeParty>

Example values only. Put the elements in place of, or beside, what your file has; element order matters in both syntaxes.
