E-invoice rule explained · EN 16931

BR-AE-10: Reverse charge VAT breakdown has no exemption reason

DeutschFrançaisAll rules

Official message

A VAT breakdown (BG-23) with VAT Category code (BT-118) "Reverse charge" shall have a VAT exemption reason code (BT-121), meaning "Reverse charge" or the VAT exemption reason text (BT-120) "Reverse charge" (or the equivalent standard text in another language).
A VAT Breakdown (BG-23) with VAT Category code (BT-118) "Reverse charge" shall have a VAT exemption reason code (BT-121), meaning "Reverse charge" or the VAT exemption reason text (BT-120) "Reverse charge" (or the equivalent standard text in another language).
Severity
Error (the invoice is rejected)
Checked in
UBL, CII
Business terms
BG-23, BT-118, BT-121, BT-120

What does BR-AE-10 mean?

When the VAT breakdown uses category AE (reverse charge), that entry must also carry an exemption reason code (BT-121) or an exemption reason text (BT-120). The official message expects it to say "Reverse charge"; the check itself only tests that one of the two is present.

Usual causes

  • The software sets category AE but has no field for the exemption reason, or leaves it empty.
  • The reverse charge wording was printed in a free-text note on the invoice instead of in the VAT breakdown.
  • The reason was put on the invoice line, not on the VAT breakdown entry.

How do I fix BR-AE-10?

  1. This rule only applies once AE has been chosen; whether reverse charge applies to your sale is a tax question, so ask your tax adviser if unsure.
  2. In the AE breakdown entry, add the code VATEX-EU-AE and/or the text "Reverse charge" (or the standard wording in the invoice language).
  3. If you keep a note for the buyer, keep it as well; the breakdown entry still needs its own reason.

<ram:ApplicableTradeTax>  <ram:CalculatedAmount>0.00</ram:CalculatedAmount>  <ram:TypeCode>VAT</ram:TypeCode>  <ram:ExemptionReason>Reverse charge</ram:ExemptionReason>  <ram:BasisAmount>1000.00</ram:BasisAmount>  <ram:CategoryCode>AE</ram:CategoryCode>  <ram:ExemptionReasonCode>VATEX-EU-AE</ram:ExemptionReasonCode>  <ram:RateApplicablePercent>0</ram:RateApplicablePercent></ram:ApplicableTradeTax>

Example values only. Put the elements in place of, or beside, what your file has; element order matters in both syntaxes.
