BR-DE-9: Buyer post code is missing

DeutschFrançaisAll rules

Official message

Das Element "Buyer post code" (BT-53) muss übermittelt werden.
Severity
Error (the invoice is rejected)
Checked in
UBL, CII
Business terms
BT-53

What does BR-DE-9 mean?

XRechnung requires the buyer's postal address to include a post code (BT-53), which plain EN 16931 leaves optional. The check fails when the post code is absent or contains only spaces.

Usual causes

  • The customer record has no post code, or it is typed into the city field.
  • A PO box or internal mail code was entered instead and the post code left out.
  • The buyer is abroad in a country without post codes.

How do I fix BR-DE-9?

  1. Put the buyer's post code in its own field: cbc:PostalZone in the buyer's cac:PostalAddress (UBL) or ram:PostcodeCode in the buyer's ram:PostalTradeAddress (CII).
  2. Take the address the buyer gave for invoices, for a public buyer usually from the order or its invoicing instructions.
  3. If the buyer's country has no post codes, ask the buyer what to send, since the rule has no exception for that case.

Corrected XML (minimal example we wrote)

UBL

<cac:AccountingCustomerParty>  <cac:Party>    <cac:PostalAddress>      <cbc:StreetName>Amtsweg 5</cbc:StreetName>      <cbc:CityName>Bonn</cbc:CityName>      <cbc:PostalZone>53111</cbc:PostalZone>      <cac:Country>        <cbc:IdentificationCode>DE</cbc:IdentificationCode>      </cac:Country>    </cac:PostalAddress>  </cac:Party></cac:AccountingCustomerParty>

CII

<ram:BuyerTradeParty>  <ram:Name>Example Authority</ram:Name>  <ram:PostalTradeAddress>    <ram:PostcodeCode>53111</ram:PostcodeCode>    <ram:LineOne>Amtsweg 5</ram:LineOne>    <ram:CityName>Bonn</ram:CityName>    <ram:CountryID>DE</ram:CountryID>  </ram:PostalTradeAddress></ram:BuyerTradeParty>

Example values only. Put the elements in place of, or beside, what your file has; element order matters in both syntaxes.
