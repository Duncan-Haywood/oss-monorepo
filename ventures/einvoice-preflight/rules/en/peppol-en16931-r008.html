E-invoice rule explained · Peppol BIS

PEPPOL-EN16931-R008: The document contains an empty element

DeutschFrançaisAll rules

Official message

Document MUST not contain empty elements.
Severity
Error (the invoice is rejected)
Checked in
UBL

What does PEPPOL-EN16931-R008 mean?

Peppol does not allow empty elements anywhere in a UBL invoice: every element must have either child elements or some text. An element that holds only spaces, or only attributes such as a currency or scheme, also counts as empty. If a value is unknown, the element must be left out entirely.

Usual causes

  • The software writes every field of its template, including ones with no value, such as <cbc:Note/> or <cbc:AccountingCost></cbc:AccountingCost>.
  • An element was given an attribute but no value, for example an endpoint with a schemeID and no address.
  • A field contains only spaces or line breaks.

How do I fix PEPPOL-EN16931-R008?

  1. Find the empty element(s) named in the validation report and remove them, or fill them with the real value.
  2. Set your export to leave out optional fields that have no value instead of writing them empty.
  3. Check elements that carry attributes too: an element with a schemeID or currencyID still needs a value.

Corrected XML (minimal example we wrote)

UBL

<cbc:Note>Thank you for your order.</cbc:Note><cbc:DocumentCurrencyCode>EUR</cbc:DocumentCurrencyCode>

Example values only. Put the elements in place of, or beside, what your file has; element order matters in both syntaxes.
