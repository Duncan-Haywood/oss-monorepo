BR-DE-25-a: Direct debit without direct debit information

DeutschFrançaisAll rules

Official message

Wenn BT-81 "Payment means type code" einen Schlüssel für Lastschriften enthält (59), muss genau BG-19 "DIRECT DEBIT" übermittelt werden.
Severity
Error (the invoice is rejected)
Checked in
UBL, CII
Business terms
BT-81, BG-19

What does BR-DE-25-a mean?

When a payment means uses the direct debit code 59 in BT-81, the invoice must carry the direct debit group (BG-19). In UBL that is a cac:PaymentMandate inside the same payment means; in CII it is enough that a mandate reference, a creditor identifier or a debited account IBAN is present. The official message says exactly one, but the test only checks presence.

Usual causes

  • Code 59 was chosen but the mandate details were not exported.
  • The mandate reference is only written in a note or the payment terms text.
  • Code 59 was used for an invoice the buyer will actually pay by transfer.

How do I fix BR-DE-25-a?

  1. Add cac:PaymentMandate with the mandate reference (cbc:ID) and the buyer's IBAN in cac:PayerFinancialAccount to the same cac:PaymentMeans (UBL).
  2. In CII give ram:DirectDebitMandateID in ram:SpecifiedTradePaymentTerms, ram:CreditorReferenceID and ram:PayerPartyDebtorFinancialAccount/ram:IBANID.
  3. If you do not collect by direct debit, use code 58 or 30 with your own account instead.

Corrected XML (minimal example we wrote)

UBL

<cac:PaymentMeans>
  <cbc:PaymentMeansCode>59</cbc:PaymentMeansCode>
  <cac:PaymentMandate>
    <cbc:ID>MANDAT-2026-001</cbc:ID>
    <cac:PayerFinancialAccount>
      <cbc:ID>DE02120300000000202051</cbc:ID>
    </cac:PayerFinancialAccount>
  </cac:PaymentMandate>
</cac:PaymentMeans>

CII

<ram:ApplicableHeaderTradeSettlement>
  <ram:CreditorReferenceID>DE98ZZZ09999999999</ram:CreditorReferenceID>
  <ram:InvoiceCurrencyCode>EUR</ram:InvoiceCurrencyCode>
  <ram:SpecifiedTradeSettlementPaymentMeans>
    <ram:TypeCode>59</ram:TypeCode>
    <ram:PayerPartyDebtorFinancialAccount>
      <ram:IBANID>DE02120300000000202051</ram:IBANID>
    </ram:PayerPartyDebtorFinancialAccount>
  </ram:SpecifiedTradeSettlementPaymentMeans>
  <ram:SpecifiedTradePaymentTerms>
    <ram:DirectDebitMandateID>MANDAT-2026-001</ram:DirectDebitMandateID>
  </ram:SpecifiedTradePaymentTerms>
</ram:ApplicableHeaderTradeSettlement>

Example values only. Put the elements in place of, or beside, what your file has; element order matters in both syntaxes.
