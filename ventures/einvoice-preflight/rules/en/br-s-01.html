E-invoice rule explained · EN 16931

BR-S-01: Standard-rated lines but no standard-rated VAT breakdown

DeutschFrançaisAll rules

Official message

An Invoice that contains an Invoice line (BG-25), a Document level allowance (BG-20) or a Document level charge (BG-21) where the VAT category code (BT-151, BT-95 or BT-102) is "Standard rated" shall contain in the VAT breakdown (BG-23) at least one VAT category code (BT-118) equal with "Standard rated".
Severity
Error (the invoice is rejected)
Checked in
UBL, CII
Business terms
BG-25, BG-20, BG-21, BT-151, BT-95, BT-102, BG-23, BT-118

What does BR-S-01 mean?

If any invoice line, document-level allowance or document-level charge has VAT category S (standard rated), the VAT breakdown (BG-23) must contain at least one entry with category S. In the UBL version the check also works the other way round: an S entry in the breakdown with no S line, allowance or charge fails as well.

Usual causes

  • The lines carry category S, but the software wrote the VAT breakdown with a different code (for example a local code or E).
  • The VAT breakdown was left out or built only for some of the rates on the invoice.
  • A line was changed to S (or away from S) after the totals were calculated, and the breakdown was not rebuilt.

How do I fix BR-S-01?

  1. Check the VAT category code on every line, allowance and charge; the code chosen there is what the breakdown must reflect.
  2. Add one VAT breakdown entry with category S for each standard rate used, with its taxable amount and tax amount.
  3. Remove any S breakdown entry that no line, allowance or charge refers to, then recalculate the invoice totals.

Corrected XML (minimal example we wrote)

UBL

<cac:TaxTotal>
  <cbc:TaxAmount currencyID="EUR">19.00</cbc:TaxAmount>
  <cac:TaxSubtotal>
    <cbc:TaxableAmount currencyID="EUR">100.00</cbc:TaxableAmount>
    <cbc:TaxAmount currencyID="EUR">19.00</cbc:TaxAmount>
    <cac:TaxCategory>
      <cbc:ID>S</cbc:ID>
      <cbc:Percent>19</cbc:Percent>
      <cac:TaxScheme>
        <cbc:ID>VAT</cbc:ID>
      </cac:TaxScheme>
    </cac:TaxCategory>
  </cac:TaxSubtotal>
</cac:TaxTotal>
<cac:InvoiceLine>
  <cbc:ID>1</cbc:ID>
  <cbc:InvoicedQuantity unitCode="HUR">1</cbc:InvoicedQuantity>
  <cbc:LineExtensionAmount currencyID="EUR">100.00</cbc:LineExtensionAmount>
  <cac:Item>
    <cbc:Name>Consulting</cbc:Name>
    <cac:ClassifiedTaxCategory>
      <cbc:ID>S</cbc:ID>
      <cbc:Percent>19</cbc:Percent>
      <cac:TaxScheme>
        <cbc:ID>VAT</cbc:ID>
      </cac:TaxScheme>
    </cac:ClassifiedTaxCategory>
  </cac:Item>
  <cac:Price>
    <cbc:PriceAmount currencyID="EUR">100.00</cbc:PriceAmount>
  </cac:Price>
</cac:InvoiceLine>

Example values only. Put the elements in place of, or beside, what your file has; element order matters in both syntaxes.
