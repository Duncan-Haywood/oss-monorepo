PEPPOL-EN16931-R010: Buyer electronic address is missing

DeutschFrançaisAll rules

Official message

Buyer electronic address MUST be provided
Severity
Error (the invoice is rejected)
Checked in
UBL, CII
Business terms
BT-49

What does PEPPOL-EN16931-R010 mean?

Peppol requires the Buyer electronic address (BT-49): the buyer's Peppol endpoint, the address the network delivers the invoice to. In UBL it is cbc:EndpointID in the buyer party, with a schemeID from the Peppol EAS code list; in CII it is ram:URIUniversalCommunication/ram:URIID in ram:BuyerTradeParty.

Usual causes

  • The software does not export the buyer's endpoint because it is optional in plain EN 16931.
  • The buyer's e-mail address or a customer number was put elsewhere and no endpoint was entered.
  • The customer record in the software has no Peppol ID yet.

How do I fix PEPPOL-EN16931-R010?

  1. Ask the buyer for its Peppol participant ID, or look it up in the Peppol directory. It has two parts: a scheme code and the identifier, for example 0204 with a Leitweg-ID or 9930 with a German VAT number.
  2. Add it as the first element of the buyer party: cbc:EndpointID with the scheme code in schemeID (UBL), or ram:URIUniversalCommunication/ram:URIID with schemeID (CII).
  3. Use only scheme codes from the EAS list; other Peppol rules reject unknown codes.

Corrected XML (minimal example we wrote)

UBL

<cac:AccountingCustomerParty>
  <cac:Party>
    <cbc:EndpointID schemeID="0204">04011000-12345-34</cbc:EndpointID>
    <cac:PartyName>
      <cbc:Name>Example Buyer GmbH</cbc:Name>
    </cac:PartyName>
  </cac:Party>
</cac:AccountingCustomerParty>

CII

<ram:BuyerTradeParty>
  <ram:Name>Example Buyer GmbH</ram:Name>
  <ram:URIUniversalCommunication>
    <ram:URIID schemeID="0204">04011000-12345-34</ram:URIID>
  </ram:URIUniversalCommunication>
</ram:BuyerTradeParty>

Example values only. Put the elements in place of, or beside, what your file has; element order matters in both syntaxes.
