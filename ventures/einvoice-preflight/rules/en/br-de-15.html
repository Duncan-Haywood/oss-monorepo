E-invoice rule explained · XRechnung

BR-DE-15: Buyer reference (Leitweg-ID) is missing

DeutschFrançaisAll rules

Official message

Das Element "Buyer reference" (BT-10) muss übermittelt werden.
Severity
Error (the invoice is rejected)
Checked in
UBL, CII
Business terms
BT-10

What does BR-DE-15 mean?

XRechnung requires the Buyer reference (BT-10) on every invoice. For German public buyers this field carries the Leitweg-ID, the routing number that tells the receiving platform which authority the invoice is for.

Usual causes

  • The invoicing software leaves BT-10 empty because it is optional in plain EN 16931.
  • The Leitweg-ID was typed into a note, the order reference (BT-13) or the buyer's name instead of BT-10.
  • A template made for private customers was used for a public buyer.

How do I fix BR-DE-15?

  1. Ask the buyer for the reference they expect; a public buyer gives you its Leitweg-ID with the order.
  2. Put it in cbc:BuyerReference (UBL) or ram:BuyerReference inside ram:ApplicableHeaderTradeAgreement (CII).
  3. For a private German buyer with no Leitweg-ID, agree another reference (for example their order number) and send that.

Corrected XML (minimal example we wrote)

UBL

<cbc:BuyerReference>04011000-12345-34</cbc:BuyerReference>

CII

<ram:ApplicableHeaderTradeAgreement>  <ram:BuyerReference>04011000-12345-34</ram:BuyerReference></ram:ApplicableHeaderTradeAgreement>

Example values only. Put the elements in place of, or beside, what your file has; element order matters in both syntaxes.
