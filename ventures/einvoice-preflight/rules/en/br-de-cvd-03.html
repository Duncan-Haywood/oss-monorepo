E-invoice rule explained · XRechnung

BR-DE-CVD-03: No invoice line identifies the clean vehicle

DeutschFrançaisAll rules

Official message

In einer Rechnung muss mindestens eine INVOICE LINE (BG-25) enthalten sein, in der der Scheme identifier von "Item classification identifier" (BT-158) den Wert 'CVD' und der "Item attribute name" (BT-160) den Wert 'cva' enthält.
Severity
Error (the invoice is rejected)
Checked in
UBL, CII
Business terms
BG-25, BT-158, BT-160

What does BR-DE-CVD-03 mean?

An invoice that declares the XRechnung Clean Vehicles (CVD) extension in BT-24 must have at least one invoice line whose item has both a classification code with scheme identifier CVD (BT-158) and an item attribute named cva (BT-160). That line is how the buyer's systems find the vehicle to report.

Usual causes

  • The vehicle line has no item classification, or one with another scheme (for example a CPV code) instead of CVD.
  • The attribute name is written differently, for example CVA or clean vehicle; the test compares it exactly with lower-case cva.
  • The classification and the attribute were put on two different lines instead of the same one.

How do I fix BR-DE-CVD-03?

  1. On the line that invoices the vehicle, add an item classification code with listID CVD and the vehicle category (M1, M2, M3, N1, N2 or N3).
  2. On the same line, add an item attribute with name cva and value clean, zero-emission or other.
  3. If no line is about a vehicle under the Clean Vehicles Directive, use the normal XRechnung identifier in BT-24 instead of the CVD one.

Corrected XML (minimal example we wrote)

UBL

<cac:Item>  <cbc:Name>Electric city bus, 12 m</cbc:Name>  <cac:CommodityClassification>    <cbc:ItemClassificationCode listID="CVD">M3</cbc:ItemClassificationCode>  </cac:CommodityClassification>  <cac:AdditionalItemProperty>    <cbc:Name>cva</cbc:Name>    <cbc:Value>zero-emission</cbc:Value>  </cac:AdditionalItemProperty></cac:Item>

CII

<ram:SpecifiedTradeProduct>  <ram:Name>Electric city bus, 12 m</ram:Name>  <ram:ApplicableProductCharacteristic>    <ram:Description>cva</ram:Description>    <ram:Value>zero-emission</ram:Value>  </ram:ApplicableProductCharacteristic>  <ram:DesignatedProductClassification>    <ram:ClassCode listID="CVD">M3</ram:ClassCode>  </ram:DesignatedProductClassification></ram:SpecifiedTradeProduct>

Example values only. Put the elements in place of, or beside, what your file has; element order matters in both syntaxes.
