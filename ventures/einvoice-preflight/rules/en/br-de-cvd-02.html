BR-DE-CVD-02: Tender or lot reference is missing on a Clean Vehicles invoice

DeutschFrançaisAll rules

Official message

Das Element "Tender or lot reference" (BT-17) muss übermittelt werden.
Severity
Error (the invoice is rejected)
Checked in
UBL, CII
Business terms
BT-17

What does BR-DE-CVD-02 mean?

On an invoice that declares the XRechnung Clean Vehicles (CVD) extension in BT-24, the tender or lot reference (BT-17) must be filled in: the number of the procurement procedure or lot the vehicle was awarded under. Invoices with the ordinary XRechnung identifier are not checked by this rule.

Usual causes

  • The procurement or lot number was not taken over from the tender documents.
  • It was put in the contract reference (BT-12) or a note only.
  • In CII, an additional referenced document was added but without type code 50, or with an empty number.

How do I fix BR-DE-CVD-02?

  1. Look up the procedure or lot number in the buyer's tender documents or award notice.
  2. In UBL, put it in cac:OriginatorDocumentReference/cbc:ID.
  3. In CII, add a ram:AdditionalReferencedDocument in ram:ApplicableHeaderTradeAgreement with the number in ram:IssuerAssignedID and ram:TypeCode 50.

Corrected XML (minimal example we wrote)

UBL

<cac:OriginatorDocumentReference>  <cbc:ID>VG-2026-117-LOS-2</cbc:ID></cac:OriginatorDocumentReference>

CII

<ram:ApplicableHeaderTradeAgreement>  <ram:BuyerReference>04011000-12345-34</ram:BuyerReference>  <ram:AdditionalReferencedDocument>    <ram:IssuerAssignedID>VG-2026-117-LOS-2</ram:IssuerAssignedID>    <ram:TypeCode>50</ram:TypeCode>  </ram:AdditionalReferencedDocument></ram:ApplicableHeaderTradeAgreement>

Example values only. Put the elements in place of, or beside, what your file has; element order matters in both syntaxes.
