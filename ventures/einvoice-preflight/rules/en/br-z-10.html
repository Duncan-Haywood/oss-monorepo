E-invoice rule explained · EN 16931

BR-Z-10: Zero-rated VAT breakdown must not have an exemption reason

DeutschFrançaisAll rules

Official message

A VAT breakdown (BG-23) with VAT Category code (BT-118) "Zero rated" shall not have a VAT exemption reason code (BT-121) or VAT exemption reason text (BT-120).
A VAT Breakdown (BG-23) with VAT Category code (BT-118) "Zero rated" shall not have a VAT exemption reason code (BT-121) or VAT exemption reason text (BT-120).
Severity
Error (the invoice is rejected)
Checked in
UBL, CII

BG-23, BT-118, BT-121, BT-120

What does BR-Z-10 mean?

A VAT breakdown entry with category Z (zero rated) must not contain an exemption reason code (BT-121) or exemption reason text (BT-120). In EN 16931 zero rating is a taxable rate of 0 %, not an exemption, so the reason fields are not allowed there.

Usual causes

  • The software fills in an exemption reason for every 0 % entry, whatever the category.
  • A template made for exempt (E) or reverse charge (AE) invoices was reused with category Z.
  • The category should have been a different one and Z was picked because the rate is 0 %.

How do I fix BR-Z-10?

  1. Check that Z is the category you meant; which category fits your sale is a tax question, so ask your tax adviser if unsure.
  2. If Z is right, delete TaxExemptionReason and TaxExemptionReasonCode (CII: ram:ExemptionReason and ram:ExemptionReasonCode) from that breakdown entry.
  3. If you want to explain the zero rate to the buyer, use an invoice note (BT-22) instead.

Corrected XML (minimal example we wrote)

UBL

<cac:TaxSubtotal>
  <cbc:TaxableAmount currencyID="EUR">250.00</cbc:TaxableAmount>
  <cbc:TaxAmount currencyID="EUR">0.00</cbc:TaxAmount>
  <cac:TaxCategory>
    <cbc:ID>Z</cbc:ID>
    <cbc:Percent>0</cbc:Percent>
    <cac:TaxScheme>
      <cbc:ID>VAT</cbc:ID>
    </cac:TaxScheme>
  </cac:TaxCategory>
</cac:TaxSubtotal>

Example values only. Put the elements in place of, or beside, what your file has; element order matters in both syntaxes.
