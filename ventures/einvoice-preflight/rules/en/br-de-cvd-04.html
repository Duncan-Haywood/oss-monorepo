BR-DE-CVD-04: Vehicle category code is not an allowed value

DeutschFrançaisAll rules

Official message

Ein "Item classification identifier" (BT-158) mit dem Scheme identifier 'CVD' muss einen Wert aus der Liste der zulässigen Fahrzeugkategorien enthalten.
Severity
Error (the invoice is rejected)
Checked in
UBL, CII
Business terms
BT-158

What does BR-DE-CVD-04 mean?

On an invoice that declares the XRechnung Clean Vehicles (CVD) extension in BT-24, every item classification code with scheme identifier CVD (BT-158) must be one of the vehicle categories M1, M2, M3, N1, N2 or N3. Roughly, M1 is a passenger car, M2 and M3 are buses, N1 is a light commercial vehicle and N2 and N3 are heavier trucks.

Usual causes

  • A description such as bus or truck was entered instead of the category code.
  • The code is in lower case (m1) or has an extra character (M-1, N 2); only surrounding spaces are ignored.
  • A category outside the list, for example L for two-wheelers or O for trailers, was used with the CVD scheme.

How do I fix BR-DE-CVD-04?

  1. Take the vehicle's EU category from its registration or type-approval papers.
  2. Enter exactly one of M1, M2, M3, N1, N2, N3 as the code, keeping listID CVD.
  3. If the item is not a vehicle covered by these categories, do not classify it with the CVD scheme.

Corrected XML (minimal example we wrote)

UBL

<cac:CommodityClassification>
  <cbc:ItemClassificationCode listID="CVD">M3</cbc:ItemClassificationCode>
</cac:CommodityClassification>

CII

<ram:DesignatedProductClassification>
  <ram:ClassCode listID="CVD">M3</ram:ClassCode>
</ram:DesignatedProductClassification>

Example values only. Put the elements in place of, or beside, what your file has; element order matters in both syntaxes.
