E-invoice rule explained · XRechnung

BR-DE-CVD-06-b: Line with a cva attribute needs exactly one CVD vehicle category

DeutschFrançaisAll rules

Official message

Wenn "Item attribute name" (BT-160) mit dem Wert 'cva' angegeben ist, muss in derselben Rechnungszeile genau ein "Item classification identifier" (BT-158) mit dem Scheme identifier 'CVD' vorhanden sein.
Severity
Error (the invoice is rejected)
Checked in
UBL, CII
Business terms
BT-158, BT-160

What does BR-DE-CVD-06-b mean?

On an invoice that declares the XRechnung Clean Vehicles (CVD) extension in BT-24, any line whose item has an attribute named cva (BT-160) must also have exactly one classification code with scheme CVD (BT-158). None fails, and so do two or more on the same line.

Usual causes

  • The cva attribute was added but the vehicle category classification was forgotten.
  • The category was given with another scheme identifier, or with none, instead of listID CVD.
  • Two CVD classifications were put on one line, for example for two vehicles invoiced together.

How do I fix BR-DE-CVD-06-b?

  1. On each line with a cva attribute, add exactly one item classification code with listID CVD and the category M1, M2, M3, N1, N2 or N3.
  2. If one line covers vehicles of different categories, split it into one line per category.
  3. If the line is not a vehicle, remove the cva attribute instead.

Corrected XML (minimal example we wrote)

UBL

<cac:Item>
  <cbc:Name>Electric city bus, 12 m</cbc:Name>
  <cac:CommodityClassification>
    <cbc:ItemClassificationCode listID="CVD">M3</cbc:ItemClassificationCode>
  </cac:CommodityClassification>
  <cac:AdditionalItemProperty>
    <cbc:Name>cva</cbc:Name>
    <cbc:Value>zero-emission</cbc:Value>
  </cac:AdditionalItemProperty>
</cac:Item>

CII

<ram:SpecifiedTradeProduct>
  <ram:Name>Electric city bus, 12 m</ram:Name>
  <ram:ApplicableProductCharacteristic>
    <ram:Description>cva</ram:Description>
    <ram:Value>zero-emission</ram:Value>
  </ram:ApplicableProductCharacteristic>
  <ram:DesignatedProductClassification>
    <ram:ClassCode listID="CVD">M3</ram:ClassCode>
  </ram:DesignatedProductClassification>
</ram:SpecifiedTradeProduct>

Example values only. Put the elements in place of, or beside, what your file has; element order matters in both syntaxes.
