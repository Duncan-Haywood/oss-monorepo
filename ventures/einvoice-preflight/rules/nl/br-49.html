E-factuurregel uitgelegd · EN 16931

BR-49: Betaalinstructies zonder code voor het betaalmiddel

EnglishDeutschFrançaisAlle regels

Officiële melding

A Payment instruction (BG-16) shall specify the Payment means type code (BT-81).
Ernst
Fout (de factuur wordt geweigerd)
Gecontroleerd in
UBL, CII
Bedrijfstermen
BG-16, BT-81

Wat betekent BR-49?

Elk blok met betaalinstructies (BG-16) in de factuur moet de typecode van het betaalmiddel (BT-81) uit de lijst UNCL 4461 vermelden, bijvoorbeeld 58 voor een SEPA-overschrijving, 59 voor een SEPA-domiciliëring (incasso) of 30 voor een overschrijving.

Gebruikelijke oorzaken

  • Er staan bankgegevens of een betalingskenmerk, maar de code die zegt hoe betaald wordt, ontbreekt.
  • De betaalwijze staat alleen als tekst ("Overschrijving") en niet als code.
  • Er is een leeg PaymentMeans-blok (CII: ram:SpecifiedTradeSettlementPaymentMeans) aangemaakt voor een betaalwijze die niet gebruikt wordt.

Hoe los ik BR-49 op?

  1. Bepaal welke betaalwijze het blok beschrijft en voeg de UNCL 4461-code toe: cbc:PaymentMeansCode in UBL, ram:TypeCode in CII.
  2. Zet de code vooraan in het blok, vóór het betalingskenmerk en de rekeninggegevens.
  3. Verwijder blokken met betaalinstructies die u niet nodig hebt, in plaats van ze zonder code te laten staan.

Gecorrigeerde XML (minimaal voorbeeld van ons)

UBL

<cac:PaymentMeans>  <cbc:PaymentMeansCode>58</cbc:PaymentMeansCode>  <cbc:PaymentID>INV-2026-001</cbc:PaymentID>  <cac:PayeeFinancialAccount>    <cbc:ID>DE02120300000000202051</cbc:ID>  </cac:PayeeFinancialAccount></cac:PaymentMeans>

CII

<ram:SpecifiedTradeSettlementPaymentMeans>  <ram:TypeCode>58</ram:TypeCode>  <ram:PayeePartyCreditorFinancialAccount>    <ram:IBANID>DE02120300000000202051</ram:IBANID>  </ram:PayeePartyCreditorFinancialAccount></ram:SpecifiedTradeSettlementPaymentMeans>
