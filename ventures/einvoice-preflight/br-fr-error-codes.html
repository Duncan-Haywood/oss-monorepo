BR-FR error codes in English

France's approved platforms check every invoice against the BR-FR rules (AFNOR XP Z12-012, the "Flux 2" controls) and every life-cycle status message against BR-FR-CDV. FNFE-MPE publishes these rules with French messages only. Below are all 195 rule codes from FNFE-MPE's Schematron 1.4.0.04, each with an English translation made for this tool beside FNFE's French. Have a file? The checker runs the same rules in your browser and reports each finding in English.

Reading a BR-FR code

A code such as BR-FR-08/BT-23 names the rule (BR-FR-08) and the EN 16931 business term it checks (BT-23, the business process, which France uses for its billing frameworks B1, S1, M1 and so on). EXT-FR-FE- terms are France's extensions to EN 16931, and MDT- and MDG- terms belong to the CDAR status message. A platform may quote the code with its own wording; the code is what to look up here.

The empty "" in some messages is where FNFE's Schematron prints the value from your file; the checker's report names the element's path instead. See also the France mandate page and the EN 16931 rule reference.

Common questions

What is a BR-FR error?

BR-FR rules are the French controls (AFNOR XP Z12-012, the "Flux 2" controls) that approved platforms (plateformes agréées, PA) apply to invoices exchanged under France's e-invoicing reform, on top of the EN 16931 rules. FNFE-MPE publishes them as Schematron files with French messages; a platform that rejects an invoice usually quotes the code, such as BR-FR-08/BT-23.

Is this the official English text?

No. FNFE-MPE publishes the messages in French only. The English on this page was translated for this tool from FNFE-MPE's BR-FR Schematron and is shown beside the French original, which remains the reference. A platform may word its own rejection differently.

Can I check an invoice against these rules before sending it?

Yes. Open the checker, tick "Also apply the French rules" and "official Schematron", and drop a UBL, CII or Factur-X file, or a CDAR status message. The BR-FR rules run in your browser, the file is not uploaded, and each finding is shown in English with FNFE-MPE's French under it.
