SdI error codes explained

The 64 codes Italy's Sistema di Interscambio can put in a rejection receipt (ricevuta di scarto, a file ending in _NS_001.xml), read from the Agenzia delle Entrate's technical specification 1.9 (Allegato A, Appendix 1) and put in plain English. For each: what SdI refused, how to fix it, and whether a file-only check can catch it before you send. Have a receipt? Drop it into the checker with the invoice and it explains every code and says whether the checker reproduces it on that file.

Reading a receipt

SdI answers every file it receives. A rejection (NS) means the invoice counts as not issued; fix it and send it under a new file name, because SdI refuses a name it has already seen (00002). A delivery receipt (RC) means the invoice passed SdI's checks and reached the buyer. A could-not-deliver receipt (MC) means it passed but SdI could not reach the buyer's channel and put it in the buyer's reserved area. For public bodies there are also the buyer's outcome (NE: EC01 accepted, EC02 refused, with the buyer's reason), the deadline notice (DT) and the transmission attestation (AT).

A receipt's Hash is the SHA-256 of the file SdI received. The checker compares it with the invoice you drop beside it, so you know whether you are looking at exactly the file SdI saw.

Rule ids such as IT-003 are this tool's own, listed in the Italy page and the rule reference. Tested on 33 public SdI receipts and notices: the Agenzia's example messages and the receipts AgID's EeISI project received in 2019, including a real 00305 rejection that the checker reproduces on the rejected file.

Common questions

What is an SdI ricevuta di scarto?

It is the rejection receipt Italy's Sistema di Interscambio sends back when a FatturaPA file fails one of its checks. Its file name ends in _NS_ and a number, and its ListaErrori gives one five-digit code per fault. Under the Agenzia delle Entrate's technical specification 1.9 (section 1.6) a rejected invoice counts as not issued.

Which SdI errors can I catch before sending?

The format errors (00200) and most content errors (00400 to 00476) can be seen in the file itself, and this checker raises them offline. Errors that depend on the tax register (00300 to 00326), SdI's archive (00404) or the signature (00100 to 00107) cannot be seen in a file; for tax ids the checker catches only numbers that fail their check digit.

Can I check an SdI receipt with this tool?

Yes. Drop the receipt (NS, RC, MC, NE, DT or AT) into the checker, together with the invoice if you have it. Each error code is explained in English, the receipt is paired with the invoice by file name or SHA-256 hash, and each code is marked as reproduced or not by the checker on that file.
