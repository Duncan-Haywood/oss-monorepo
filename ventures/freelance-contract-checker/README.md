# Freelance Contract Checker

**Live tool:** <https://duncan-haywood.github.io/monorepo-projects/freelance-contract-checker/>

Free, private browser tool for freelancers and independent contractors: paste the client agreement or statement of work and see the common ways it costs the signer money (net 60 or pay-when-paid, no deposit, unlimited revisions, IP assigned before payment, non-compete, no pay on cancellation, uncapped indemnity), each with the change to ask for.

Open `index.html`. Tests: `node --test 'ventures/freelance-contract-checker/**/*.test.mjs'`.

Not legal advice. It reads wording with fixed rules and does not decide fairness or enforceability. See `VENTURE.yaml`.
