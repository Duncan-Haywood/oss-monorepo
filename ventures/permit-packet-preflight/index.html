Permit packet preflight

Cities bounce incomplete residential permit packets, and each bounce costs weeks. Paste your city's published checklist (one item per line), choose the files in your packet, and see which lines have no matching file.



Questions


How do I check a permit packet against the city's checklist?


Paste the checklist the building department publishes, one item per line, then choose your packet's files or type their names. Each checklist line is matched to a file name by keyword overlap, and lines with no matching file are listed as missing.


Does it read my plans or PDFs?


No. It only compares file names to checklist lines. A mislabelled file can pass and an oddly named one can fail, and it does not review any sheet. Files never leave your browser.


Why is no city's checklist built in?


Requirements differ by city and change, so a built-in list could be wrong. Use the one your city publishes; only the city decides whether a packet is complete.


What does "weak match" or "closest file" mean?


A weak match is a file that matched a line with a score under 0.6, so check it. A closest file scored at least half of the 0.4 threshold but not enough to count; rename it if it is the right one. A file matching two lines is flagged as a possible combined set.


Can I run it from the command line?


Yes: node cli.mjs checklist.txt ./packet-folder exits with code 1 when a required line has no file. It is free and MIT licensed.
