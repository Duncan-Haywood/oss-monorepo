      The model, and what it leaves out

      • Headings are free text: HubSpot's wizard lets you map any column to a property, so an unrecognised heading is a note, not an error. The tool shows which headings it recognises as default properties (First Name, Email, Phone Number, Lifecycle Stage, Create Date and so on) and which you will map by hand.
      • Email is the identity: rows that share an email become one contact and later rows overwrite earlier values. Rows with no email cannot be matched, so importing the same file twice creates the contacts twice. The tool finds both.
      • Dropdown values: Lifecycle Stage must be one of HubSpot's eight stages, by label or internal name. Lead Status is checked against the default values and only warns, because accounts can add their own.
      • Dates: a date column must be one format. Day-first and month-first mixed in one column is an error; a column where every date is ambiguous is a note to choose the format in the wizard.
      • Numbers: Annual Revenue and Number of Employees take plain digits, with no currency symbol, separators or suffix.
      • Excel damage: phone numbers in scientific notation are unrecoverable and flagged; postal codes and phones that lost a leading zero are flagged but never rewritten, because the tool cannot know the original.
      • Safe fixes change only the separator, stray spaces, a mailto: prefix, upper-case in emails, a currency symbol or thousands comma in the two number properties, and exact duplicate rows. It never edits the letters of a name, a company, a phone number, a postal code, a date or a lifecycle stage.
      • Not checked: that HubSpot will accept the file today, that a contact already exists in your account, that your custom properties and dropdown values exist, whether the people agreed to be emailed, and anything HubSpot changes in its importer. Import a handful first.

      Common questions

      Why did my HubSpot contacts import fail or create duplicates?

      The usual causes are an email column holding two addresses or a note, the same email on several rows (HubSpot merges them into one contact), a Lifecycle Stage that is not one of HubSpot's stages, dates that mix day-first and month-first, numbers written with currency symbols, and an Excel save that turned phone numbers into scientific notation. A file with no email column at all is imported as brand new contacts every time. This tool tests each of these and names the line.

      How do I check a HubSpot contacts CSV before importing it?

      Paste the file or drop it onto this page. It maps your headings to HubSpot's default contact properties, then lists every problem with its line number as errors, warnings and notes. Nothing is uploaded.

      Does HubSpot de-duplicate contacts on import?

      HubSpot uses the email address to match a row to an existing contact, so rows that share an email become one contact and later rows overwrite earlier values for the same property. Rows with no email cannot be matched and are created as new contacts each time. This tool lists every shared email with its line numbers and can download them as a review file.

      Which Lifecycle Stage values does HubSpot accept?

      Subscriber, Lead, Marketing Qualified Lead, Sales Qualified Lead, Opportunity, Customer, Evangelist and Other, or the internal names such as marketingqualifiedlead. A value such as Hot lead is not a stage and is left blank or blocks the mapping. The tool flags it and never rewrites it, because it cannot know which stage you meant.

      Why are my dates wrong after a HubSpot import?

      The import wizard reads a date column in one format. A column that has 14/03/2026 on one row and 03/14/2026 on another cannot be read consistently, and a column where every date has a day and month of 12 or under is ambiguous: 03/04/2026 is 3 April or 4 March depending on the source system. The tool detects both cases.

      Why did my phone numbers turn into 4.41175E+11?

      Excel stored a long number in a cell formatted as General or Number and shortened it. The lost digits cannot be recovered from the file, so the tool flags the cell as an error and leaves it alone. Re-export from the source with the column set to Text.

      What does Apply safe fixes change?

      Only things with one reasonable reading: the separator, stray spaces in any cell, a mailto: prefix on an email, upper-case letters in an email address, a currency symbol or thousands comma in Annual Revenue or Number of Employees, and exact duplicate rows. It never edits the letters of a name, a company, a phone number, a postal code, a date or a lifecycle stage.

      Is it safe to put my contact list into a web page?

      The page runs in your browser, the file is read locally and nothing is uploaded; a test in the code asserts there are no network calls. Your own policies, and any consent your contacts gave, still decide what you may open and import.

      What does this not check?

      Whether HubSpot will accept the file today, whether a contact already exists in your account, whether your custom properties and dropdown values exist, whether your contacts agreed to receive marketing email, and anything HubSpot changes in its importer. A clean result is not a promise of success: import a handful of contacts first.
