Questions

What is job shop scheduling?

Each job is a list of operations that must run in a fixed order, each on a given machine for a given time. A machine runs one operation at a time. The question is the order each machine should take its operations in so that the whole set of jobs finishes as early as possible; that finishing time is the makespan.

Is the schedule optimal?

When the page says proved, yes: either the schedule meets a lower bound no schedule can beat, or (on small shops) an exhaustive search finished. Otherwise it shows the best schedule found and the proved lower bound, so you can see the largest possible gap. The how-it-works page lists how it did on 162 published benchmark instances.

Can I use standard benchmark files?

Yes. The page reads the OR-Library and JSPLIB format (a line with the job and machine counts, then one line per job of machine and time pairs, machines numbered from 0) and Taillard's format (times, then machines numbered from 1), as well as a plain job, machine, time table.

Is my shop data uploaded?

No. Every calculation runs in your browser. An optional anonymous counter in this browser's local storage records only that a schedule ran and the day.
