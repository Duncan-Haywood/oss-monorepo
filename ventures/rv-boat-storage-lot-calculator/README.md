# RV and Boat Storage Lot Calculator

**Live tool:** <https://duncan-haywood.github.io/monorepo-projects/rv-boat-storage-lot-calculator/>

Free, private browser tool for people planning an outdoor RV, boat and trailer storage lot: acres, land, surfacing and permit cost, rent per space, occupancy, lease-up, operating costs and a loan become the number of spaces, NOI, yield on cost, debt coverage, break-even occupancy, the rent for a target yield, a monthly lease-up with payback, and the equity IRR if you sell.

After using this, you know whether a lot pays back its build cost, how full it has to get to cover the loan, and how much cash to hold in reserve during lease-up.

Open `index.html`. Tests: `node --test 'ventures/rv-boat-storage-lot-calculator/**/*.test.mjs'`.
