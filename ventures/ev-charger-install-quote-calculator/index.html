What it does, and what it leaves to you

    
    
      
  • Counts: required ampacity and breaker = 125% of charger amps, breaker rounded up to the next standard size; conductor = smallest copper size whose 75 C table ampacity covers it (12 to 1 AWG); voltage drop = 2 x 12.9 x amps x one-way feet / circular mils; the conductor steps up until the drop is 3% or less.
    • 
      
  • Panel: service amps minus the existing demand you enter minus the charger's 125% load. The existing demand must come from your own load calculation.
    • 
      
  • Price: cost = (charger + conductor per foot x run + materials + permit + labor) x (1 + overhead); price = cost / (1 - margin).
    • 
      
  • Not decided: the adopted code edition and local amendments, conductor type and temperature derating, conduit fill and burial depth, grounding, GFCI and disconnect requirements, load-management rules, utility rebates and interconnection, aluminum conductors, and whether the charger's manual requires more.

Common questions

    
How do you size a circuit for an EV charger?

    
An EV charger is a continuous load, so the breaker and conductors are sized at 125% of the charger's rated amps. A 32 A charger needs a 40 A circuit, a 48 A charger needs 60 A. This worksheet does that arithmetic and picks the next standard breaker size; your adopted code and the charger's manual decide.

    
How much does it cost to quote an EV charger install?

    
Add the charger if you supply it, conductor by the foot, breaker and fittings, permit, and labor that grows with the run, then overhead. Price divides cost by one minus your target margin, so a 30% margin on $700 of cost is $1,000, not $910.

    
What is voltage drop and why does it change the wire size?

    
Current through a long run loses voltage along the conductor. This page works it out as 2 x 12.9 x amps x one-way feet / circular mils for copper and steps the conductor up until the drop is within 3%, a common design target. It is guidance, not a code requirement for every branch circuit.

    
Does the panel have room for the charger?

    
Enter the service size and the existing demand from your own load calculation. The page subtracts the charger's 125% load and flags when little or nothing is left, which is when load management or a service upgrade comes into the quote.

    
Is my data uploaded anywhere?

    
No. Everything is calculated in your browser and nothing is sent; a test in the code asserts there are no network calls.
