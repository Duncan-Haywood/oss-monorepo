# EV Charger Install Quote Calculator

Free, private browser tool for electricians and electrical contractors quoting home and small-commercial EV charger installs: charger amps and run length become the breaker and copper conductor at 125% of a continuous load, the voltage drop and the wire size that keeps it within 3%, panel headroom against the service, and a price at a target margin, with the price at other margins and longer runs.

After using this, you can quote an EV charger install in a minute with the circuit, voltage drop and panel room checked and the margin held, which used to take a spreadsheet and a calculator.

Open `index.html`. Tests: `node --test 'ventures/ev-charger-install-quote-calculator/**/*.test.mjs'`.
