# Open House Plans: a free house plan generator that hands you the whole plan set

Describe a home in a sentence ("3 bed 2 bath farmhouse, 1,400 sq ft, porch") or a JSON brief, and Open House Plans lays it out, sizes the framing, checks it, prices it and exports everything a designer or builder would want to start from: a floor plan, four elevations, a 3D view, a CAD file (DXF), a BIM model (IFC4), a 3D model (OBJ), a bill of materials, schedules and the design as data. Every generated plan is **public domain (CC0 1.0)**: use it, change it, sell it, build from it. It runs in a browser, from a command line, or as a tool an AI agent calls.

**Live page:** https://duncan-haywood.github.io/oss-monorepo/open-house-plans/

> **Not for construction.** The plans are generated by software. They have not been reviewed by a licensed architect or engineer or checked against any building code. Before anyone builds from one you need a licensed review (or your local code's prescriptive path), site, soils and energy design, and a permit.

## What it makes

| | |
|---|---|
| Programs | studio to 5 bedrooms, 1 to 3.5 baths, 300 to 3,200 sq ft, optional 1- or 2-car attached garage, porch, accessible option (36 in doors, 42 in hall, a bath with a 5 ft turning circle) |
| Styles | modern farmhouse, craftsman bungalow, modern shed roof, classic ranch (hip roof), storybook cottage, budget minimal |
| Optimises for | lowest cost, balanced, or looks and light |
| Site and climate | lot width and depth with setbacks, roof snow load, wind speed, regional cost factor |
| Construction | slab or crawlspace; advanced (2x6 at 24 in) or conventional (2x4 at 16 in) framing; roof trusses |

Each plan set holds 18 files:

| File | What it is |
|---|---|
| `sheet.svg` | one-page presentation sheet: 3D view, plan, two elevations, title block |
| `plan.svg`, `plan.dxf` | dimensioned floor plan with doors, windows, fixtures and furniture; the DXF is AutoCAD R12, inches, on layers (A-WALL, A-DOOR, A-GLAZ, A-FIXT, A-FURN, A-ANNO-TEXT, A-ANNO-DIMS) |
| `elevations.svg`, `view.svg` | front, rear and side elevations at one scale; a 3D view |
| `model.ifc` | IFC4 BIM model: walls, slab, roof, windows and doors filling openings that void the walls, and an IfcSpace with its area for every room (metres) |
| `model.obj`, `model.mtl` | the same 3D model for Blender, SketchUp and others (metres, y up) |
| `framing.svg` | every wall's framing elevation: each stud, king, jack, header ply, rough sill, cripple and plate at its real length, marked and dimensioned on layout, all walls at one scale |
| `lumber-order.csv`, `framing-cuts.csv` | the wall framing order (boards of each size and length, precut studs, any engineered header) and the cut list with the board every piece comes out of |
| `bom.csv` | bill of materials: studs, plates, headers, trusses, sheathing, roofing, foundation, insulation, drywall, fixtures, porch |
| `openings.csv`, `rooms.csv`, `cost.csv` | window and door schedule, room schedule, cost by stage |
| `design.json` | the brief and the whole design as data (rooms, walls, openings, parameters, checks) |
| `README.md`, `LICENSE.txt` | the design's summary, checks and limits; the CC0 dedication |

A catalogue of twelve ready-made designs, from a backyard studio to a five-bedroom farmhouse, is in [`catalogue/`](catalogue/) and on the page.

## Use it

**In a browser:** open the live page, type what you want, press *Design it*, and download the `.zip`. Nothing is uploaded.

**From a command line** (Node 18+, no install, no dependencies):

```bash
cd ventures/open-house-plans
node cli.mjs design --text "3 bed 2 bath craftsman, 1500 sq ft, crawlspace"          # summary
node cli.mjs design --beds 4 --baths 2.5 --garage 2 --style ranch --out my-house --zip   # the plan set
node cli.mjs design --brief brief.json --json                                          # JSON for scripts
node cli.mjs parse "two bedroom cottage with a porch on a 50 ft lot"                   # see how a sentence is read
```

**From an AI agent:** see [`AGENTS.md`](AGENTS.md). In short, the repository's tool runner and MCP server expose the engine:

```bash
node platform/agents/tools.mjs call open-house-plans design --input '{"beds":3,"style":"modern","priority":"beauty"}'
node platform/agents/tools.mjs run open-house-plans -- design --text "4 bed ranch with garage" --out house --zip
```

The same brief always produces the same house, byte for byte, so a brief is a complete, shareable description of a design.

## How it works

1. **Brief** (`brief.mjs`). Every field is optional and is clamped with a note saying what changed. Plain English is read by deterministic keyword rules (no model); an agent with a language model should write the JSON brief itself.
2. **Layout** (`layout.mjs`). A single-storey rectangle on a 6 in grid, laid out as zones along the street front: an optional garage, a great room (living, kitchen, dining), and a bedroom wing with a hall and a row of rooms on each side, optionally ending in a full-depth primary suite (bedroom, bath, walk-in closet); a split plan puts the suite on the other side of the great room. Studios and one-bedrooms stack the bedroom, bath and laundry beside the great room instead. Bedrooms get reach-in closets; laundry sits with the water heater and air handler; with a garage they move to a mudroom and the garage.
3. **Search** (`search.mjs`). It enumerates footprints (depth 20 to 36 ft, width to hit the area within -7% to +10%), zone widths, hall position, which rooms go in which row and order, suite size and orientation, then the great room's layout and kitchen size and side: 2,500 candidates for two bedrooms, 38,000 for three, 75,000 for five, in 0.1 to 0.7 s. Each is scored on modelled cost, distance from the asked area, room sizes and proportions against comfortable minimums, plumbing spread, hall area, footprint and roof proportion, front-facade symmetry, window rhythm and glazing, and daylight, weighted by the priority. The best skeletons get doors and windows and are rescored with the facade terms.
4. **Openings** (`openings.mjs`). Walls are derived from the rooms (a 6 in unit with one room on it is an outside wall, with two a partition, or nothing for open plan). Doors follow the circulation links; every bedroom gets egress casements sized to its style; living rooms get the style's big windows, falling back to smaller ones where they do not fit; the kitchen gets a window over the sink and a packed run (fridge, sink, dishwasher, range) with an L or an island where 3.5 ft aisles fit.
5. **Structure and takeoff** (`structure.mjs`, `takeoff.mjs`). Headers, studs, floor joists and girders are checked with NDS allowable-stress formulas ported from [`research/house-spans`](../../research/house-spans) and [`research/house-framing`](../../research/house-framing) and pinned to them by tests. Trusses are listed for the truss maker to design.
5b. **Wall framing, stud by stud** (`framing.mjs`, added 2026-11-01). Like the [Shed Designer](../shed-designer/), every wall is framed member by member, by the [Wall Framing Takeoff](../wall-framing-takeoff/) engine (vendored byte for byte as `wft-*.mjs` by `vendor-framing.mjs`; a test fails when the copy drifts). `framing.mjs` reads the plan the way a framer does: the front and back walls run full width and the sides fit between them; partitions run between wall faces and put a tee (backing studs, or ladder blocking with advanced framing) in the wall they meet, or nail to a door's kings when they land on one; rough openings are a door plus 2 in by 2-1/2 in, a window plus 1/2 in; windows under 12 in apart are one mulled opening whose header is sized again for the combined span; a header that does not fit under the plate lowers the head, with a note; an engineered (LVL) header is drawn at 2x12 depth and listed for the supplier, not cut from boards. Studs are the ceiling's precut (92-5/8, 104-5/8 or 116-5/8 in); everything else comes from 8 to 20 ft boards, chosen by Gilmore-Gomory cutting stock against relative prices (a foot of board costs the same to 16 ft and an assumed 15% more at 18 and 20 ft), so the order counts boards, not dollars.
6. **Checks** (`checks.mjs`). Program, room sizes, ceiling height, hall width, glazing, emergency escape windows, egress door, circulation (every room reachable, no bedroom through another), kitchen fit, structure, a bracing proxy, and accessibility when asked. Room and egress rules are paraphrased from the 2021 IRC by section number; the code text is copyrighted and was not copied.
7. **Cost** (`cost.mjs`). Anchored on NAHB's *Cost of Constructing a Home in 2024* (Eye on Housing, 2025-01-23): $428,215 construction cost for the average 2,647 sq ft house, split over eight stages. Each stage is scaled by this design's own drivers (footprint, perimeter, wall and roof area, openings, plumbing fixtures, partitions, framed floor) against an assumed reference house. The driver splits, the reference geometry, the porch, foundation and finish factors are assumptions written out in the file. 2024 dollars, US average unless you set a regional factor.
8. **Model and drawings** (`model3d.mjs`, `views.mjs`, `plan-draw.mjs`, `draw.mjs`, `ifc.mjs`). One 3D model of convex solids (walls cut around openings, trim, glass, roof prisms, porch) feeds the OBJ, the IFC, the axonometric view and the elevations; hidden surfaces are ordered with Newell's plane tests. The plan is drawn once as primitives and written to both SVG and DXF.

## Verification

- `node --test` in this directory: 33 tests, about 30 s. They include every program from a studio to five bedrooms with every bath count, 0 to 2-car garages, accessible or not (150 briefs), and every style and priority on slab and crawlspace, each required to produce a plan whose rooms tile the footprint exactly, whose openings sit inside their walls without overlapping, whose kitchen appliances fit, and which passes every rule check; determinism; plain-English parsing; the cost model reproducing its NAHB anchor exactly on the reference geometry; and the file formats (IFC references, OBJ indices, DXF structure, CSV headers, zip CRCs against Node's zlib).
- **The structure port agrees with the research code to 1e-9** on 294 cases (span checks across sizes, spacings, load cases and spans; maximum spans; sizing; stud and header checks), from `data/structure-fixture.json`, which `python3 verify/structure_fixture.py` writes by running the Python originals.
- **Independent readers** (`python3 verify/check_files.py <bundle>`, with IfcOpenShell 0.9.0 and ezdxf 1.4.5). On all twelve catalogue designs: IfcOpenShell parses every IFC as IFC4 with **0 schema-validation errors**, its geometry kernel builds **every** product's solid (26 to 115 per file, 0 failures), spaces match rooms by name and count, and every outside opening voids a wall and is filled by a window or door; ezdxf reads and audits every DXF with 0 errors; every OBJ face index is valid. Output: [`data/verify.txt`](data/verify.txt).
- **The page in a browser** (headless Chromium): the first design renders in 0.4 s, the examples and settings work, the zip downloads with 15 files (18 since 2026-11-01) that Python's `zipfile` tests clean, and the console shows no errors.
- **Wall framing** (`framing.test.mjs`): 24 programs (0 to 5 bedrooms, both framing schemes, with and without a garage) frame every solid wall, none left out, and every laid-out wall passes the engine's own self-check (`verifyWall`: no member leaves the wall, no two members overlap); the order covers the cut list and lands within 2% of the cutting-stock lower bound. A wider sweep of 144 briefs (every style too) found two kinds of overlap that the test now pins: a partition landing on a door's framing (now nailed to the kings) and, in the Wall Framing Takeoff engine itself, ladder blocking drawn over a stud that sits on the tee's layout mark (fixed there, with its own regression test).
- `node build-catalogue.mjs --check` (also a test) confirms the committed catalogue is what the engine makes today.

## What the engine says about cost

From [`data/study.txt`](data/study.txt) (`node verify/study.mjs`). All figures are the anchored model, not quotes.

- **Size is the big lever per square foot.** A 3-bed/2-bath minimal house models at $221/sq ft at 1,092 sq ft and $162/sq ft at 2,176 sq ft; the total rises from $241k to $352k.
- **Style costs more than layout.** For one program (3 bed, 2 bath, 1,400 sq ft, 50 x 28 ft), the modern farmhouse (9:12 roof, full-width porch) models at $214/sq ft and the budget minimal (4:12 roof, entry porch) at $196, 9% apart. The full-width porch alone is $19k (6.5%).
- **Layout barely moves modelled cost.** Across the 2,600 to 7,700 rule-passing layouts of each brief, the chosen design's cost per sq ft is within 2% of the median one; the search earns its score on room sizes, area, plumbing, hall and facade. This is partly a limit of the model, which cannot see pipe-run length or partition complexity beyond a partition-length term.
- **Other single choices** on that farmhouse: a crawlspace +8.5%, a two-car garage +13.6%, premium finishes +7.7%, basic finishes -3.3%, 8 ft instead of 9 ft ceilings -0.9%.
- **Advanced framing** uses 12% to 15% less wall lumber than conventional 2x4 at 16 in on the same plans (wall studs, plates and headers only), in line with [`research/house-framing`](../../research/house-framing).

### Do these findings survive the cost model's assumptions?

The model has one sourced anchor; the rest (how each stage splits over its drivers, the reference house's geometry, the porch and foundation factors) is assumed. [`verify/sensitivity.mjs`](verify/sensitivity.mjs) draws 500 sets of those assumptions (every driver weight scaled by 0.5 to 1.5 and renormalised, the reference house's storeys, glazing, fixtures, wall height, pitch and garage over plausible ranges, the factors widened by half) and reprices fixed designs. From [`data/sensitivity.txt`](data/sensitivity.txt), 5th to 95th percentile:

| Finding | As built | 5th to 95th |
|---|---|---|
| $/sq ft at 1,000 against 2,200 sq ft asked | 1.36x | 1.32x to 1.44x |
| Farmhouse over minimal, $/sq ft | 9.3% | 6.5% to 12.3% |
| Full-width porch on the farmhouse | $19,413 | $10,539 to $28,215 |
| Crawlspace over slab | 8.5% | 5.0% to 11.0% |
| Two-car garage | 13.6% | 11.6% to 14.5% |
| Widest $/sq ft spread across 2,896 rule-passing 3-bed layouts (areas differ by up to 17%) | 7.2% | 6.6% to 8.4% |

Every finding keeps its sign and rough size; the porch is the least certain number, because it rests on one assumed factor.

## Limitations

- **Single storey, rectangular footprints.** No second floor, stairs, L or U shapes, basements or bonus rooms. Wide programs get long houses (the five-bedroom with a garage is 98 ft).
- **Layout rules are a designer's heuristics, written as code.** The room minimums, the scoring weights and the beauty terms (symmetry, rhythm, glazing band) are choices, not findings; the room and egress rules are paraphrased from the IRC from section numbers and were not checked against the code text; the "bracing proxy" is not the IRC's braced-wall calculation.
- **Wall framing is walls only.** The stud-by-stud order covers wall studs, plates, headers, sills, cripples and tee and corner backing; not floor framing, trusses, sheathing, fire blocking or the steel plate ties a single top plate needs (the notes count them). Lumber prices are not used: the order is in boards.
- **Structure is partial.** Headers, studs, joists and girders are checked; trusses, lateral bracing, hold-downs, foundations and connections are not designed. Design values are SPF No. 2 as reprinted by NELMA (house-spans' README).
- **Costs are a model.** One survey anchor, assumed driver splits and assumed factors; no local prices, labour rates, site costs, fees or land. Accessibility shows no cost because the model does not see door widths.
- **Files.** The IFC holds walls, slab, roof, openings, windows, doors and spaces, not studs; it has been read by IfcOpenShell, not yet opened in a commercial BIM tool. The DXF is plan only. Clerestory glass in the modern style is drawn and modelled but not counted as glazing in the checks.
