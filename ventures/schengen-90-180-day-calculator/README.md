# Schengen 90/180 Day Calculator

Free, private browser tool: paste your past Schengen stays and see days used and left in the rolling 180-day window, when allowance returns, and the longest trip (with last permitted exit date) from a planned entry date.

**Live tool:** https://duncan-haywood.github.io/monorepo-projects/schengen-90-180-day-calculator/

After using this, you know the last day you can legally stay and the earliest day a longer trip becomes possible, which used to mean counting calendar squares by hand.

Open `index.html`. Tests: `node --test 'ventures/schengen-90-180-day-calculator/**/*.test.mjs'`.
