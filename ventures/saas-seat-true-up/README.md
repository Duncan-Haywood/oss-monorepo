# SaaS Seat True-Up Calculator

Find unused software seats before a renewal or true-up. Enter the seats purchased, active users, billing cadence, and price per seat to see avoidable spend, overage exposure, and a copyable renewal brief. It is a fast local planning tool for operations, finance, and IT teams; it does not connect to a vendor or upload an employee roster.

```bash
python3 -m http.server 4173 --directory ventures/saas-seat-true-up
```

Open `http://localhost:4173`. Everything runs in the browser. Your numbers are stored only in local storage, and anonymous feature counts are local and optional; no accounts, cookies, analytics vendor, or network calls are used.
