Retail analytics that respects shoppers.

A privacy-first analytics stack for very small stores. The first target is a roughly 10 m² leather boutique in Italy. It turns sample edge and point-of-sale events into SQLite-backed reports.

What it does

  • TypeScript monorepo (pnpm) on Node 22+ with built-in SQLite; pnpm bootstrap loads sample events and builds a report.
  • A demo portal that walks through business value, overview, SKU gaps, experiments and a privacy gate. Its numbers are illustrative demo data unless you connect the local KPI server.
  • A documentation site and commercial-viability write-ups, written as TSX pages in the repository.

Status

Prototype. No live store data is shown here. Whether a small store would pay for it is untested.

Run it yourself

git clone https://github.com/Duncan-Haywood/oss-monorepo
cd oss-monorepo/ventures/retail-pilot-intel

The README in that folder has the full steps.
