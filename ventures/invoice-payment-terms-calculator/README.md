# Invoice Payment Terms Calculator

Free browser tool for freelancers and small service businesses. Enter an invoice amount, terms, late-rate assumption, and outstanding invoices to get the due date, cash-flow exposure, 30/60/90-day scenarios, and copyable payment-terms wording.

## Run

Serve this directory with `python3 -m http.server` and open `index.html`. It has no build step, account, network request, or API key.

## Privacy and usage

Calculations and optional saved drafts stay in the browser. There are no accounts, cookies, uploads, or analytics vendor. The optional anonymous local counter records only feature names and can be disabled in the footer. Saved drafts can be loaded for repeat invoice reviews and are never sent anywhere.
