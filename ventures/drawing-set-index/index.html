What you get

The sheet index lists one row per page: sheet number, title, discipline and sheet type (the US National CAD Standard's designators, so S-201 is Structural, Elevations), the page and the file it came from, sorted the way the NCS binds a set. The set check flags pages with no number, numbers used twice, numbers out of order within a discipline, a discipline split across the set, and, when the cover sheet has a drawing index, sheets it lists that are not in the set, sheets in the set it leaves out and titles that disagree. The comparison matches the two issues by sheet number and shows sheets added, removed and retitled, and the notes, labels and callouts whose text changed on each sheet.

Questions

How do I make a sheet index from a drawing set PDF?

Choose the set's PDF, or every sheet's PDF at once. The tool finds each sheet's number and title in its title block and lists them in binding order. Download the CSV for the cover sheet, a transmittal or a document log.

How does it find the sheet number?

On a drawing sheet the number is the largest ID-shaped text in the title block, at the same spot on every sheet, while callouts citing other sheets are small and scattered. Each page's candidates are scored by size and position, then the set votes for the title block's number cell. The title is the largest text near the number that is not repeated on most sheets (firm, project, address) and is not a date, scale or field label; the title block's ruled cells keep a project name stacked above the title out of it.

What does the comparison show, and what does it miss?

Sheets added, removed and retitled, and the text added or removed on every sheet in both issues. Plot stamps and issue dates are ignored. It compares text, not linework: a moved wall with no changed note shows as the same text. Use it to find where to look, then overlay the two sheets in your PDF viewer.

Is my drawing set uploaded?

No. The PDF is read by code running in this tab; nothing is sent anywhere.

How accurate is it?

On 123 single-sheet PDFs whose file names carry the sheet number and title, from public architecture projects on GitHub, it read 121 numbers right (98.4%) and 115 number-and-title pairs (93.5%); three of the misses are file names that disagree with the sheet itself. On 14 whole sets (180 pages) it found a number on all 172 pages with a text layer, and matched all 25 sheets with file-name truth. These are mostly one office's Revit sets, so check the list against your set. How it was checked.

Can I run it on my own machine?

Yes. It is FSL-1.1-MIT-licensed, has no dependencies and runs from a folder: node cli.mjs set.pdf --csv index.csv or node cli.mjs --compare old.pdf new.pdf. Source on GitHub.
