This calculator vs. Qdrant's own pricing page

Two different jobs: Qdrant's pricing page documents Qdrant's own plans -- self-hosted, Qdrant Cloud, and hybrid -- and how Qdrant bills for its own service. This page estimates the storage footprint of one workload and prices it identically across Qdrant and other vector database providers, side by side, using the rates you paste in.

What each tool is for

Qdrant's pricing page is Qdrant's own documentation of its plans -- including the option to self-host for infrastructure cost alone, or run Qdrant Cloud on a usage-based tier -- and how those units are billed for Qdrant specifically. It answers "what would this workload cost on Qdrant" for Qdrant alone, using Qdrant's own current numbers. Qdrant's own site is not reachable from this session to confirm today's specific plan names, unit prices, or free-tier limits, so no dollar figure for Qdrant appears anywhere on this page — only its well-documented identity and category are stated here.

This calculator does a different, narrower job: it does not describe any single vendor's plan structure. You type in your vector count, embedding dimension, and any per-vector metadata size once; it computes the resulting storage footprint in gigabytes, including an index-overhead multiplier you set yourself rather than one this tool assumes on your behalf. You then paste in the storage and query rates quoted by up to three providers — Qdrant included, if you want it in the comparison — and it totals a monthly estimate for each, ranked cheapest first. It runs free in any browser, keeps no account, and nothing you type is uploaded.

Different jobs, and most people evaluating a vector database eventually use both.
