Questions

Is this real VR?

No headset needed and none supported yet. It is a 3D room drawn with CSS that you walk through with the keyboard or by dragging, on a laptop or a phone. It feels like a small virtual office; it is not a WebXR app.

Where are my tasks stored?

Only in this browser's local storage. Nothing is sent to a server of ours. Export the board as JSON to back it up or move it to another device.

Does voice input send my audio anywhere?

Voice uses your browser's built-in speech recognition. Some browsers, Chrome among them, send the audio to the browser maker's speech service to transcribe it. The page only receives the text. If you'd rather not, type instead: the commands are the same.

How does the GitHub import work?

Give it a public repository. The page asks GitHub's public API for the 40 most recently updated pull requests: drafts become in-progress tasks, open ones in-review, merged ones done. Branches named claude/…, codex/… or copilot/… go to a desk for that agent; other pull requests go to their author. No token is used, so GitHub allows about 60 requests an hour from your address.

How do I hand a task to an agent?

Each task row has Copy brief, which copies a short prompt to paste into your agent's chat, and, once a repository is set, Draft issue, which opens GitHub's new-issue form prefilled. You review and submit it there; this page never posts anything for you.
