Agent Workroom VR

The same board, in a headset. Your coding agents sit at desks around you, each monitor showing what that agent is on and whether its CI is red; the wall in front is the task board. Talk to it: hold the grip and say "go to Claude's desk", "start 3", "refresh" or "ask Claude on 12 to add a test", then "confirm". Or point with a controller and pull the trigger.

Repository

Pull requests become tasks: draft = in progress, open = in review, merged = done. claude/, codex/ and copilot/ branches sit at that agent's desk.

GitHub token (optional)

Only needed to see CI on the monitors and to post an "ask" comment. Use a fine-grained token for just that repository with Pull requests: read and write and Checks: read. It stays in this tab's memory: never saved, and sent only to api.github.com. Close the tab to forget it.

Questions

Which headsets work?

Any browser with WebXR's immersive-vr mode: Meta Quest Browser is the main target. The Enter VR button only lights up where the browser offers it. Everywhere else the preview above shows the same room on a screen. This page was built and tested in a desktop browser without a headset, so expect rough edges on a real device and please report them.

Does my voice go anywhere?

Where the browser has built-in speech recognition (Chrome, Edge, Android), that is used, and some browsers, Chrome among them, send the audio to the browser maker's speech service. Where it doesn't (Quest Browser, Firefox), the page runs a small Whisper model (tiny, English) on your own device: the model is downloaded once from Hugging Face via the jsDelivr CDN and your audio never leaves the headset. Tick Always use on-device speech to use it everywhere. Recognition is push-to-talk only: the microphone is open only while you hold the button.

Can it really talk to my agents?

It talks to them where they already listen: on GitHub. "Ask Claude on 12 to …" posts a comment on pull request 12 that starts @claude, which the Claude Code GitHub action (and Copilot or Codex for @copilot / @codex) picks up if the repository has it installed. The comment is posted as you, with your token, only after you confirm, and says it was sent from Agent Workroom. Agents running in a terminal or a cloud session can't be reached from a web page; for those, use Copy brief on the 2D page.

Where are my tasks?

In this browser's local storage, shared with the 2D room on the same site. Nothing is uploaded to a server of ours.
