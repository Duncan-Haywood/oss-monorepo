# Medicaid Look-Back Penalty Calculator

Free, private browser tool for families planning nursing-home care: list gifts and transfers, see which fall inside the look-back window, the penalty period in months and days, the care bill it leaves to cover, how returning money changes it, and the date each gift stops counting.

**Live tool:** https://duncan-haywood.github.io/monorepo-projects/medicaid-lookback-penalty-calculator/

Open `index.html`. Tests: `node --test 'ventures/medicaid-lookback-penalty-calculator/**/*.test.mjs'`.

Not legal advice. The state's divisor, window and exemptions decide; check with an elder-law attorney. See `VENTURE.yaml`.
