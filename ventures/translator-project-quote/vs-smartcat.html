This calculator vs. Smartcat

Two different shapes: Smartcat is an account-based CAT tool, translation-memory, and marketplace platform built for running ongoing localization work. This page is a free, private calculator for one direct-client quote — weighted words, add-ons, and a printable quote, with nothing to sign up for.

What each tool is for

Smartcat is a cloud-based CAT (computer-assisted translation) tool and localization-management platform. Inside one account it combines a translation-memory-driven editor, terminology management, optional machine-translation pretranslation, project and vendor workflow, and a marketplace that connects businesses with freelance linguists and agencies. Word counts and fuzzy-match discounts are computed automatically against a translation memory the platform keeps between projects, which is most valuable when the same client sends recurring work and that memory compounds over time. It requires an account, and setting up a project means working inside Smartcat's own workspace. Smartcat's own pricing and plan terms are not repeated here, since this session cannot verify today's figures against Smartcat's current terms; only its well-documented scope as a CAT-tool and localization-management platform is described.

This calculator does none of what Smartcat's workspace does. It has no account, no translation memory, and no marketplace matching. It takes the new and fuzzy word counts, hourly rate, QA and desktop-publishing add-ons, a rush fee, and a minimum project price for one job you already have in front of you, and returns the weighted word count, direct cost, target-margin price, and the recommended quote — plus, once you have a number, a one-page printable quote for the client with the scope, total, deposit split, and a signature line. It runs free in any browser, needs no account and no project set up in advance, and uploads nothing you type.

Common questions

Should I use this calculator or Smartcat?

They solve different problems. Smartcat is a cloud-based CAT tool and localization-management platform: translation memory, terminology, machine-translation integration, project workflow, and a marketplace connecting businesses with freelance linguists and agencies all run inside one account. It is built for ongoing or recurring localization programs, where a translation memory accumulates across many projects and a client or agency needs a system of record for the whole pipeline. This calculator does none of that. It has no account, no translation memory, and no marketplace. It takes the weighted word count, hourly rate, and add-on costs for one project you already have in front of you and turns them into a quote floor, a target-margin price, and a printable client-facing quote, instantly, with nothing uploaded and nothing to configure first. A translator already running recurring work through Smartcat's workflow gets that project's numbers from the platform it already operates in; a freelancer pricing a single direct-client job, or without a Smartcat account at all, is in the right place here.
