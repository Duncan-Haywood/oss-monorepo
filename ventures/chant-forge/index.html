Chant Forge: Gregorian chant to MIDI, with a gym-genre preview

Paste chant in GABC (the text format used by Gregorio and GregoBase). You get a MIDI choir line with one Latin lyric per note, moved into a men's-voice range, optionally over drums, bass and chords in the chant's own mode. Everything runs in your browser; nothing is uploaded.

Read the project plan and command-line tools

Release folder (optional)

One button builds what a distributor upload is made from, the same folder as the command line's ep-cli.mjs: the track as a -14 LUFS WAV, its MIDI, timed lyrics, the GABC source, a 3000 px cover drawn from the chant's opening notes, release.json with the source edition and the AI disclosure, and a report of the release check. Rendering takes a few seconds to a minute.

EP queue (optional)

For several tracks in one release: convert a chant, press Add this track to the EP, change the chant or any setting, convert and add again. Each track keeps the settings it was converted with (genre, tempo, sections, voice) and the ISRC typed above. Build the EP folder renders every track at -14 LUFS and writes one folder with the release title, artist and date above, the cover drawn from track 1, the same files and the same check as the command line's ep-cli.mjs. The queue stays in this browser until you clear it. Rendering takes a few seconds a sung track.

    What it does

    1. Reads GABC: clefs, pitches, flats and naturals, dotted notes, episema and the four bars. Neume shapes are treated as plain notes.
    2. Fits the voice: finds the finals that keep the whole chant in E2-E4, a comfortable unison range for men, or you choose one.
    3. Fits the bar: pads or stretches phrases so each starts on a downbeat over a drum grid.
    4. Arranges: deep house, EDM, hard rock or metal drums, bass and chords in the chant's mode.
    5. Exports: a MIDI file with lyrics, plus a plain synthesised WAV to hear tempo and range. The preview is not a release master and the "choir" is a synthesiser.
    6. Sings the Latin: with the choir voice set to sing, each note is sung on the vowel of its Latin syllable (a, e, i, o, u, with ae and oe as e, qu and gu read as consonants, and au and eu gliding), by five detuned synthetic men's voices through formant filters set to measured men's vowels. Each syllable's opening consonants are sung too (t, d, k, the soft c of caeli, s, the sc of descendit, m, n, a tapped r and the rest), just before the beat as choirs place them, so the vowel lands on the beat, and its final consonants close the syllable's last note (the s of Dies, the n of sunt before its t). Measured from the audio on the five corpus pieces, 98% of measurable notes read back as the written vowel (the pad: 18%) and 75% of syllable openings as the written consonant. Nobody has listened to it yet.
    7. Cues the singers: a plain-text cue sheet with the bar, beat, time, note and syllable of every sung note, and timed lyrics (LRC) for a lyric display. With song sections on, a line above each section says what the band does under it, the first note to pitch from and how far it is from the last one, when the band comes in after an a cappella verse, and the new key's first note after a key lift. The same sheet as the command line's --cues.
    8. Prints the parts: the score download is a MusicXML file with one part per section (tenors, second tenors, baritones, basses when the choir is split), the Latin under the notes, the same pitches and timing as the MIDI in 4/4, and the song sections as rehearsal marks. MuseScore (free), Dorico, Sibelius and Finale open it, so a director can print each section's part. The same file as the command line's --musicxml.
    9. Teaches each section its part: the rehearsal tracks download holds two WAVs per choir section (one for a unison chant, two each for tenors, baritones and basses when it is split): a part track with that section loud on the left and the other sections 12 dB down on the right, the band 6 dB down, and a minus track with everything but that section to sing the part against. These are the learning tracks choirs usually buy per part. The same files as the command line's render-cli.mjs --learn.
    10. Builds the release folder: one button renders the track limited to -14 LUFS, draws a 3000 x 3000 cover from the chant's own opening notes (square notation on a red staff, no text), writes release.json with the source edition, year, transcriber and rights note read from the GABC header, the AI disclosure ("assisted", naming the tools and parts) and the credits, then runs the release check over all of it. The ZIP's REPORT.md separates build faults (a GABC with no source edition, a cover too small, loudness off) from the steps only you can take (artist name, p- and c-lines, ISRC). The same files and the same check as the command line's ep-cli.mjs for an EP.
    11. Hands the session to a DAW: with phrase markers on, the MIDI carries a locator at the start of each phrase (and at each song section), and the stems download is one WAV per part (choir, bass, chords, drums, organ drone) in a ZIP. The stems sum to the preview mix, so they line up from one start point. The same files as the command line's --markers and render-cli.mjs --stems.

    Questions

    How do I turn Gregorian chant into MIDI?

    Chant is published as GABC text. Paste it above, pick a tempo and a final note for your singers, and download the MIDI file. Each syllable becomes a lyric event on its note, so a DAW or notation program shows the Latin under the melody.

    Is the chant free to use?

    Melodies from editions published before 1929 are in the public domain in the United States, but a modern transcription or recording can carry its own rights. Check the licence of every source you paste. The tool does not decide that for you.

    Does the preview sound like a real choir?

    No. It is a plain synthesiser so you can judge the arrangement. Set the choir voice to sing and it sings each Latin syllable's opening consonants, its vowel and its final consonants. Nobody has listened to it yet. For a real sound, take the MIDI and cue sheet to singers; the recording guide has a protocol.
