Common questions

How do I create a Shopify app permission inventory without the Admin API?

Export only app metadata from a store you are authorized to administer — typically an Admin GraphQL appInstallations response with granted accessScopes and webhook topics. Paste it here, add the API version if the dump omitted it, and download the inventory JSON. The page does not connect to Shopify.

Does this treat requested scopes as granted?

No. Requested or declared scopes are stored separately. If an export has only declared scopes, capture refuses instead of inventing a granted list.
