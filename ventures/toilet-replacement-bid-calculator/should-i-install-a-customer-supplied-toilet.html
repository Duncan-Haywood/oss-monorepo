Should I install a customer-supplied toilet?

Owners call with a box in the hallway: “I already bought the toilet. Can you just set it for $249?” That sounds like free margin because the fixture invoice left the bid. It did not leave the trip, the wax, the set hours, or the chance that the bowl is a 12-inch on a 10-inch closet.

Zeroing the bowl is not a free install

A plumber-supplied two-piece still carries the fixture invoice. An owner-supplied bowl that actually fits zeros that line and keeps the same set hours. On a typical 12-inch swap-only — $42 wage, 30% burden, 15% overhead, 20% target margin, six miles — the plumber-supplied bid is in the mid-$500s. Zeroing a $165 bowl drops it, but the owner-supplied walk-away stays above $249. Taking the Facebook special to “just set what they bought” still loses money.

Wrong rough-in is a second trip

Store shelves default to 12-inch. Plenty of closets are 10-inch or 14-inch. Setting the wrong bowl means an offset flange or a drive back to exchange it. Common questions

Should I install a toilet the customer bought at a store?

Only after you price the set without the fixture invoice. Pulling their box is still a trip, a wax ring, and crew hours. A $249 install-only special often sits under that walk-away number even when the bowl is free to you.

Does a customer-supplied toilet make the $249 installed special profitable?

Usually not. Zeroing a $165 two-piece invoice drops the bid, but loaded labor, travel, wax, and overhead stay. On a typical 12-inch swap the owner-supplied walk-away is still above $249. A wrong rough-in adds a second trip and an offset flange.

What if the store-bought bowl is the wrong rough-in?

That is a second dispatch plus an offset flange or an exchange. Price that callback on the same closet before you agree to set whatever they rolled into the driveway. The calculator adds a starting callback trip and a 10-inch offset kit on top of your current rates.
