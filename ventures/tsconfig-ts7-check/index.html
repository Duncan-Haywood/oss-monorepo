Questions

Which tsconfig options did TypeScript 7 remove?

TypeScript 6.0 deprecated, and 7.0 removed: target ES5, downlevelIteration, moduleResolution node (node10) and classic, baseUrl, outFile, module AMD, UMD, System and None, and the false values of esModuleInterop, allowSyntheticDefaultImports and alwaysStrict. TypeScript 7 stops with error TS5102 or TS5108 for most of them and TS6046 for module None. The options removed back in 5.5 (charset, out, keyofStringsOnly, importsNotUsedAsValues and others) are unknown options in 7, error TS5023, even when set to false.

How do I replace baseUrl in TypeScript 7?

Delete baseUrl and write every paths target relative to the tsconfig file. With baseUrl set to src and "@lib/*": ["lib/*"], write "@lib/*": ["./src/lib/*"]. Imports that only worked because baseUrl made src a lookup root, such as import "utils/date" meaning ./src/utils/date, need a paths entry like "*": ["./src/*"] or a relative import. The suggested config on this page does the paths rewrite for you.

Does "ignoreDeprecations": "6.0" work in TypeScript 7?

No. In TypeScript 6 it silences the TS5101 and TS5107 deprecation errors. TypeScript 7 still accepts the setting but reports every removed option as an error regardless, so it only buys time on 6.0. Fix the options, then delete it.

Why are process, Buffer or describe undefined after upgrading to TypeScript 6 or 7?

Because the default of types changed from loading every package in node_modules/@types to an empty list. Globals that came from @types/node, @types/jest or @types/mocha are no longer declared unless you list them, for example "types": ["node", "jest"]. "types": ["*"] restores the old load-everything behaviour.

If this check finds nothing, will my project compile with TypeScript 7?

Not necessarily. The check covers the config file: removed options and changed defaults. Your code can still hit new type errors, packages may resolve differently under bundler or nodenext resolution, and editor plugins listed in plugins are a separate question. Run tsc 7 on the project; this page tells you why the first errors appear and what to change in the config.
