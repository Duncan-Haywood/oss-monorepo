iOS Privacy Manifest Checker

Scans your Swift/Objective-C source for Apple's Required Reason API usage (file timestamps, disk space, system boot time, active keyboards, UserDefaults) and checks it against your PrivacyInfo.xcprivacy manifest -- the two most common causes of an App Store Connect rejection with code ITMS-91061 (missing declaration) or ITMS-91055 (invalid reason code). Everything runs in this tab; nothing is uploaded. A command-line version for CI is in the same repository (node check.mjs .).


Open your project folder in Finder/Explorer, select every .swift/.m/.mm/.h file plus PrivacyInfo.xcprivacy (select-all works), then choose them here.

Evidence, not a determination. This tool reports what pattern-matching found in the files you selected and what your manifest declares. It cannot see reflection, dynamically loaded code, or the internals of third-party SDK binaries, and Apple can add categories or reason codes at any time. A clean report is not a guarantee App Review will pass -- verify against Apple's current documentation before you submit, and pick the reason code that actually matches why your code uses the API.
