Social Preview Checker vs. Screaming Frog SEO Spider

Different jobs: one checks one page's link-preview tags in your browser right now, for free; the other crawls a whole site as an installed, paid desktop application.

Check a page →

Screaming Frog SEO Spider is a well-known SEO crawler, described on its own site (screamingfrog.co.uk) as a desktop application for Windows, macOS, and Linux that crawls an entire site and audits it against hundreds of checks -- broken links and response codes, page titles and meta descriptions, duplicate content, hreflang, XML sitemap generation, and extraction of social meta tags including Open Graph and Twitter Cards, among others, per its own documented feature list. Its free tier is capped at 500 URLs per crawl and leaves out advanced features such as JavaScript rendering, custom extraction, and saved crawl configurations; a paid annual license removes the crawl cap and unlocks those features.

That is a different job from the one this page does. This tool has no install, no crawl, and no per-site license. It exists for the narrower question that comes up when one specific page -- often one about to be shared or just published -- needs its link preview checked right now: will this page's Open Graph and Twitter Card tags actually produce a working preview, with a preview image that meets the platform's own documented size minimum?

Common questions

Should I use this checker or Screaming Frog SEO Spider?

They overlap on one narrow slice and differ everywhere else. Screaming Frog SEO Spider is a paid, installable desktop crawler (Windows, macOS, and Linux) that walks an entire site and reports on hundreds of things — broken links, response codes, titles and meta descriptions, duplicate content, hreflang, XML sitemaps, and, among its social-tag checks, Open Graph and Twitter Card extraction, per its own site. Its free tier is capped at 500 URLs per crawl and drops the advanced features (JavaScript rendering, custom extraction, saved crawl configs); a paid annual license removes that cap. This tool does one page at a time: paste the JSON from a small local CLI probe (or check a single image URL directly) and get a plain-English report on missing tags, a relative og:image URL, an image below a platform's documented minimum size, and the twitter:image to og:image fallback chain — free, in your browser, with nothing to install and no crawl limit because there is no crawl.

Does Screaming Frog already catch the problems this tool catches?

It extracts the same Open Graph and Twitter Card tags, per its own documented feature list, so a site-wide crawl will surface which pages have which tags set. What this tool adds is the specific classification: whether an og:image URL is relative (which the Open Graph protocol requires to be absolute), whether the image is actually large enough for Facebook's or Twitter's documented minimum — which needs reading the image file's own pixel dimensions, not just confirming a tag exists — and whether the twitter:image to og:image fallback chain leaves a page covered even without every tag set explicitly.

Why use a narrower tool if Screaming Frog already crawls the whole site?

Two reasons this tool exists alongside it. First, Screaming Frog is a desktop application you install and configure to crawl a site; this tool is a page you open and paste a small probe's JSON into, which is faster when you only care about the one URL in front of you right now — a page about to be shared, say — rather than auditing the whole domain. Second, this tool reads the preview image's real pixel dimensions from the image file's own header and checks them against the platform-specific minimums Facebook and Twitter document, which is a narrower, more specific answer than confirming a tag is present.
