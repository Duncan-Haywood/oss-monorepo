# Horse Boarding Rate Calculator

Free, private browser tool for horse boarding barn owners: feed, bedding, chore labour, land and repair costs and the profit you want become a monthly board rate per stall, a break-even rate, the rate needed at each occupancy level, and a check on the rate you charge today.

After using this, you can set a board rate that still pays when two stalls are empty, instead of one copied from the barn down the road.

Open `index.html`. Tests: `node --test 'ventures/horse-boarding-rate-calculator/**/*.test.mjs'`.
