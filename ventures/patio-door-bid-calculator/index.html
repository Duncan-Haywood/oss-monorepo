      Common questions

      Why is a balcony unit priced so much higher than the same door on a ground patio?

      Second-story access changes the labor, not the door: staging, hoisting the panels, and working a lift or scaffold add hours a ground-floor swap never sees. The calculator prices access as its own line so a 12-foot 4-panel unit on a balcony is not quoted off the same number as the identical door at grade.

      Does new-construction framing cost more than a retrofit, and why?

      Yes — a retrofit reuses the existing frame and trims to it, while new-construction tears back to the rough opening, sets a new sill pan and frame, and wraps and flashes it. Pick “New-construction (full frame + wrap)” only if the opening is actually being framed out; picking it for a pocket replacement will overstate the bid.

      What if I don't know exactly which extras (transom, sill pan, screen) apply?

      Leave them unchecked and price the base door first, then toggle each one to see its dollar impact before you walk the job. The starting hours per extra are common ballpark figures, not a manufacturer spec, so true them up against your own invoices once you have a few jobs logged.

      Is this an engineering or code determination for impact glazing?

      No. Impact/hurricane glazing requirements are set by local code and wind-zone maps, not by this calculator — it only prices the glazing option you select. Confirm the required rating with your local building department before ordering material.
