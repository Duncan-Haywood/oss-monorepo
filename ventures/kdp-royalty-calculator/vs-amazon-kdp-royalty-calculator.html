This calculator vs. Amazon's KDP royalty calculator

Kindle Direct Publishing publishes a royalty help page and, inside a signed-in KDP account, a royalty calculator that prices printing cost and royalty for a list price, page count, ink, and marketplace. That is the right place to check what KDP would pay on one format you have already chosen.

Between that official preview and the decision still open — enroll this title in KDP Select for a 90-day exclusive window, or keep it wide — sits arithmetic the official tool does not do: how many Kindle Unlimited page reads match one paid sale, and whether this month's KU window still beats the other-store and Ingram volume you would keep by staying wide. This calculator does not try to reproduce KDP's live print cost. Paste the preview figure into the override box.

Common questions

Should I use this calculator or Amazon's KDP royalty calculator?

Both, for different jobs. Amazon's KDP royalty calculator, published inside a KDP account, computes printing cost and royalty for a list price, page count, ink, and marketplace you already chose. It is the right place to check what KDP would pay on that one format. It does not compare Kindle Unlimited page reads to a paid sale, and it does not put a 90-day exclusive window next to the same book sold wide. This page does not try to replace KDP's live print preview — paste that figure into the override box — and instead answers the follow-on decision the official calculator leaves open.

Does Amazon's calculator require an account?

Yes. Amazon documents the royalty calculator as part of Kindle Direct Publishing, used from a signed-in KDP account on a title you are publishing or have published. This page is a static file. It needs no Amazon account and never talks to Amazon.
