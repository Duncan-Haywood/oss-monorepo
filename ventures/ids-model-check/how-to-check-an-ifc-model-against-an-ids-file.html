How to check an IFC model against an IDS file

An IDS (Information Delivery Specification) file is buildingSMART's machine-readable list of what a model must contain: which elements need which properties, classifications, materials and places in the building. Checking a model against one means finding, for every specification, the elements it applies to and testing each requirement on each element. You can do that with a free checker in your browser: drop the .ifc and the .ids on the page and read the failing elements, with nothing uploaded.

Open the free IDS checker (or press Try a tiny sample on it)

What you need

  • The model as IFC: a STEP .ifc exported from Revit, ArchiCAD, Tekla or any other authoring tool, an .ifcxml, an .ifczip, ifcJSON or an IFC5 .ifcx. IFC2X3, IFC4 and IFC4X3 are read.
  • The IDS, usually from the client's information requirements (EIR) or the BIM execution plan. No IDS yet? The page's use the starter IDS button loads seven common coordination requirements, and you can write one in a spreadsheet.

Steps

  1. Open the checker and drop the model on the left box and the IDS on the right one.
  2. Press Audit the IDS only first if the IDS is new to you. It finds mistakes in the IDS itself (a class name that does not exist, a boolean written TRUE, a number with a decimal comma) that would otherwise make every element fail. A specification with such a mistake is reported INVALID, not failed.
  3. Press Check the model. Each specification shows how many elements it applies to, how many pass, and every failing element with its class, name, GlobalId and the reason.
  4. Send the result back: Download BCF issues gives an issue per failing element in BCF 2.1, the issue format BIM coordination tools open at the element; Download report (HTML) is a single file to email; CSV and JSON are for spreadsheets and scripts.

A worked example

The checker's built-in sample is a one-storey house with three walls, a door, a window, a space and a kitchen unit exported as a proxy. Checked against the starter IDS it passes 3 of 7 specifications:

The same check runs on the command line, which is how a team puts it in CI so every export is checked:

node cli.mjs samples/tiny-house.ifc samples/coordination-basics.ids.xml --bcf issues.bcfzip

It exits 1 when a specification fails. On GitHub, one Action step checks every model against every IDS on each push and writes the failures as annotations.

Reading the result

  • Required specifications fail when any element they apply to misses a requirement. Optional ones report the same way, but the IDS author has said the elements may be missing. Prohibited ones fail when any element matches at all.
  • Applies to 0 elements is not a pass to celebrate: often the class is wrong for the schema (IFCWALLSTANDARDCASE in an IFC4X3 model) or the applicability asks for a property value no element has. The report names subclasses an entity facet leaves out.
  • "has no property set" and "has no property" usually mean the export did not map the parameter. Fix the export mapping, or write the missing values into a copy of the model.

How far to trust it

The checker scores all 334 of buildingSMART's official IDS test cases right, and gives the same results as IfcTester, the open-source checker from IfcOpenShell, on real models element by element, apart from a few documented cases where it follows the XML Schema standard instead. The figures and every difference are in the source repository.

Questions

Is there a free IDS checker?

Yes. IDS Model Check is free and MIT licensed and runs in the browser or as a Node command line. IfcTester, part of the open-source IfcOpenShell project, is a free Python alternative.

Is my model uploaded?

No. The page reads the model and the IDS in your browser tab; there is no server that receives them and no account.

What does INVALID mean in the report?

The specification itself breaks the IDS rules, for example a class that does not exist in the model's IFC version or a value of the wrong type, so it was not checked. Fix the IDS and run the check again.

Which IFC versions can be checked?

IFC2X3, IFC4 and IFC4X3 models, as STEP .ifc, ifcXML, .ifczip, ifcJSON or IFC5 alpha .ifcx files.
