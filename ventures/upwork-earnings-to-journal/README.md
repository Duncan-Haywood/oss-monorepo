# Upwork Earnings to Journal

Free, private browser tool: paste an Upwork transaction history and get balanced, month-split journals for Xero, QuickBooks Online and QuickBooks Desktop (IIF). Income is booked gross, Upwork's service fees, withdrawal fees and Connects as expenses, withdrawals as money moving to the bank, and the running Balance column is walked row by row to prove no row is missing. It also reports what Upwork took as a share of what you billed.

**Live tool:** https://duncan-haywood.github.io/monorepo-projects/upwork-earnings-to-journal/

Open `index.html`. Tests: `node --test ventures/upwork-earnings-to-journal/*.test.mjs`.

The export layout is from memory of public help pages; nothing has run against a real Upwork export yet. See `VENTURE.yaml`.
