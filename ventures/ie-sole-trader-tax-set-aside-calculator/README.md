# Ireland Self-Employed Tax Set-Aside Calculator (2026)

Free, private browser tool: enter business income and expenses and get income tax (after credits), USC, Class S PRSI and the share of every invoice to set aside. Reminds you about preliminary tax and VAT registration.

After using this, an Irish sole trader knows how much to move out of each payment instead of facing a Form 11 bill.

Open `index.html`. Tests: `node --test 'ventures/ie-sole-trader-tax-set-aside-calculator/**/*.test.mjs'`.
