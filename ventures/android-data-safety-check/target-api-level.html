Play Store Target API Level Checker

Reads your AndroidManifest.xml or Gradle targetSdkVersion/targetSdk declaration and checks it against Google Play's published target API level requirement -- the gate that restricts an update from reaching devices on newer Android versions once its target API level falls too far behind, separate from the Data safety declaration the sibling checker on this page covers. Everything runs in this tab; nothing is uploaded. A command-line version for CI is in the same repository (node target-sdk-check.mjs . --form-factor phone-tablet).

Common questions

What happens if my app's targetSdkVersion is below Google Play's requirement?

Your app is not removed from Google Play. Instead, it stops being visible to and installable by new users on a device running a newer Android version than your app targets. Existing installs, and users on an OS version at or below your app's target, are unaffected.

Is the required target API level the same for every app?

No. Google Play sets a different floor per form factor -- phone/tablet, Wear OS, Android TV, Android XR, and Android Automotive OS each have their own required level, and a newly published app must meet a higher floor than an update to an app already on Google Play. Pick your form factor above before reading the result.

Can I get more time to meet the deadline?

Google states that an extension to the primary deadline can be requested in Play Console. This tool shows both the primary deadline and the extension deadline it has on record, but whether an extension applies to your app is only visible in your own Play Console -- this tool cannot see that.

Is my project uploaded anywhere?

No. The browser tool reads the files you select using the File API and never sends them anywhere -- everything happens in memory in your tab. The CLI never makes a network call either.

Evidence, not a determination. The deadline and per-form-factor floor above are reproduced from Google's own target API level requirement page, dated 2026-09-23. Google revises these numbers and dates on its own schedule, and whether an extension applies to your specific app is visible only in your own Play Console. A clean report here is not a guarantee Google Play will treat your app as compliant -- verify against Google's current target API level requirement page before you rely on it.
