What this is (and isn't)

This report distinguishes your inputs from derived arithmetic. It does not recommend a price, provide tax or financial advice, or claim that a quote is profitable — you decide what costs and target rate are appropriate. "Gap to target price" compares the quote to your own supplied target rate; "After direct costs" shows what's left before your own compensation. Both are arithmetic signals, not a verdict.

Privacy

Everything runs in your browser. Your prices, project names, and figures are never uploaded — there is no server for them to go to. This page counts anonymous, local feature-use events (e.g. "a report was generated") in your own browser's localStorage, only to help this project's maintainers tell whether the tool is used at all.

Prefer a spreadsheet workflow or scripting several quotes at once? The same math runs as a local command-line tool — see the Quote Margin Check README for the Python CLI (supports Markdown, JSON, and CSV output). MIT licensed — see LICENSE.
