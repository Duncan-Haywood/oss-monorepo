What this is (and isn't)

This report distinguishes your inputs from derived arithmetic. It does not recommend a price, provide tax or financial advice, or claim that a quote is profitable — you decide what costs and target rate are appropriate. "Gap to target price" compares the quote to your own supplied target rate; "After direct costs" shows what's left before your own compensation. Both are arithmetic signals, not a verdict.

Privacy

Everything runs in your browser. Your prices, project names, and figures are never uploaded — there is no server for them to go to. A "copy link" URL carries your figures in the # fragment, which browsers never send to a server; treat that link as private anyway, since anyone you send it to can read the numbers in it. This page counts anonymous, local feature-use events in your own browser's localStorage — the event name and the day, never your figures — only to help this project's maintainers tell whether the tool is used at all. The full list: a result was shown, a report was copied, a link was copied, the example was loaded, a link was opened.

Prefer a spreadsheet workflow or scripting several quotes at once? The same math runs as a local command-line tool — see the Quote Margin Check README for the Python CLI (Markdown, JSON, and CSV output; the Markdown is byte-identical to the report this page copies). MIT licensed — see LICENSE.
