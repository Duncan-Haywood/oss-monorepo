What this does not check

This reads dimensions, byte size, format and filename. It is blind to everything that actually decides how a print looks:

  • Colour. No profile inspection, no gamut check, no soft proof. A file can pass here and print with a colour cast.
  • Sharpness and noise. An upscaled or heavily denoised file has the pixel count without the detail, and nothing here can tell the difference.
  • Paper, press and finish. The same file on matte, glossy and canvas is three different results, and each lab has its own requirements.

So clearing the floor means the file is not obviously too small — nothing more. Order a proof.

Questions

What DPI does a print master need?

This tool checks a documented floor of 150 DPI at the print size named in the filename. That is a conservative floor for fine-art and photographic printing rather than an ideal: many labs prefer 240 or 300 DPI, and some accept less for large pieces viewed from a distance. Implied DPI is simply your pixel dimensions divided by the physical print size, so the same file is print-ready at 8x10 and far below the floor at 24x36.

How does the tool know what size I am printing?

It reads a size token out of the filename. A file called harbor-11x14.jpg is checked as an 11x14 print, and the named size is matched in either orientation, so a landscape file is measured against 14x11. If no supported size appears in the filename, the tool falls back to a conservative floor of 1500 pixels on the short edge instead of guessing a print size. The compare view lets you pick any supported size explicitly.

Why does the tool block a file for its filename?

Filenames containing web, thumbnail, lowres, instagram, or facebook are almost always a web export that was resized and recompressed for a screen. Such a file can still have enough pixels to clear the DPI floor, which is exactly why it is worth flagging: the resolution looks fine while the file has already lost the detail a print needs. It is a filename convention check, so rename the file if it is genuinely your print master.

Is my artwork uploaded anywhere?

No. The files are opened by your own browser to read their pixel dimensions, and nothing is transmitted. There is no server, no account, and no upload step. You can disconnect from the network and the tool still works.

Does a passing preflight mean my print will look good?

No. This is limited automated evidence, not a print-ready warranty or lab approval. It reads dimensions, byte size, format and filename — it cannot judge colour accuracy, sharpness, noise, colour profile, paper choice, or how a specific press and stock will render your image. Order a proof and confirm requirements with your printer before committing to a run.
