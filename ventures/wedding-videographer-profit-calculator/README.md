# Wedding Videographer Profit Calculator

A free browser calculator for wedding and event videographers: enter the package price and every hour (shoot, travel, highlight film, ceremony and speeches edits, revision rounds), plus second shooter, travel, gear and fees, and see your true hourly rate, profit per booking, the minimum package price for a target rate, how the rate erodes as edit hours grow, and what each deliverable tier pays per hour. Entirely client-side; nothing is uploaded.

**Live tool:** https://duncan-haywood.github.io/monorepo-projects/wedding-videographer-profit-calculator/

After using this, you can now **price a wedding film so the edit and revision hours are paid for**, which used to mean guessing from the shoot day alone.

Scope: arithmetic on user-editable numbers, USD only. The example presets are unverified approximations; the page says so. Not legal, tax or financial advice.

Run the tests: `node --test ventures/wedding-videographer-profit-calculator/*.test.mjs`
