How much does asbestos abatement cost?

It depends far more on containment class than on square footage. The same 400 square feet prices anywhere from about $5 to $12 a square foot on this calculator's own verified defaults — a 2.4x spread from one input.

Containment class, not area, sets the price

Search for a cost-per-square-foot answer and every number you find is really an answer for one specific OSHA (29 CFR 1926.1101) / EPA NESHAP containment class, quietly generalized to the whole trade. Class I friable material (pipe or duct insulation, sprayed-on fireproofing, surfacing material) needs full containment, a negative-air machine, and a three-stage decon chamber, with crews working slowly in full-face respirators doing wet removal. Class III minor, incidental disturbance of non-friable material can be glovebagged in an afternoon with almost none of that. The two are not the same job at the same size, and pricing them off one $/sq ft figure gets one of them wrong every time.

The same 400 square feet, three different prices

Using this calculator's own verified defaults (400 sq ft, 1 containment area, a 3-person crew at $38/h, a $58/h supervisor, 6 air monitoring samples at $65 each, 3 cubic yards of waste disposal at $145/yd³, a $275 permit, and a 30% target margin), changing only the containment class:

Bigger jobs don't scale by area alone either

A 1,000 square foot Class I job split across 2 containment areas, with 10 air monitoring samples and 6 cubic yards of waste, prices around $9,828.84 on this calculator — about $9.83 per square foot. That is close to, but not the same as, the $11.87/sq ft rate for the smaller 400 square foot Class I job above, because containment setup is a cost per work area and monitoring/disposal are costs per sample and per cubic yard — neither one scales in lockstep with square footage. A rate calibrated on one job size and area count will drift as either one changes.

Common questions

How much does asbestos abatement cost?

It depends far more on OSHA/EPA containment class than on square footage alone. On this calculator's own verified defaults, a 400 square foot job prices around $1,998 as Class III (about $4.99/sq ft), around $2,710 as Class II (about $6.77/sq ft), and around $4,749 as Class I (about $11.87/sq ft) — the same area, a 2.4x spread, because Class I needs full containment, a negative-air machine, and a three-stage decon chamber that Class III does not.

Why does the same square footage cost so differently?

Because labor hours per square foot are set by containment class, not area. Class I friable material needs full containment and crews working in full-face respirators doing wet removal — about 22 labor-hours for 400 square feet. Class III minor, incidental disturbance of non-friable material needs almost none of that — about 3.6 labor-hours for the same 400 square feet, roughly six times faster.

Does a bigger job always cost proportionally more?

Not exactly, because containment setup is a fixed cost per work area, not per square foot. A 1,000 square foot Class I job split across 2 containment areas prices around $9,829 on this calculator's defaults — about $9.83/sq ft, close to but not identical to the 400 square foot Class I rate, because the second containment area and the added air monitoring and waste disposal do not scale exactly with area.

Is a per-square-foot price ever accurate?

Only within one containment class and a similar area/monitoring load — the band the rate was actually built on. Quoted across containment classes, the same $/sq ft number overcharges the easy jobs and underprices the hard ones, because it cannot see which class a given job falls into.
