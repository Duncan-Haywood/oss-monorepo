Import photos into Apple Photos without losing your place.

Command-line utilities for moving large JPEG and RAW libraries into Apple Photos safely. Imports are manifest-backed and restartable, duplicate risk is handled, failures are classified with recovery actions, and a watchdog supervises long runs.

What it does

  • Resumable importer with a per-media-type manifest
  • SD-card offload with optional SHA-256 verification
  • A verify command that reads every manifest file back before you retire a staging directory
  • Atomic status and report files that never appear half-written

Status

Prototype. macOS and Python 3 only. These are local command-line tools, so there is no browser version; nothing is uploaded anywhere.
