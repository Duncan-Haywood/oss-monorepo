Local LLM Connection Check

Want a web tool to use the AI model on your own computer instead of an API key? This page tries to reach Ollama, LM Studio and llama.cpp the same way a web tool would, tells you what is in the way (a CORS block, a server that is not running, no model downloaded), and gives you the command that fixes it. Then it sends a test prompt and measures how fast your model answers.

Nothing is uploaded. This page only talks to the addresses it probes, which are on your own computer unless you type another. The checks and the test prompt run in your browser.

Common questions

Why does a web page get a CORS error from Ollama?

Ollama answers requests only from pages served from your own computer unless you list other origins in the OLLAMA_ORIGINS environment variable. A page on any other site is refused, and the browser reports it the same way as a server that is not running. Set OLLAMA_ORIGINS to that site's origin and restart Ollama. Step-by-step for macOS, Linux and Windows.

How can this page tell a CORS block from a server that is off?

It sends a second request in no-cors mode, which is allowed to reach the server but not to read the reply. If that request completes, something is listening on the port and refusing this page; if it fails too, nothing is listening, or the browser blocked access to your local network.

Does anything I type or any model output leave my computer?

No. The page talks only to the addresses it probes, which are on your own computer unless you enter another. The test prompt goes to your model and its reply is shown here; nothing is sent to us or to an analytics service.

Is it safe to allow a website in OLLAMA_ORIGINS?

Allowing one origin lets pages from that site use your local model while it runs, which is the point. Allow only sites you trust, never a wildcard on a machine others can reach, and remove the setting if you stop using them.

Why can my https page not reach a model on another machine on my network?

Browsers treat http://localhost as secure, so an https page may call it, but they block plain-http requests to any other address from an https page. Run the tool on the computer with the model, serve the model over https, or forward its port to localhost with ssh.
