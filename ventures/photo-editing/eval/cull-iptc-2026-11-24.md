## Check 2: the page in Chromium, read back by ExifTool 12.76

Three NEFs from metadata-extractor-images (D810, D300, D5100) and a
Lightroom-style sidecar for the D810 (rating 2, `crs:Exposure2012`,
`crs:CropTop`, keyword "landscape", title "Old" with a fr-FR "Vieux").
Template: creator "Jane Doe", copyright "© {year} Jane Doe", caption
"Shot on {camera} at {aperture}, {monthname} {day}, {year} ({stem}).",
keywords "sample, {year}", city, country, title. D300: `K` with
"Ice hockey, final; Ice hockey", rated 4. D810 rated 5.

```
exiftool -j -G1 -a -XMP-dc:all -XMP-photoshop:all -XMP-iptcCore:all -XMP-xmp:Rating -XMP-crs:Exposure2012 -XMP-crs:CropTop out/*.xmp
"Nikon D300.xmp": Rights "© 2008 Jane Doe", Creator "Jane Doe",
  Subject ["sample",2008,"Ice hockey","final"],
  Description "Shot on NIKON D300 at f/18, March 6, 2008 (Nikon D300).",
  Title "New title", Country "United Kingdom", City "Leeds", Rating 4
"Nikon D810.xmp": Rights "© 2015 Jane Doe", Creator "Jane Doe",
  Subject ["landscape","sample",2015],
  Description "Shot on NIKON D810 at f/3.5, May 13, 2015 (Nikon D810).",
  Title "New title", Title-fr-FR "Vieux", Country, City, Rating 5,
  Exposure2012 "+0.35", CropTop 0.05
```

The D5100 was not marked, so with "only frames I rated" ticked it got no
sidecar (2 files in the zip). Page status: "2 sidecars in the zip, 1 of them
your own with only the rating, label and IPTC fields changed; 2 carry IPTC
captions or keywords." No page errors; the template came back after a reload.

All 13 fields on a fresh sidecar (`xmpSidecar` then `mergeIptc`): ExifTool
reads Headline, Title, Description (with `"`, `&`, `<`), Subject, Creator as
two entries, Rights, Credit, Source, Location, City, State, Country,
Instructions as written. `exiftool -validate -warning` reports OK on all
three files.

At 390 px wide the page has no horizontal scroll with the form open.

## Reproduce

```bash
git clone --depth 1 --filter=blob:none --sparse https://github.com/drewnoakes/metadata-extractor-images.git mei
(cd mei && git sparse-checkout set nef)
python3 -m http.server 8765 -d site &
node eval/cull-iptc-page.mjs http://localhost:8765/cull.html mei WORK
exiftool -j -G1 -a -XMP-dc:all -XMP-photoshop:all -XMP-iptcCore:all WORK/out/*.xmp
exiftool -validate -warning -a WORK/out/*.xmp
```
