Which camera RAW files can ShootFlow develop without Adobe DNG Converter?

Eleven formats, read directly: DNG, Canon CRW, CR2 and CR3, Sony ARW, Nikon NEF, Olympus ORF, Panasonic RW2, Samsung SRW, Pentax PEF and Fujifilm RAF, including X-Trans and Fujifilm's compressed modes.

Each reader was checked on real camera files from public sample collections against LibRaw 0.22, the open-source decoder behind most raw software. For every format, every sensor value read was equal to LibRaw's, and so were the as-shot white balance and colour filter layout. Source: the project's evaluation records, one per format.

Develop a file

A DNG carries its own colour matrices. The other formats need the camera's .dcp profile. Adobe's free DNG Converter installs one per body, and RawTherapee and dcamprof write them too. Pass a folder and ShootFlow picks the right profile for each camera.

git clone https://github.com/Duncan-Haywood/oss-monorepo
cd oss-monorepo/ventures/photo-editing
PYTHONPATH=src python3 -m shootflow.cli develop DSCF0001.RAF --dcp ~/profiles --out masters

The output is a neutral 16-bit TIFF master with as-shot white balance and sRGB, meant as the starting point for your LUT or grade. It runs on Python's standard library alone. Install numpy and the optional C decoders build on first use, and most files then read in under two seconds.

What it is not

  • Not a Lightroom replacement. No sliders, no looks, no noise reduction or highlight recovery. It turns raw files into neutral masters for a batch pipeline.
  • Colour is only as good as the profile you give it. No camera profiles ship with ShootFlow, so colours will differ from Lightroom's own rendering.
  • Matching LibRaw is a decoding check, not a picture-quality score. It shows the numbers came out of the file correctly. How the picture looks depends on the demosaic, profile and grade that follow.
  • Camera raw video is not decoded.

Questions

Can I open Canon CR3 files without Adobe DNG Converter?

Yes. ShootFlow reads full-quality CR3 and the smaller C-RAW setting directly. On real EOS R8 and EOS R3 files every sensor value matched LibRaw 0.22. You still need the camera's .dcp profile for colour.

Does it read Fujifilm X-Trans RAF files, including compressed ones?

Yes: uncompressed, lossless compressed and lossy compressed RAFs, X-Trans and GFX Bayer. On ten real files from nine bodies every sensor value matched LibRaw. X-Trans files are demosaiced with a directional method written for the 6x6 layout.

Which newer Nikon and Panasonic files does it not read yet?

Nikon's high-efficiency NEF from Z bodies, Coolpix NEFs, and Panasonic's old 16-bit RawFormat 2 and 3. Those files are refused with a message to convert to DNG first.

Can I still develop old Canon CRW files from a 10D, 300D or PowerShot G5?

Yes, from 2026-11-16, without converting them to DNG. On 20 real CRW files from 15 Canon bodies (EOS D30, D60, 10D, 300D and the PowerShot G2 to G6, Pro1 and S30 to S70) every sensor value matched LibRaw 0.22, and so did the as-shot white balance wherever the file records one. When a PowerShot was set to Auto white balance the file keeps no balance for the shot, so none is applied and the report says so. The four-colour G1, Pro70 and Pro90 IS are refused. A file takes 2 to 5 seconds to read. Colour needs a .dcp profile for the camera, such as the ones Adobe DNG Converter installs for the cameras it supports.

Does it read Leica RWL files?

Yes, from 2026-11-16. Leica's D-LUX, V-LUX and C-LUX are built by Panasonic and write the same file as a Lumix under another name. On a real D-LUX (Typ 109) and V-LUX (Typ 114) file every one of 32.7 M sensor values, the white balance, black level, colour pattern and crop matched LibRaw 0.22. Colour needs Adobe's .dcp for the Leica model.

Will the card copy leave behind raw files it cannot develop?

No, from 2026-11-16. The copy takes every common raw format (Canon CRW, Nikon Coolpix NRW, Sigma X3F, Hasselblad 3FR, Phase One IIQ, Kodak DCR and others), HEIF and HIF stills, MXF and M2TS video and XMP sidecars, and lists any other file it leaves on the card, so you see it before formatting the card. Formats it cannot develop are still culled from the preview the camera embedded, and stop at the grade with a message to convert to DNG.

Are my photos uploaded anywhere?

No. ShootFlow runs on your own computer and only reads your raw files. It never changes them.
