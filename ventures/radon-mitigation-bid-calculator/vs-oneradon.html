This calculator vs. OneRADON

Two different shapes: OneRADON is Sun Nuclear's free companion software for its own SunRADON continuous radon monitors, turning a connected device's test data into a report and invoice. This page is a free, private worksheet for one question — what should this one mitigation install cost, given its suction points, membrane, and circuit, before you quote it.

What each tool is for

OneRADON is Sun Nuclear's own software suite built around its SunRADON family of continuous radon monitors (CRMs). Its publicly described feature set is device-centric: connect to a monitor over Bluetooth (the XP line) or USB (the 1027/1028/1030 line), retrieve the test data it recorded, and generate a customizable PDF inspection report and invoice from that reading, with sensor charts folded in and integration into SunRADON's own Cloud, Desktop, and SunLAB certified-lab services. It ships free with the hardware, on desktop, Mac, and mobile. Sun Nuclear's own site is not reachable from this session to confirm today's feature list in full, so nothing beyond what is documented above is stated here, and no dollar figure for OneRADON or the monitors it runs on appears on this page.

This calculator does none of what OneRADON does. It has no device to connect to and generates no test report. It takes one job's footprint, suction-point count, an optional crawl-space membrane, a roof discharge, a high-suction fan, a new dedicated circuit, firestops through living space, a permit or notification fee, and a post-mitigation test, and turns that into the per-job price and the walk-away price below which the job loses money — plus, if you already have a number on the table, a check of whether it clears that floor, and a printable customer proposal for that one job. It runs free in any browser, keeps no account, and uploads nothing you type.

Common questions

Should I use this calculator or OneRADON?

They do different jobs in the same trade. OneRADON is Sun Nuclear's free companion software for its SunRADON continuous radon monitors: connect a monitor by Bluetooth or USB, pull the retrieved test data, and generate a customer-facing PDF inspection report and invoice from it, with sensor charts and integration into SunRADON's own Cloud, Desktop, and certified-lab services. It is a testing-and-reporting tool built around owning that hardware. This calculator does a different job entirely: starting from footprint, suction points, a crawl membrane, a roof discharge, a high-suction fan, a new circuit, firestops, a permit, and a post-mitigation test, it prices the mitigation install itself — hours, materials, loaded labor, overhead, and the walk-away price below which the job loses money. It runs free in any browser, keeps no account, and uploads nothing you type. A mitigator running SunRADON monitors and generating test reports from them needs OneRADON or a comparable device app for that; the same mitigator pricing what the install itself should cost, before or without a test in hand, is in the right place here.

Does this calculator include the post-mitigation test?

It prices the labor and kit cost of running one, as its own line, so the hour that test takes is not quietly folded into the install price. It does not perform, record, or report an actual radon measurement — that is what a continuous monitor and its companion software, such as OneRADON, are for. The two are complementary: this calculator answers what the job should cost to install and test; the monitor and its software answer what the test actually measured.
