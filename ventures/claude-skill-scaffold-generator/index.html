    Common questions

    What does this tool actually generate?

    A starter SKILL.md file -- valid YAML frontmatter (name and description) plus a body naming any scripts, references, or assets you said the skill bundles -- and a suggested folder layout to put it in. It does not write the skill's actual instructions for you; the body is a placeholder you fill in.

    Does this tool call an AI model to write the skill?

    No. The frontmatter and body are assembled from the fields you type by a fixed template, entirely in your browser. Nothing is uploaded and no model is called.

    Does a clean result mean Claude will actually load and use the skill correctly?

    No. This tool checks the fields you supplied -- is the name a valid slug, does the description avoid first person, is a trigger condition present -- not whether Claude will invoke the skill correctly at runtime. Write real instructions in the body, then actually try the skill before relying on it.

    Why does the description field matter this much?

    Claude decides whether to load a skill from its description alone, before reading anything else in it. A description with no concrete trigger condition, or one written in the first person as if the skill were speaking, is the most common reason a skill exists but never fires.
