Common questions

How do I generate TypeScript types from JSON?

Paste a JSON response, or several samples, and pick TypeScript. The tool reads every sample, merges them, and writes one interface per object shape. Fields missing from some samples become optional, fields that are sometimes null become nullable, and strings that are always dates, UUIDs, emails or URLs are annotated.

Why paste more than one sample?

One sample cannot show which fields are optional or which values can be null, so every field comes out required. Paste several responses one after another, or one per line, and the merged types reflect what the API actually returns.

Which output formats are supported?

TypeScript interfaces, Zod schemas with inferred types, JSON Schema (draft 2020-12), and Go structs with json tags. All four come from the same inferred model.

Does this upload my JSON?

No. Everything runs in this page and the page makes no network calls, so API responses containing customer data stay on your device. The CLI reads files or stdin on your machine and prints to your terminal.

How is this different from quicktype or json2ts?

It overlaps on purpose. It merges many samples, reports what it had to guess, and needs no install, account or upload. For a build-time pipeline use a maintained generator; use this to get a correct first draft in seconds.
