RDS INSTANCE RIGHTSIZER · RUNS IN YOUR BROWSER

Is your RDS or Aurora instance too big?

Paste a CSV of CloudWatch numbers per instance (and/or aws rds describe-db-instances --output json) and get, per instance, an over- or under-provisioned verdict, the next class in the same family that still fits CPU, memory and connections, a Graviton saving for x86 classes, the monthly saving (Multi-AZ doubles the price) and the aws rds modify-db-instance command to paste.

Nothing is uploaded and no AWS account is contacted. The text box is analysed in this browser and never leaves your device. This is a recommendation from metrics, not a bill: metrics must be sampled over a representative period, and prices are approximate.

aws rds describe-db-instances --output json > rds.json
node cli.mjs analyze rds.json metrics.csv --commands

Common questions

    
Does this connect to my AWS account?

    
No. It reads the text you paste and never contacts AWS or any server. It cannot see your real invoice, reserved instances, Savings Plans, storage or I/O charges, so every dollar figure is the instance list price you can edit, times 730 hours.

    
How long should the CloudWatch window be?

    
Long enough to include your busiest period: at least two weeks, and a month-end or batch cycle if you have one. Use the p95 of CPUUtilization, the minimum of FreeableMemory and the p95 of DatabaseConnections. A quiet week will recommend a class that falls over on payroll day.

    
Is low freeable memory always a problem?

    
No. MySQL and PostgreSQL use free memory as cache, so a low minimum is a prompt to check SwapUsage and read latency, not proof of trouble. The tool keeps a 20% freeable reserve on the new class at your observed peak, and you can change it.

    
Will changing the instance class cause downtime?

    
Yes. Modifying the class restarts the instance. A single-AZ instance is unavailable for several minutes and a Multi-AZ instance fails over, usually in one to two minutes. Without --apply-immediately the change waits for the next maintenance window; with it, the restart starts now.

    
Is my pasted text uploaded anywhere?

    
No. The browser page analyses the text in your own browser and never sends it anywhere. The CLI reads local files or stdin and makes no network call.
