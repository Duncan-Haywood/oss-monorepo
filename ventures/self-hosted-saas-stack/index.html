The small-SaaS stack you can host yourself.

28 open-source tools, each replacing a subscription a founder or small team usually pays for: booking pages, a help center, error tracking, feature flags, web analytics, lifecycle email, referral programs, Stripe revenue metrics and e-signature. Every one is MIT licensed, a zero-dependency Node server, and deployable to your own cloud with no vendor in between. Pick the one you need; none requires another.

Questions

Are these really free?

Yes. Every tool is MIT licensed. You pay only for wherever you choose to run it, which for most of them is a single small Node process on a free or low-cost host. There is no per-seat fee and no usage cap beyond your own server.

How do I deploy one?

Each tool is a zero-dependency Node server with a Dockerfile, a docker-compose file, and Render and Fly.io configuration. Clone the repository, open the tool's folder and run node server.mjs, or use the one-click deploy button where the tool's page offers it. Your data stays on the server you run.

How do these compare with Calendly, Sentry or LaunchDarkly?

They cover the core job a small team needs, not every feature of a paid platform. Each tool's page has an honest limits section naming what it does not do, for example single admin key instead of team logins. If you need enterprise permissions, audit certifications or a vendor to call, a paid product is still the right call.

Who maintains them?

They are built and maintained in the open in one repository, with automated tests for every tool. They are provided as-is, with no warranty and no uptime or delivery guarantee, so read the code and test it against your own needs before relying on it.

Can I use only one?

Yes. Each tool stands alone and shares nothing with the others. Those that talk to Stripe use your own webhook or a read-only key, and none of them needs another tool in this list.
