Common questions

Does this connect to my Google Cloud project?

No. It reads the rows you paste and never contacts Google. It cannot see your real invoice, discounts or commitments, so every dollar figure is the rows you pasted times list prices you can edit.

How do I get the numbers?

Query INFORMATION_SCHEMA.JOBS_BY_PROJECT for the last 30 days, grouped by a label, user or query hash: COUNT(*) for runs, AVG(total_bytes_billed)/1e9 for GB billed per run and AVG(total_slot_ms)/3600000 for slot-hours per run. Slot hours are optional; without them Editions is not compared.

On-demand or Editions: which is cheaper?

On-demand bills bytes scanned, $6.25 per TiB after the first free TiB each month. Editions bills slot-hours, $0.04 to $0.06 each pay-as-you-go. Scan-heavy, compute-light queries favour Editions; compute-heavy queries over small tables favour on-demand. The tool compares your own rows, and treats the Editions figure as a floor because autoscaling bills in 50-slot steps with a one-minute minimum.

What does maximum_bytes_billed do?

A query run with a maximum bytes billed setting fails without charge if it would bill more than that many bytes. The tool suggests a cap 25% above an expensive query's usual size so a bad edit cannot cost much more than the normal run.

Is my data uploaded anywhere?

No. The browser page analyses the text in your own browser and never sends it anywhere. The CLI reads a local file or stdin and makes no network call.
