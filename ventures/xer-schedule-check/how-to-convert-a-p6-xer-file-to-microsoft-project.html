How to convert a P6 XER file to Microsoft Project

To move a Primavera P6 schedule into Microsoft Project, convert the .xer to Microsoft Project XML (MSPDI) and open that file in Project with File, Open. The free tool here does the conversion in your browser: WBS, activities, calendars, logic, constraints, progress, baseline, resources, activity codes and user-defined fields carry across. Project then recalculates with its own rules, so a few dates can move, and the tool lists which rules apply to your file.

Open the free schedule check (open the XER, then press Download for Microsoft Project (.xml))

Steps

  1. In P6, export the project as XER (File, Export, Primavera PM XER), or use the file you were sent.
  2. Open it on the tool page.
  3. Press Download for Microsoft Project (.xml). Tick "write activity code descriptions too" if you want codes written as "CON - Construction".
  4. In Microsoft Project: File, Open, choose XML Format, select the file. ProjectLibre and GanttProject open the same file.
  5. Read the tool's list of what Project will treat differently for this file, and check those activities after Project recalculates.

How it was tested

On six public P6 files (21,422 activities, 54,843 relationships) every activity and relationship read back unchanged after conversion, and MPXJ, an independent open-source reader, read the same names, dates, durations, progress, logic and resource hours from the XER and from the converted file. On four of those files, 276,042 of 276,042 activity code values written read back to the same value. Details are in the project's eval/ notes.

Why some dates move in Project

  • Lag calendar. Project counts a lag on the successor's calendar; P6 can use the predecessor's, the successor's or a 24-hour calendar.
  • Milestones. Project puts a milestone with a predecessor at that predecessor's finish time.
  • Level of effort. Project has no equivalent, so these become manually scheduled tasks that keep P6's dates.

The reverse direction works too: open a Microsoft Project .xml file on the tool page and download a P6 XER.

Questions

Can Microsoft Project open an XER file directly?

Current versions do not import XER. Convert it to Microsoft Project XML first, then open the .xml with File, Open.

Will the critical path be the same in Project?

Mostly, but Project schedules with its own rules: lags count on the successor's calendar and a milestone with a predecessor sits at that predecessor's finish. The tool lists which of these apply to your file so you know where to look.

Can I convert a Microsoft Project file to XER?

Yes. Save the .mpp as XML in Project (File, Save As, XML Format), open the .xml on the tool page and download the XER. The .mpp format itself is not read.

Is the file uploaded for conversion?

No. The conversion runs in your browser tab, and the converted file is produced on your computer.
