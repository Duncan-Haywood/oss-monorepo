# GAO scorecard: planted faults on the public P6 files (2026-11-23)

`gao.mjs` scores the ten best practices of the GAO Schedule Assessment Guide
(GAO-16-89G) from an XER. Six of its tests have no DCMA counterpart, so the
DCMA checks' own evals do not cover them. This plants one fault of each of
those kinds in a copy of each public file and asks whether the scorecard names
the planted activity under its own test.

Run: `bash eval/corpus-fetch.sh DIR && node eval/gao-check.mjs DIR/xer --json eval/gao-check-2026-11-23.json`
(about 2 minutes; the 16,000-activity CCA file takes about 9 s per run, so it
gets 2 seeds, the others 5).

## Plants

| Kind | Practice | What is planted | Found |
|---|---|---|---|
| wbs | 1 | an open activity moved onto the project's own WBS node | 27 / 27 |
| names | 1 | an activity renamed to another's name (both must be named) | 9 / 9 |
| zero | 4 | an unstarted task given zero original and remaining duration | 27 / 27 |
| milestone | 5 | every predecessor of an open finish milestone removed | 27 / 27 |
| path-lag | 6 | a one-day lag on a zero-lag link between two driving-path activities | 17 / 17 |
| path-cstr | 6 | a start-on constraint at its early start on an unstarted driving-path activity | 22 / 22 |

**129 of 129** planted faults named under their own test. A plant whose target
was already named under that test before planting is skipped, not counted:
most names plants on Expressway, sample and the airport file drew an activity
whose name was already shared, and the hotel file's driving path is one ALAP
milestone (no link or activity to plant on; its practice 6 fails for that
reason, named in the test).

What this measures is detection of the planted activity. It does not measure
false alarms: the unplanted files' own failures are real properties of those
files (the hotel file repeats 1,377 activity names, the CCA file has 475
zero-duration tasks), but nothing here checks them against a second tool, and
no public tool publishes a GAO scorecard to compare against.

## Fixed during the check

- Failed-test item lists were first capped at 200 rows. The hotel file's 1,377
  repeated names and CCA's 475 zero-duration tasks ran past the cap, so a
  planted fault could be missing from the list (and from the CSV) while the
  count went up. The cap is gone; the page and text view show the first few.
- "Stored dates follow the logic" failed on files with no stored dates
  (hand-made or never scheduled). It is now left out of practice 5 with a
  warning, not counted as a failure.
