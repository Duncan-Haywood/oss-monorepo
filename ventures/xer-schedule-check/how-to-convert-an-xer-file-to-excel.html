How to convert a Primavera P6 XER file to Excel

To read a Primavera P6 schedule in Excel, convert the .xer to an .xlsx workbook in which every P6 internal id is replaced by what P6 shows: activity IDs, WBS paths, calendar, resource and code names. The free tool here does it in your browser: one row per activity with its dates, durations and float in days, constraints, predecessors and successors, activity codes and user-defined fields as columns, and sheets for relationships, WBS, resources, assignments, expenses, calendars and code values. Dates are real Excel dates, so sorting, filters and pivot tables work.

Open the free schedule check (open the XER, then press Download for Excel (.xlsx))

Steps

  1. In P6, export the project as XER (File, Export, Primavera PM XER), or use the file you were sent.
  2. Open it on the tool page. If the file holds several projects, pick one in the project list.
  3. Press Download for Excel (.xlsx). Tick the box below it to add every XER table as it is, one sheet each, under P6's own field names.
  4. Open the file in Excel, LibreOffice Calc or Google Sheets. Each sheet's header row is frozen and has filters on.

How it was tested

On six public P6 files exported from P6 versions 5.0 to 24.12 (21,758 activities, 56,666 relationships), a separate reader written in Python, sharing no code with the tool, parsed each XER on its own and opened each workbook with openpyxl. It compared every activity's ID, name, status, eight stored dates, durations, float, activity code values and user-defined field values, every relationship and resource assignment, and every value of every raw table: 6,239,763 of 6,239,763 values were equal. Details are in the project's eval/ notes.

Things to know

  • Days follow each activity's calendar. P6 can be set to show days on a fixed hours-per-day instead; the hours are in the XER sheets if you need them.
  • Start and Finish are the actual dates once the activity has started, else the early dates, as in P6's Start and Finish columns.
  • Long text over Excel's 32,767-character cell limit (a notebook pasted into a field) is cut, and the tool says how many cells were.

For Microsoft Project, the same page writes Microsoft Project XML instead (how that conversion works).

Questions

Can Excel open an XER file directly?

It opens as text, but not usefully: an XER holds a dozen or more P6 tables one after another, each row tagged %R, and every link between them is an internal number (a predecessor is task_id 4177, not activity A1010). Convert it to a workbook first, with each table on its own sheet and the numbers replaced by names.

Why are durations and float in days and not hours?

P6 stores every duration, lag and float in hours. The workbook divides by the hours per day of each activity's own calendar, as P6 shows them by default, so a 10-hour-a-day calendar's 50 hours read as 5 days. The Relationships sheet keeps each lag in hours too.

What are the Recomputed columns?

The tool runs its own critical path from the logic, calendars, constraints and progress in the file and writes those dates beside the ones P6 stored. Float Agrees says whether P6's stored total float matches. A no usually means a duration, lag or link was edited after P6 last scheduled the file.

Is the file uploaded?

No. The workbook is written in your browser tab and saved straight to your computer. There is no server, account or upload.
