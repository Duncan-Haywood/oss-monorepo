How to break down a DCMA assessment by subcontractor or WBS

A DCMA 14-point check on a whole schedule says "31% of links carry a lag" and stops there. The owner's rep then has to tell the general contractor, who has to work out which subcontractor's fragnet holds the lags. Commercial schedule-analysis seats solve this with a "ribbon" view: the same metrics broken down by WBS node or activity code. The free tool here does the same from a P6 XER: one row per WBS node or per value of any activity code the scheduler set up (responsibility, area, trade, subcontractor), points 1 to 11 scored on that group's own activities, worst first.

Open the free schedule check (open the XER, then press Break down the 14 points)

Steps

  1. Export the schedule from P6 as XER (File, Export, Primavera PM XER), or as P6 XML. A Microsoft Project XML file works too, grouped by its summary tasks.
  2. Open it on the tool page.
  3. Under DCMA by WBS, area or subcontractor, choose Group by: WBS, or one of the activity code types the file carries. For WBS or a nested code, Level 1 is the top node, 2 one below.
  4. Press Break down the 14 points. A red cell fails the DCMA threshold on that group's own activities; hover it for the count.
  5. Press Download (CSV) for every group's count, population and value per point, to send each party its row. The activities behind each finding are in the 14-point lists above it.

Each of those is a different conversation with a different party.

How it is worked out

The tool runs the DCMA assessment once on the whole file, then puts each finding in the group of the activity it names. A relationship finding (lead, lag, relationship type) goes to its successor's group. Each group's denominator is its share of the same population the project-wide point uses (open activities, open non-milestone activities, links into open work, or activities planned to finish by the data date), so the groups' counts add up to the project's and each cell can be read against the same threshold. Activities without a value of the chosen code are grouped as "no" that code; an activity filed above the chosen WBS level is grouped at its own node.

How it was tested

On six public P6 files, every WBS level from 1 to 3 and every activity code type the files carry (58 groupings): each point's group counts add up to the project-wide count, each group's pass flag matches its count against the threshold, and all 34,287 findings land in the same group when assigned a second way, by their activity ID text looked up in the file's own tables.

Things to know

  • Small groups swing. One activity in a group of three is 33%. Read the count beside the percentage before writing to a subcontractor.
  • The breakdown is only as good as the coding. Work with no responsibility code lands in one "no" group; on the public hospital file that is 12,845 of 14,270 open activities by division.
  • Screening, not a verdict. As with the project-wide check, a failing cell is something to fix or explain.

Questions

What is a ribbon analysis of a schedule?

A breakdown of schedule-quality metrics by a grouping in the schedule, such as WBS, responsibility, area or trade: one row per group, one column per metric. Commercial schedule-analysis tools sell it so a reviewer can see which part of a schedule is weak, not only that the schedule as a whole fails.

Are the thresholds different per group?

No. Each group is scored against the same published DCMA thresholds (5% for most counts, 0 for leads, negative float, invalid dates and unresourced work, 90% finish-to-start), but on its own activities only. A small group can fail a percentage point on one activity; the count is shown with every cell.

How are relationships assigned to a group?

A relationship counts under its successor's group, since the successor's scheduler owns the link into their work. A lead from a civil activity into an electrical one is the electrical group's finding.

Why are points 12 to 14 not broken down?

The critical path test, the critical path length index and the baseline execution index describe the whole network or the whole project's progress. A subcontractor's share of them has no defined threshold, so they stay project-wide.

Is the file uploaded?

No. The schedule is read and analysed in your browser tab. There is no server, account or upload.
