How to convert a P6 XML file to XER

P6 has two export formats. XER is the tab-separated one most review tools, claims consultants and contract specifications ask for. P6 XML is the format P6 EPPM and Oracle Primavera Cloud export, and P6 Professional writes it too (File, Export, Primavera PM (XML)). If a contractor sends you the XML and your tools want an XER, the usual answers are to import it into a P6 database and export again, which needs a P6 seat, or to buy a converter. This page does it in the browser, and runs the schedule checks on the XML while it is open.

Open the free schedule check (open the .xml, then press Download as P6 XER)

Steps

  1. Open the .xml file on the tool page, in the same box as an XER. The page tells P6 XML from Microsoft Project XML by its first element.
  2. Under Convert this P6 XML file to an XER, press Download as P6 XER (.xer). The file is saved in Windows-1252, the code page P6 reads an XER in, unless a name holds characters that code page cannot hold.
  3. Scroll down for the DCMA 14-point assessment, the critical path and everything else the page does with an XER: it reads the XML directly, so there is no need to convert first.

How it was tested

No public schedule exists as both an XER and a P6 XML of the same project, so the six public P6 schedules this project is tested on were written as P6 XML by MPXJ, the independent open-source converter library. Read back here, every activity, calendar, WBS path and all 56,666 relationships were the same as in the original XERs, and the recomputed schedule (early and late dates and total float) was equal on 21,441 of 21,441 activities. The XML written back as XER schedules the same again, and MPXJ reads those XERs exactly as it reads the originals: 239,338 of 239,338 fields. On a P6 XML file P6 itself wrote, the recomputed early start, early finish and late finish equal P6's stored ones on 32 of 32 open activities. The project's eval/pmxml-2026-11-23.md has the detail, including two faults in the generator that the test found and worked around.

Things to know

  • No float in P6 XML. P6 leaves calculated float out of its XML export, so the XER's float columns are empty until P6 schedules it. This tool recomputes float from the logic, so its checks are unaffected, except the one comparing stored float with the logic.
  • Baselines. A P6 XML file can carry baseline projects. They are named in the notes and not converted; export the baseline as its own file.
  • Import into P6 not yet tested here. The XER is checked with this tool's reader and with MPXJ, not yet by importing it into P6. Check the first one you import.

Questions

What is a P6 XML file?

The XML format Primavera P6 uses to move projects between databases: the file starts with an APIBusinessObjects element and holds projects, WBS, activities, relationships, calendars, resources and assignments under the names of P6's API. P6 Professional writes it from File, Export, Primavera PM (XML); P6 EPPM (the web version) and Oracle Primavera Cloud export it as their standard exchange file.

How do I convert P6 XML to XER without P6?

Open the .xml file on the tool page and press Download as P6 XER. The file is read in your browser and written back as an XER with the same projects, WBS, activities, relationships, calendars, scheduling options, resources, assignments, activity codes and user-defined fields. Nothing is uploaded.

Is anything lost converting P6 XML to XER?

P6 XML stores no total or free float, so the XER's float columns are left empty for P6 to fill at its first schedule run (this tool recomputes float from the logic anyway). Baseline projects inside the XML file are not carried; open the baseline as its own file. On six public schedules written as P6 XML, the XER read back with every activity, calendar and relationship the same, and the recomputed schedule equal on all 21,441 activities.

Can I run a DCMA 14-point check on a P6 XML file?

Yes. Open the .xml wherever the page asks for an XER: the 14-point assessment, the GAO scorecard, the Gantt chart, the comparison of two updates, the windows analysis, risk, levelling and the time impact analysis all read it the same way. The only check that cannot run is the one comparing P6's stored float with the logic, because P6 XML does not store float.

Is my schedule uploaded?

No. The file is read and converted in your browser tab. There is no server, account or upload.
