How to open an XER file without Primavera P6

An .xer file is a plain-text export from Oracle Primavera P6: tab-separated tables for the project, calendars, activities, relationships and resources. Without a P6 seat you can open it in a viewer that reads those tables, convert it to a Microsoft Project XML file, or read the raw text. The free tool linked here reads it in your browser and shows the Gantt chart, the critical path and a DCMA check, with nothing uploaded.

What is inside an XER

Open one in a text editor and you will see a header line starting ERMHDR with the P6 version and export date, then blocks that each start %T (table name), %F (field names) and rows starting %R. The tables a reviewer needs are:

TableHolds
PROJECTProject ID, data date (last_recalc_date), planned start and must-finish date
CALENDARWorking week, hours and holidays, packed in P6's own bracket format
PROJWBSThe WBS tree
TASKActivities: ID, name, status, durations in hours, actual, early, late and planned dates, constraints, total float
TASKPREDRelationships: predecessor, successor, type (FS, SS, FF, SF) and lag in hours
RSRC, TASKRSRCResources and their assignments with hours and cost
ACTVTYPE, ACTVCODE, TASKACTVActivity codes (phase, area, responsibility)
UDFTYPE, UDFVALUEUser-defined fields

Durations and float are stored in hours, so a "10-day" activity on an 8-hour calendar shows as 80. Dates have no time zone. The file can hold several projects; each row carries its proj_id.

Questions

Can I open an XER file in Excel?

You can import it as tab-separated text, but every table lands in one sheet, durations are in hours and calendars are packed codes. Excel will not compute the critical path or float. A viewer that reads the tables is quicker for anything beyond a lookup.

Can Microsoft Project open an XER file?

Not directly in current versions. Convert the XER to Microsoft Project XML first (the free tool here does this in the browser), then use File, Open in Project and choose the .xml file.

Is it safe to open a confidential schedule in an online tool?

Check whether the tool uploads the file. This one reads the file in your browser tab with JavaScript; there is no server that receives it, no account and no analytics vendor.

What P6 versions does it read?

XER exports from P6 version 5.0 to 24.12 were in the test set.
