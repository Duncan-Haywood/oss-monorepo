A world-time bezel for your Garmin watch.

A worldtimer-bezel watch face in the style of classic GMT travel watches. A fixed 24-hour ring runs around the rim, and 42 major cities sit at the position matching their current local hour. Your own time stays big and digital in the center.

What it does

  • 42 cities across every standard time zone, shown at once as 3-letter codes on two label tiers
  • DST transitions derived from the published IANA rules
  • Open source (MIT); build it yourself with the Connect IQ SDK

Status

Prototype. Not yet listed in the Connect IQ Store. This is a native watch app, so there is nothing to run in the browser; the page describes it and links to the source.

Build with the Garmin Connect IQ SDK and sideload to a supported watch; steps are in the project README. Source code and README.
