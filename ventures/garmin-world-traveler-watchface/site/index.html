A world-time bezel on your wrist.

A watch face in the style of classic GMT travel watches: 42 cities sit on a 24-hour ring at their own current local hour, with your local time large in the center.

What it does

  • 42 cities across UTC-11 to UTC+12 plus UTC+5:30, drawn on two label tiers so same-offset pairs do not overlap.
  • Big digital local time and date, following the device's 12/24-hour setting.
  • Daylight-saving rules for US, EU, Australia and New Zealand are computed on the watch, with no timezone database.
  • Four color themes: Midnight, Aurora, Sand, Mono.
  • Requests no permissions: it reads only the system clock and device settings. No location, no network.

Status

Prototype. It is not published on the Connect IQ Store. You build it with the Connect IQ SDK and load it onto a device or the simulator; whether travelers want it is untested.

Run it yourself

git clone https://github.com/Duncan-Haywood/oss-monorepo
cd oss-monorepo/ventures/garmin-world-traveler-watchface

The README in that folder has the full steps.
