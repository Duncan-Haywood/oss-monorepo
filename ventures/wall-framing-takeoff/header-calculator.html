Header size checker

Copy the header span table from your code or your engineer (longest clear span, header size, plies), type your openings, and each opening gets the first row that covers its width. A header you picked yourself is kept and flagged UNDER if it is shallower or has fewer plies than your table asks for. No code values are shipped: the check is only as good as the table you paste.


  
Do the whole house: framing, sheathing, plumbing and more in one takeoff


  
How it is checked

  
    
    
  1. Your table. Rows of longest clear span, header size and plies, copied from the span table that applies to your load, building width and stud size. A table that gets lighter for a longer span is rejected.
    2. 
    
  2. Each opening. The first row whose span covers the opening's width is the one asked for. "auto" takes it; a header you typed is compared against it.
    3. 
    
  3. Too wide. An opening wider than the longest row is an error, never a guess.

Questions

  
Which header does a 4 ft window need from my span table?

  
With the made-up table in the box (up to 3 ft 2x6, up to 5 ft 2x8, up to 7 ft 2x10, up to 10 ft 2x12, all two plies) a 4 ft window takes two 2x8s, set from the table. A 3 ft door framed with two 2x6s is OK, and a 6 ft window framed with two 2x8s is flagged UNDER because the table asks two 2x10s. The rows are placeholders to show the check, not code values: copy yours from your code's span table or your engineer's schedule.

  
What happens when an opening is wider than my table?

  
The check refuses rather than guessing. If the longest row is 5 ft and a window is 6 ft wide it says so and asks you to add a row from your span table or frame that opening to an engineer's size.
