Common questions

    
Can I use a GPL dependency in a closed-source app?

    
Not if you distribute it. GPL and AGPL require the whole combined work to be released under the same license when you hand it to others. Running GPL software on your own servers without distributing it is a different case, and a separate program talking to yours over a pipe or socket is usually treated as arm's length. This tool flags the first case and notes the others.

    
What changes for a SaaS?

    
Copyleft such as GPL is triggered by distribution, which a hosted service does not do, so GPL dependencies are usually fine there. AGPL adds a network clause for modified versions, and SSPL requires releasing the surrounding service stack if you offer the software as a service.

    
Is this legal advice?

    
No. It encodes widely published FSF and OSI compatibility positions as a rules table so you can skim a large tree. Whether a rule applies to your facts, your linking and your contracts is a question for you or your counsel.

    
Is my dependency list uploaded anywhere?

    
No. The page parses what you paste in your own browser. The CLI reads local files only and makes no network call.
