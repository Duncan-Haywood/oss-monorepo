Common questions

How do I calculate the cutoff frequency of an RC filter?

For a first-order RC filter the -3 dB cutoff frequency is f_c = 1 / (2·π·R·C), where R is in ohms and C is in farads. The time constant is τ = R·C. Whether the filter is low-pass or high-pass only changes where the output is taken, not the cutoff frequency.

What is the cutoff frequency of an RL filter?

For a first-order RL filter the -3 dB cutoff frequency is f_c = R / (2·π·L), with R in ohms and L in henries. The time constant is τ = L / R.

What does the -3 dB cutoff frequency mean?

It is the frequency at which the filter's output power has fallen to half of the input (voltage down to about 70.7%). Beyond it, a first-order filter rolls off at -20 dB per decade (-6 dB per octave).

What this is (and isn't)

This covers the standard first-order (single R with a single C or L) passive filter. It reports the −3 dB cutoff frequency, the angular cutoff, and the time constant. It does not model higher-order filters, component tolerances, source/load impedance loading, parasitics, or the full frequency response — treat the numbers as the ideal textbook design point, then verify against your real parts and datasheets.
