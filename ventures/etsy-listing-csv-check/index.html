Safe fixes

    The rules, and what they leave out

    • One row, one listing. Each row needs a TITLE, PRICE and QUANTITY. TITLE is limited to 140 characters.
    • TAGS are comma-separated: up to 13, each up to 20 characters, using letters, numbers, spaces, hyphens and apostrophes. A semicolon list reads as one long tag.
    • PRICE is digits and a decimal point, with the currency in CURRENCY_CODE as a three-letter capital code such as USD. The lowest price is 0.20 in US dollars or the equivalent.
    • QUANTITY is a whole number up to 999.
    • IMAGE1 to IMAGE10 are direct https addresses ending in JPG, PNG or GIF, filled in order. A file name or a page link cannot be fetched.
    • Variations pair a type or name with a list of VALUES; each choice must be unique.
    • SKUs Excel rewrote to scientific notation are flagged because the original digits are gone.
    • Safe fixes change only the delimiter, header capitals, price and currency formatting, spaces and empty entries in TAGS and MATERIALS, semicolon tag lists and stray spaces around a SKU. It never edits a title, description, tag word, material, image address, variation value or SKU.
    • Not checked: that Etsy will accept the file today, banned or restricted items, shipping profiles, categories, trademark and policy rules, image contents, and anything Etsy changes in its importer. Upload two or three listings first.

    Common questions

    Why does my Etsy bulk listing CSV upload fail?

    The usual causes are a title over 140 characters, more than 13 tags or a tag over 20 characters, a price with a currency symbol or a decimal comma, a quantity above 999 or with a decimal, image links that are file names or web pages, an unquoted comma in a description that shifts every later cell, and an Excel save that turned SKUs into scientific notation. This tool tests each of them and names the line.

    How do I check an Etsy CSV before uploading it?

    Paste the file or drop it onto this page. It reads the header against the bulk listing template, checks every row, and lists problems with their line numbers, grouped as errors, warnings and notes. Nothing is uploaded.

    How many tags can an Etsy listing have?

    From memory of Etsy's public documentation, thirteen, each up to twenty characters. The tool reports a listing with more, any tag that is too long, repeated tags, and tags with punctuation Etsy may refuse. Confirm the current limits in Etsy's help.

    Why are my image links not working?

    Etsy fetches each image from a public web address. A file name, a local path, or a share link that opens a viewer page cannot be fetched. Use a direct link that ends in an image file type.

    What does Apply safe fixes change?

    Only things with one reasonable reading: the delimiter, header capitalisation, prices like $1,299.00 to 1299.00, currency codes to capitals, spaces and empty entries in TAGS and MATERIALS, semicolon tag lists to commas, and stray spaces around a SKU. It never edits a title, description, tag word, image address, variation value or SKU.

    Is it safe to put my listings into a web page?

    The page runs in your browser, the file is read locally and nothing is uploaded; a test in the code asserts there are no network calls.

    What does this not check?

    Whether Etsy will accept the file today, prohibited or restricted items, shipping profiles, categories, policy and trademark rules, and image contents. A clean result is not a promise of success: upload a few listings first.
