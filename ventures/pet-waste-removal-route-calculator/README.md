# Pet Waste Removal Route Calculator

Free, private browser tool for pet waste removal (dog poop scooping) route owners: weekly clients, price per visit, minutes on site, drive time between yards, supplies and fixed costs become monthly profit, pay per hour including driving, break-even clients, the price per visit for the hourly pay you want, and a table showing what a tighter route is worth.

**Live tool:** https://duncan-haywood.github.io/monorepo-projects/pet-waste-removal-route-calculator/

After using this, you know whether your route pays a wage or only looks busy, and whether to raise prices or cluster clients.

Open `index.html`. Tests: `node --test 'ventures/pet-waste-removal-route-calculator/**/*.test.mjs'`.
