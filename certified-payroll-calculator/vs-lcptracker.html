Common questions

Should I use this calculator or LCPtracker?

They solve different problems at different scales. LCPtracker is cloud-based, subscription compliance software that a contracting agency or general contractor rolls out across an entire project: every subcontractor's certified payroll is collected, validated against Davis-Bacon and state prevailing-wage rules, and stored for audit, often because the awarding agency requires certified payroll to be submitted through it. This page is a single free form: no account, no project setup, no submission workflow. You type one worker's wage-determination rate, fringe, actual pay, and hours for one week, and it checks the combined-compensation requirement and computes overtime correctly when part of the fringe is paid in cash instead of into a bona fide plan.

Does LCPtracker check the same cash-in-lieu-of-fringe overtime rule this page does?

LCPtracker's own materials describe a validation engine that flags Davis-Bacon and prevailing-wage errors across submitted certified payrolls before they go to the agency, run against the payroll data a contractor's system feeds into it. This page does one narrower thing directly: given a wage determination's base and fringe rates plus what a worker was actually paid, it computes whether cash-in-lieu-of-fringe was correctly included in the overtime regular rate under 29 CFR 5.32 / 778.7, so you can check that one calculation by hand before it ever reaches a submission system.

Is LCPtracker free?

No. LCPtracker is subscription software (LCPtracker Pro, with an add-on LCPtracker+ training/support tier), typically paid for by the contractor or required by the contracting agency as part of the project's compliance process. This calculator has no account and nothing that bills — it is a free static page with no server behind the numbers you type.
