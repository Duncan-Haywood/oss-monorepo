    Common questions

    What is llms.txt?

    An emerging, optional convention (see llmstxt.org) for a plain-text Markdown file at /llms.txt that gives an AI assistant a short, curated map of a site's most important pages — cheaper to read than crawling the whole site, and curated rather than everything a sitemap lists. It is not enforced by any browser or search engine; it is a convention some AI tools already read and more are adopting. More background: what llms.txt is for, and what it isn't.

    Is this file generated correctly to spec?

    The generator always produces the required shape — an H1 title, an optional blockquote summary, and Markdown link bullets grouped under "## Section" headings — and every build is run back through the same validator shown in tab 3, so you see any warning before you publish. What it can't know is whether you picked the right pages to include; that judgment stays yours.

    Is my content uploaded anywhere?

    No. The browser page builds and validates entirely in your own browser and never sends what you paste anywhere. The CLI only reads local files, or fetches a URL you explicitly name (a sitemap.xml), and makes no other network call.

    Where do I put the generated file?

    Publish it at the root of your site as /llms.txt — the same level as /robots.txt — so it's reachable at https://yoursite.com/llms.txt.
