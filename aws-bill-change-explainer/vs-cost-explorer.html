This tool vs. the Cost Explorer console

Different jobs. The AWS console is where spend lives and where you explore it. This is a small, offline tool for one question: which lines explain the change between two periods in an export you already downloaded.

What each one is for

The Cost Explorer console is AWS's own interface for exploring spend. You can group and filter by service, account, region, tag and usage type, chart it, and download the result as CSV. It has the live data.

This tool reads that CSV, in a browser page or a single Node.js file, ranks every line by how much it moved between two periods, scales an unfinished month so it is not mistaken for a drop, names what is new and what is gone, and lists common causes for the services that rose. It has no data of its own.

Common questions

Is this a replacement for Cost Explorer?

No. Cost Explorer is where the data comes from, and its own console can group, filter and chart spend interactively. This tool takes the CSV it exports and does one narrow job: rank two periods against each other, normalise a partial month, and list what usually moves each service.

When is this tool the better fit?

When you want the answer to one question, which lines explain the rise, without clicking through filters, or when you want a script to flag a jump every month. It also helps when the bill must not leave your machine.

Does it replace a FinOps platform?

No. Paid FinOps and cost-management products describe features such as anomaly detection on live data, allocation by tag or team, budgets, and savings recommendations. This tool has none of that: it compares two periods in a file.

Can I use both?

Yes. Use Cost Explorer or a platform to see live data and set budgets, and use this to explain a specific month-over-month jump from an export.
