Ingest safely. Plan deliverables.

An early-stage toolkit for photographers and videographers: copy media with checksums and manifests, never delete the source, and plan the render tasks for reels, carousels and graded intermediates.

What exists today

  • Safe ingest: planned copies with checksums, manifests and conflict detection; source media is never deleted.
  • A catalog built from ingest manifests, and loaders for per-asset analysis output bound to a trusted production plan.
  • Assembly of explicit render tasks, with resumable, lock-protected status files and a dry-run worker and scheduler.

What does not exist yet

The renderers are dry-run placeholders: ShootFlow does not yet render video or grade images, and there is no app. The direction is a Mac app for human review or editor handoff. Treat this as a design and a tested core, not a finished product.

Run it yourself

git clone https://github.com/Duncan-Haywood/oss-monorepo
cd oss-monorepo/ventures/photo-editing

The README in that folder has the full steps.
