# Print Atelier

Print Atelier is an AI-first, software-driven platform that bridges the gap between traditional fine art and scalable e-commerce.

This repository contains the Next.js web application demo and the TSX-converted foundational business documents.

## Running the Demo

First, install dependencies:
```bash
npm install
```

Then, run the development server:
```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

## Architecture & Documents
The business plan, strategy, operations, revenue model, market research, AI strategy, and GTM strategy have been converted to TSX components under `src/app/` for a unified interactive experience.
