# age public keys that may decrypt infra/secrets/*.age. One per line.
#
# Generate yours on the machine that runs your agents, and keep the private half
# off every server and out of every Actions secret:
#
#   bootstrap/scripts/gen-age-key.sh          # writes ~/.config/sops/age/keys.txt
#   grep '^# public key:' ~/.config/sops/age/keys.txt
#
# Paste the age1… line here, then re-encrypt each secret you keep in the repo:
#
#   bootstrap/scripts/load-secrets.sh --encrypt HETZNERSSHKEY
#
# Adding a recipient (a second laptop, a co-owner) means re-running --encrypt for
# every secret: age fixes the recipient set at encryption time. Removing one is
# not a revocation — anyone who held the old file can still open it — so a
# removal is a rotation of the underlying credential, not an edit to this file.
#
# Empty until an owner adds one. `--encrypt` refuses to run against an empty
# file rather than producing something nobody can read.
