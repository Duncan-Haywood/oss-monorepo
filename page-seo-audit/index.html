Questions people actually ask

What does a free on-page SEO audit check?

Title and meta description length, a single h1 and a sane heading outline, a canonical link, the viewport tag, Open Graph link-preview tags, JSON-LD structured data that actually parses, image alt text, vague link text and how much real text is in the served HTML.

How do I audit a page without uploading it anywhere?

Open the page, choose View source, copy everything and paste it here. The audit runs in your browser and the page makes no network calls. The command-line version fetches a URL or reads a file on your own machine.

What is AI-readiness here?

Six signals AI assistants and answer engines rely on when they read a page: not blocked by noindex, structured data present, enough text in the raw HTML, a description, one clear h1 and a canonical URL. It is a checklist of markup, not a promise of being cited.

Does a score of 100 mean I will rank?

No. Ranking depends on content quality, links, speed and competition, none of which can be seen from one page's markup. This is not an SEO guarantee; it finds the mechanical mistakes that quietly hold a page back.

Why does it ask for pasted HTML instead of a URL?

Browsers block a web page from reading another site's HTML. Pasting the source keeps the tool private and serverless. For URLs, the Node command-line version fetches the page directly and can fail a build below a minimum score.
