Should I install a customer-supplied home elevator?

Owners call with a crate in the garage: “I already bought a Stiltz / Savaria. Can you just install it for $4,995?” That sounds like free margin because the unit invoice left the bid. It did not leave the trip, the through-floor cuts, the set hours, or the chance that the opening does not match the tube they bought.

Zeroing the unit is not a free install

A contractor-supplied pneumatic tube still carries the unit invoice. An owner-supplied unit that actually fits zeros that line and keeps the same set hours. On a typical two-stop through-floor cheap special — $52 wage, 32% burden, 15% overhead, 20% target margin, ten miles — the contractor-supplied bid is about $28,108. Zeroing a $14,500 vacuum unit drops it to about $7,264, and the owner-supplied walk-away is about $5,811. Taking the Facebook special to “just set what they bought” at $4,995 still loses about $816. A $6,995 number keeps about $1,184 when the opening matches. A wrong opening still loses about $2,231.

Wrong opening is a second trip

Online listings skip the template. Openings come in short, floor-frames are missing, and the feeder or inspection they expect you to eat is not in the crate. Setting the wrong unit means a second dispatch plus adapter plates. Price that callback on the same house before you agree. Common questions

Should I install a home elevator the customer bought online?

Only after you price the set without the unit invoice. Setting their Stiltz or Savaria is still a trip, a through-floor cut, and crew hours. A $4,995 install-only special often sits under that walk-away number even when the unit is free to you.

Does a customer-supplied home elevator make the $4,995 installed special profitable?

Usually not. Zeroing a $14,500 pneumatic invoice drops the bid, but loaded labor, hoistway cuts, travel, and overhead stay. On a typical two-stop through-floor tube the owner-supplied walk-away is about $5,811. A $6,995 number covers that set if the opening actually matches. A wrong opening adds a second trip and an adapter kit and walks away about $9,226.

What if the store-bought unit does not fit the hoistway?

That is a second dispatch plus adapter plates or a floor-frame kit. Price that callback on the same house before you agree to set whatever they rolled into the garage. The calculator adds a starting inspect trip and opening hardware on top of your current rates.
