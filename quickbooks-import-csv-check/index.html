    The model, and what it leaves out

    • Names are unique. A customer, vendor or employee Display name can appear once in a QuickBooks company, ignoring capitals and extra spaces. A repeat inside the file is an error; a clash with a name already in your account is not visible to this tool.
    • A colon means a sub-account. QuickBooks writes Parent:Child for sub-customers and sub-items, so a colon in a name you did not mean that way is flagged.
    • Opening balances are plain numbers with an as-of date. Currency symbols, thousands commas and words are refused, and a balance with no date can be skipped.
    • Dates that only read one way are fine; a file that mixes day/month and month/day is an error, and one that cannot say is a note, because QuickBooks follows your region setting.
    • Excel damage: scientific notation in phone numbers, tax IDs and SKUs, ZIP codes that lost a leading zero, garbled accents, error values and semicolon files.
    • Vendors: a tax ID that is not 9 digits, a 1099 flag that is not Yes or No. Only the last four characters of a tax ID are ever shown.
    • Products and services: Type spelling, price and cost formats, repeated SKUs, and inventory items missing a quantity, as-of date or asset account.
    • Safe fixes change only the delimiter, spaces at the ends of a name, money columns and the spelling of a Type. It never edits an email, phone, address, ZIP, SKU, tax ID, description or the middle of a name.
    • Not checked: that QuickBooks will accept the file today, names already in your account, whether accounts, tax rates and lists exist, and anything Intuit changes in its importer. Import a few rows first.

    Common questions

    Why did my QuickBooks Online import fail or skip rows?

    The usual causes are a name that is blank or repeats another (display names are unique across customers, vendors and employees, ignoring capitals), a colon in a name that QuickBooks reads as a sub-customer, an opening balance with a currency symbol or no as-of date, dates mixing day/month and month/day, an email it cannot read, more than about 1,000 rows, and a spreadsheet save that turned phone numbers or tax IDs into scientific notation or stripped a leading zero from a ZIP. This tool tests each of them and names the line.

    How do I check a QuickBooks customer or vendor CSV before importing?

    Choose what you are importing, then paste the file or drop it onto this page. It lists every problem with its line number, grouped as errors, warnings and notes. Nothing is uploaded.

    Why does QuickBooks say a customer already exists when I import?

    Display names must be unique across customers, vendors and employees in one company file, ignoring capitals and extra spaces, so Acme and acme collide. The tool finds repeats inside your file; it cannot see names already in your QuickBooks account, so also look there.

    What is the row limit for a QuickBooks Online import?

    Intuit's help pages describe a limit of about 1,000 rows per import. If your file is longer the tool says how many files you need and can write them, each with the header row. Check the current limit in QuickBooks, because it is read from memory here.

    What does Apply safe fixes change?

    Only things with one reasonable reading: the delimiter, spaces at the ends of a name, money columns such as $1,250.00 to 1250.00, and the spelling of a product Type. It never edits an email, phone number, address, ZIP, SKU, tax ID, description or a name in the middle.

    Is it safe to put client lists into a web page?

    The page runs in your browser, the file is read locally and nothing is uploaded; a test in the code asserts there are no network calls. If you work with clients' data, your own engagement terms and policies still decide what you may open in a browser. Tax IDs are shown only as their last four characters in the report.

    What does this not check?

    Whether QuickBooks will accept the file today, whether a name already exists in your account, whether accounts such as Sales or Inventory Asset exist, tax rates, class and location lists, and anything Intuit changes in its importer. A clean result is not a promise of success: import a few rows first.
