What this is

A working set of 1279 small, single-purpose web tools across 12 areas — pricing a job, checking what a marketplace sale actually nets, planning cashflow, normalising freight quotes, and assembling the evidence a compliance obligation asks for. Each one exists because the arithmetic behind it is easy to get wrong under time pressure and expensive to get wrong in front of a customer.

They are deliberately narrow. A tool here answers one question for one kind of business, rather than being a spreadsheet template that answers none of them well.

The one thing that is counted is which tools get opened, as a plain tally that is written to your own browser's local storage and is never sent anywhere. It exists so the next tool built is one people actually opened. Browsers sending Do Not Track or Global Privacy Control are not counted at all, and there is an opt-out checkbox at the foot of the tool list.

Why it is free

Because keeping it free costs almost nothing. A static page has no per-user cost, so there is no usage to meter and no reason to build a paywall around arithmetic. There is no paid tier, no trial, and no feature held back — the version you are using is the whole product.

If one of these has saved you money, sponsoring on GitHub is welcome and entirely optional. Declining changes nothing about what any tool does, and nothing here is gated behind it.

What these tools are not

They are estimates and working records, not professional advice and not a determination made on anyone's behalf. They do not replace a quantity surveyor, an accountant, a lawyer, or an engineer, and the output of any of them is a starting figure to check against your own numbers before you quote it to a customer or file it anywhere. The full terms are in the footer of this and every other page.

Embedding a tool on your own page

Every one of the 1279 tools here can be framed on someone else's page — a trade association's resource page, a supplier's blog post, a forum's sidebar. Open any tool and scroll to the bottom for a ready-made, copyable snippet built from that page's own address and title; there is nothing to write by hand. It always takes this shape:

<iframe src="https://duncan-haywood.github.io/monorepo-projects/<tool-slug>/?pfEmbed=1" style="width:100%;max-width:820px;border:0;min-height:1400px" loading="lazy"></iframe>

  • Same arithmetic, same disclaimer. The framed page is the calculator's own page, not a stripped-down copy, so it keeps the tool's full working and its liability notice.
  • Links back. A framed tool swaps its own site-wide navigation for one line linking back to the full page here, so a visitor can always reach the rest of the site.
  • Adds nothing. No script, cookie, or request is added by embedding — the framed page runs the same client-side arithmetic described above, on the host's page instead of this one.
  • 1400px is a starting height, not a fit for every form; most hosts adjust it once the embed is on the page.

This needs no permission and no message to us first.
