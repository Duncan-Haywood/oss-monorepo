    Common questions

    Does this connect to my AWS account?

    No. It reads the REPORT lines you paste and never contacts AWS. It cannot see your real invoice, free tier, tiered pricing, provisioned concurrency or other functions, so every dollar figure is lines you pasted times list prices you can edit.

    How can it know the duration at a different memory size?

    It cannot measure it; it models it. Lambda gives CPU in proportion to memory, about one vCPU at 1,769 MB. A CPU-bound function speeds up as memory rises and an I/O-bound one does not, so the tool shows the cheapest size at 0%, your guess, and 100% CPU-bound. If those disagree, the real answer depends on your code: run AWS Lambda Power Tuning to measure it.

    Why does it limit how much slower the new size may be?

    Cost is memory times billed time, so shrinking memory on a CPU-bound function can look cheaper on paper while making every request several times slower. The tool only recommends sizes whose modelled median stays within a latency cap (1.25x by default, editable).

    Is my log text uploaded anywhere?

    No. The browser page analyses the text in your own browser and never sends it anywhere. The CLI reads a local file or stdin and makes no network call.
