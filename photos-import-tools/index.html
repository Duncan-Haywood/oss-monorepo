Import photos without losing your place.

Python command-line tools for moving large photo libraries into Apple Photos. Every step is recorded in a manifest, so a crash or timeout resumes instead of starting over or duplicating files.

What it does

  • resumable_photos_import.py: restartable importer with init, run, status, preflight and verify commands; JPEG and RAW keep separate manifests.
  • photos_import_watchdog.py supervises the import phases, and photos_import_errors.py classifies failures and picks a recovery action.
  • sd_offload.py copies from removable storage; --verify hash compares SHA-256 so a same-size corrupted copy is caught.
  • verify reads every manifest file back and exits 1 if any is missing, empty or unreadable, before you retire a source copy.
  • Status and report files are written atomically, so a reader never sees a half-written file.

Status

Prototype. It runs on your Mac and talks to Photos.app; defaults reflect one machine's folder layout, so pass your own paths as the README describes.

Run it yourself

git clone https://github.com/Duncan-Haywood/oss-monorepo
cd oss-monorepo/ventures/photos-import-tools

The README in that folder has the full steps.
