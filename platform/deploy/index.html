Deploy your own copy

Pick an app, click Deploy, and a copy of it appears in your GitHub account, live on GitHub Pages. You run it; we host nothing.

Before you click. You become the operator of your copy: its domain, terms, privacy policy, users and any changes are yours. The software is MIT licensed and provided as is, with no warranty; the creator is not liable for your copy. The app's own disclaimers ship with it — keep them accurate.
Create a classic token with only the public_repo scope, then delete it after deploying. It stays in this tab and is sent only to api.github.com. It is never stored and never reaches any server of ours.

What happens

  1. Your browser reads the app's files from the public source repository.
  2. It creates a public repository in your account and commits those files plus a README with your operator notes.
  3. It turns on GitHub Pages. The site is usually live within a minute or two.

Prefer not to paste a token? Copy the app's folder from the source repository into any static host. Every app is plain files.
