    PRICE DROP WATCHER · FREE · SELF-HOSTED

    Price drop and back-in-stock alerts for any product page

    Check a page here, copy two small files into your own GitHub repository, and your phone buzzes when the price falls or the item is back. It runs on your own free Actions minutes, so nobody else holds your watch list.

    The tester below reads the page source you paste in this browser. This page makes no network calls and nothing you paste leaves your device.

    1. Test a product page

    Open the product page, choose View Source (or Ctrl+U), copy everything and paste it here.

    This shop publishes no price data? Add your own pattern

    Paste a page's source and click the button.

    2. Your watch.json

    Add one entry per product. Put this file in the root of your repository.

    
    
    
    
    
  
    
  
    
    
    3. Turn it on in your own repository
    
    
      
      
    1. Create a repository (private is fine) and add extract.mjs, watch.mjs and your watch.json.
      2. 
      
    2. Save the workflow below as .github/workflows/price-watch.yml.
      3. 
      
    3. Pick a hard-to-guess topic name, install the free ntfy app on your phone, subscribe to it, and add the same name as a repository secret called NTFY_TOPIC (or DISCORD_WEBHOOK for Discord).
      4. 
      
    4. Run the workflow once from the Actions tab. It records the starting prices; later runs alert on changes.
      5. 
    
    
    
    # Copy to .github/workflows/price-watch.yml in YOUR OWN repository (a private one is fine).
# Runs on your GitHub Actions minutes and your secrets; nothing passes through anyone else.
name: price-watch
on:
  schedule: [{ cron: "17 */6 * * *" }]
  workflow_dispatch: {}
permissions:
  contents: write
jobs:
  watch:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - uses: actions/setup-node@v4
        with: { node-version: 20 }
      - run: node watch.mjs --config watch.json --state state.json
        env:
          NTFY_TOPIC: ${{ secrets.NTFY_TOPIC }}
          DISCORD_WEBHOOK: ${{ secrets.DISCORD_WEBHOOK }}
      - run: |
          git config user.name "price-watch"; git config user.email "price-watch@users.noreply.github.com"
          git add state.json && (git diff --cached --quiet || git commit -m "price-watch: update state" && git push)

    
    
    
    Try it on your computer first: node watch.mjs --dry-run prints what it sees and sends nothing.

    Questions people actually ask
    
    
    How do I get a price drop alert for free without giving an app my email?
    
    
    Copy the watcher into your own GitHub repository, list the product URLs in watch.json and turn on the scheduled workflow. It checks every six hours on your own Actions minutes and sends a push through ntfy or a Discord webhook. No account here, no email list.
    
    
    Will it work on any shop?
    
    
    It reads the structured data most shops publish for Google (schema.org Product, Open Graph price tags, microdata). Paste a page's source into the tester above to see what it finds. If a page has none, give it a priceRegex for that page.
    
    
    Is it allowed to check a shop's page?
    
    
    It identifies itself, reads robots.txt first and skips any page the shop disallows, and makes one request every two seconds. It is for watching a handful of pages for yourself, not for scraping a catalogue. Check the shop's terms.
    
    
    How is this different from CamelCamelCamel, Keepa or Honey?
    
    
    Those track a fixed set of big retailers on their servers and earn money from affiliate links or subscriptions. This watches any page you choose, runs in your own repository, has no tracking links, and is free. It has no price history charts or shared database.
