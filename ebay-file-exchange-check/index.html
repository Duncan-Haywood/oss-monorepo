Safe fixes

    The rules, and what they leave out

    • Comma-separated UTF-8. File Exchange reads CSV. A semicolon file (European Excel) or Excel's UTF-16 "Unicode Text" is read wrongly.
    • Action is Add, Revise, End, Relist or VerifyAdd, and the header names the site, like *Action(SiteID=US|Country=US|Currency=USD|Version=1193). Revise and End rows need an ItemID or a matching CustomLabel.
    • Title is at most 80 characters. All-capitals and repeated punctuation are flagged because they waste the space that carries keywords.
    • ConditionID is numeric: 1000 New, 3000 Used and so on. Which IDs a category accepts varies, so unknown ones are warnings.
    • Format and Duration: FixedPrice listings use GTC; auctions use Days_1, 3, 5, 7 or 10 and list one item.
    • StartPrice is digits and a decimal point only. Quantity is a whole number.
    • PicURL takes up to twelve https addresses separated by a pipe. Description may not contain JavaScript, iframes, forms or event handlers.
    • UPC and EAN check digits are recomputed for every row; "Does not apply" is accepted.
    • Safe fixes change only the delimiter, stray spaces, price formatting, a quantity written as 5.0, Action and Format capitalisation, and an 11-digit UPC whose restored leading zero passes the check digit. It never edits a title's words, a description or a picture address.
    • Not checked: that eBay will accept the file today, whether a category ID exists, item specifics, business policies, variation listings, VeRO and prohibited items, and pricing. Upload two or three rows first.

    Common questions

    Why did eBay reject my File Exchange CSV?

    The usual causes are a file saved with semicolons or as UTF-16 instead of comma-separated UTF-8, a title over 80 characters, a missing or misspelled Action, a UPC that lost its leading zero in Excel or whose check digit is wrong, ItemIDs or SKUs that Excel turned into scientific notation, prices with currency symbols or decimal commas, a Duration that does not fit the Format (an auction cannot be GTC), picture URLs separated by commas instead of pipes, and JavaScript in the description. This tool tests each of them and names the line.

    Why did Excel change my eBay ItemIDs and UPCs?

    Excel treats long digit strings as numbers. A 12-digit ItemID becomes 1.23457E+11 and the real digits are lost, and a UPC that starts with 0 loses it. Format those columns as Text before pasting. This tool flags both, and restores a UPC's zero only when the 12-digit result passes the check digit.

    How do I separate multiple pictures in a File Exchange file?

    From memory of eBay's documentation, PicURL takes up to twelve https addresses separated by a pipe character, not a comma. This tool reports comma-separated pictures and any address that is not https.

    What does Apply safe fixes change?

    Only things with one reasonable reading: the delimiter, stray spaces, prices like $1,299.00 to 1299.00, a quantity of 5.0 to 5, Action and Format capitalisation, and an 11-digit UPC to 12 digits when the check digit confirms the restored zero. It never edits a title's words, a description, a category or a picture address.

    Is it safe to put my listings into a web page?

    The page runs in your browser, the file is read locally and nothing is uploaded; a test in the code asserts there are no network calls.

    What does this not check?

    Whether eBay will accept the file today, whether a category ID exists or accepts a condition, item specifics, business policy names, variation listings, VeRO and prohibited items, and whether the price is competitive. A clean result is not a promise of success: upload a few rows first.
