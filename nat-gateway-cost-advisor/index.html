Common questions

Does this connect to my AWS account?

No. It reads the rows you paste and never contacts AWS. It cannot see your real invoice, Savings Plans, private pricing or free tier, so every dollar figure is the rows you pasted times list prices you can edit.

How do I get the GB per destination?

Turn on VPC Flow Logs for the NAT gateway's network interface and sum bytes by destination, or in Cost Explorer filter usage type NatGateway-Bytes by gateway. Label the destinations you can tell are AWS services (S3, DynamoDB, ECR, CloudWatch Logs, STS, SSM); everything else counts as internet and is never recommended for an endpoint.

Why is S3 through a NAT gateway such a common waste?

A NAT gateway charges $0.045 per GB processed for every byte, including bytes to S3 in the same region, while a gateway endpoint for S3 or DynamoDB is free and is only a route-table entry. Terabytes of S3 reads from private subnets cost hundreds of dollars a month for nothing.

When is an interface endpoint worth it?

An interface endpoint costs $0.01 per hour per AZ (about $7.30 a month per AZ) plus $0.01 per GB, against $0.045 per GB through the NAT gateway. It breaks even at roughly 209 GB a month per endpoint per AZ, and services such as ECR, SSM and ECS need two or three endpoints, which the tool counts.

Is my data uploaded anywhere?

No. The browser page analyses the text in your own browser and never sends it anywhere. The CLI reads a local file or stdin and makes no network call.
