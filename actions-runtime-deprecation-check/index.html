Common questions

What does the “Node.js 16 actions are deprecated” warning mean?

GitHub runs JavaScript actions on a Node runtime chosen by each action’s major version. When that runtime reaches end of life, GitHub annotates every run that uses the old major and later forces a newer runtime, which can change behaviour. This tool lists every step that triggers it, with file and line.

Which actions have been shut down entirely?

actions/upload-artifact and actions/download-artifact v1 to v3, and actions/cache v1 and v2, are no longer served by GitHub, so jobs using them fail rather than warn.

Is Node 20 a problem today?

Not today. It is reported as informational because GitHub has announced moving the runner default to Node 24. It never counts as a risk.

Does this tool cover third-party actions or SHA-pinned refs?

No. It covers a short list of first-party actions/* actions. A commit SHA or a branch such as @main cannot be mapped to a major version, so those lines are skipped, not judged.

Does this tool send my workflow anywhere?

No. It makes no network calls. Paste your workflow YAML and the scan runs entirely in this page.

Does a clean scan mean my workflows are up to date?

No. The version-to-runtime table is a labelled snapshot (as of 2026-10) and covers only some actions. Confirm against each action’s action.yml (runs.using) and release notes before upgrading.
