This calculator vs. Homewyse

Homewyse prices a crown-molding install from a zip code and a linear-foot count alone. This page is a free, private worksheet for the same question with the grade, profile, ceiling, and corners put back in — the inputs a zip-and-footage estimate has no field for.

What each tool is for

Homewyse is a free, vendor-neutral online reference for home projects, operating since 2006, offering cost estimators across maintenance, installation, and materials categories with no account required for basic access. Its crown-molding install estimator takes two inputs — a zip code and a linear-foot count — and returns a per-foot price range for what its own disclaimer labels “BASIC mid-range work performed in readily serviceable conditions.” It does not ask about molding grade, profile (simple cove versus colonial versus built-up), joint type (mitered versus coped), ceiling shape, story height, removal of existing trim, or the number of inside and outside corners.

This calculator asks for exactly those. Starting from linear feet, inside and outside corners, rooms, grade (paint-grade versus stain-grade), profile, ceiling type (flat, cathedral, or tray), ceiling height, demo of existing crown, blocking, an LED cove, casing match, travel, loaded wage, burden, and overhead, it turns that into the walk-away price below which the run loses money, the price per linear foot, and where the crew hours are actually going — plus a printable customer proposal with scope lines and a signature block. On this calculator's own worked examples, at a fixed $42 crew wage, 32% burden, 15% overhead, and 20% target margin, 80 identical linear feet walk away at $1,182.95 as a flat paint-grade simple cove in one 8-ft room and at $7,710.87 as stain-grade built-up crown in a two-story cathedral foyer with fourteen coped inside corners and an LED cove — a spread Homewyse's own two inputs, zip code and linear feet, have no field to represent. It runs free in any browser, keeps no account, and uploads nothing you type.
