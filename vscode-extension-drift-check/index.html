    Common questions

    Why doesn't VS Code already warn me about this?

    VS Code auto-updates extensions silently and has no mechanism to tell you an installed extension's activation surface changed, or that it was later pulled from the marketplace for being malicious. If you already have it installed when that happens, it keeps running with no notice — auto-update just quietly stops offering a newer version.

    Is this a malware scanner?

    No. It reports a structural difference between two snapshots of an extension's declared manifest fields (when it activates, what it depends on, its entry point), and a factual marketplace-resolution check. A flag means "read this one", not "this is malware" — it is not exhaustive and it is not a verdict.

    Is my extension list uploaded anywhere?

    No. The browser page parses the snapshot you paste entirely in your own browser and never sends it anywhere. The CLI's snapshot and diff commands read only local files — no network call, ever. Only the CLI's separate check command talks to the network, on your own machine, and only when you run it.

    What do I paste in?

    The output of node cli.mjs snapshot for the full picture, or the plain output of code --list-extensions --show-versions (Cursor and Windsurf have the same flag) for a quick id/version-only check.
