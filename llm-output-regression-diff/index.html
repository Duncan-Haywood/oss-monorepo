    Common questions

    Does this call any model or API?

    No. It compares two files of outputs you already saved. It makes no network call, needs no API key and never sees your prompts unless you put them in the output text.

    What does it actually check?

    Per case id: empty or missing output, JSON that stopped parsing or lost keys or changed a value's type, new refusal or apology wording, unclosed code fences, large length changes, numbers that disappeared, lost lists, headings or code blocks, truncation, and low word overlap. Errors are likely to break a consumer; warnings deserve a human look.

    Is this a quality score for a model?

    No. It is a tripwire for changes, not a judge of which output is better. A flagged case can be an improvement and a clean case can still be worse; read the flagged ones and keep your own evaluation for quality.

    Is my data uploaded anywhere?

    No. The page works in your browser and sends nothing. The CLI reads local files only.
